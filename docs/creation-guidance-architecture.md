# 创作方法与任务选择（2026-10-26）

## 边界

保持唯一 Scene v2、统一 Command 执行、来源/物理尺寸/裁片占用和真实 Canvas 预览。创作方法是指导信息，不增加一种作品格式，也不生成固定坐标模板。

`src/creation-guidance.js` 同时供搭配页、网页 AI 动态指导、应用内 AI 和生图提示使用。它根据现有风格、用途、文字策略及本次候选材料选择方法；用户无需新增配置。主素材、普通胶带/印章、数字预设分别计数，避免 27 个辅助预设让一张照片被判断成“主素材丰富”。分类只是线索，实际视觉重量仍需查看原图和毫米尺寸。

## 阅读与执行

1. `self-test` 检查环境；`brief` 返回 TASK 的任务、事实、选择优先级、尺寸、图片路径与方法选择，不展开来源快照。
2. 动态 `design/GUIDE.md` 说明本次需求；共用 `design/SKILL.md` 说明图文共同构图与视觉迭代。
3. `guide` 列目录；`guide tape stamps` 或 `guide 美式拼贴` 只返回需要的方法与可执行命令名。精确字段仍用 `describe`，不重复维护另一套参数 Schema。
4. 完整初稿 → apply → 真实 preview → 看图找具体原因 → 有必要的修订 → pack。不是强制粗排、强制三候选或强制工艺数量。

`brief`、`guide` 只读，不改 Scene。非法专题返回 `GUIDE_TOPIC_UNKNOWN`，不猜文件路径。移除无调用方的旧 instructions/plan 文档导出，避免维护者再次引用过时协议和组坐标说明。

离线 ZIP 先采用本地 CLI：网页 AI 环境拿到 ZIP 即可操作，不需要常驻服务或连接用户数据库。将来如宿主有稳定 MCP，可作为同一执行器的薄传输层；当前没有新增 MCP 服务。应用内模型传输仍有 native-tools、JSON tools 与 direct-page 路径，共享创作指导不等于这些传输已迁移到统一 Command；不能据此宣称所有入口能力完全一致。

## 验证边界

- 方法引用的每个操作名须存在且可执行；纯拼贴/不配文、记录事实、清单、封面与材料数量分别测试。
- 实际导出的 ZIP 测试 `brief/guide`，并验证 Scene 字节不变、未知专题报错。既有真实 Canvas、裁片、开窗、穿插、项目重新导入测试继续运行。
- 搭配浏览器用例检查用途联动、四种视口、无横向溢出；使用模拟账号，不访问用户数据库。此检查不代表实体 Safari 验收。
- 读取字符数和 CLI 耗时可衡量准备成本；不能替代完整创作速度与审美质量。三件素材保留失败首稿，修订后把同源纸分片分布到两页、保留书写并增加回应主题的信封。八件素材加两段胶带、一枚印章完成 32 条初稿指令和 3 条局部修订。两者均已实际看 PNG、打包、重新导入；不是独立盲测或所有风格的审美验收。

## 实际试作暴露的执行问题

- `material.split`/实体裁切替换原图层时，沿用原层级与组归属，避免加工后的背景跳到文字上方。保留原有兄弟图层 zIndex，避免误触锁定或用户编辑保护；覆盖根级和旋转组回归。
- Scene 渲染器把已有画布工厂传给素材绘制、胶带取样与轴向旋转。Node 与网页继续使用同一算法，不使用 document 全局垫片或替代图片。真实胶带 Command→PNG→pack 通过，横纵轴像素回归验证非透明源像素被正确绘制。
- Schema 错误优先报告具体深层字段，路径内不支持的 strokeWidth 不再误报另一个分支的 viewBox。严格字段校验保留。
- 仅预设试作发现，素材与图形的底层默认 zIndex 不同，后添加的贴纸被先前的色块盖住。统一 Command 的新建节点现在按命令顺序放在同级最前方，修改保留原层序，显式 order 控制先后。只改新节点，不重新编号锁定兄弟；实体裁切替换仍保留原层级。
