# 画面问题 → 选技法 → 选 Command → 验证

本文件按诊断使用，不要从头到尾机械执行。围绕当前主要问题，积极尝试多个局部变化；可以同时在不同区域构成呼应。先画出来看效果，不一味只做最低限度。不以高级命令数量、笔迹数量或素材裁切面积评价质量。

<a id="r01"></a>
## R01 · 从素材陈列板改为有主次的叠层
**症状：** 大纸片完整平铺、旋转角度略不同，但各自孤立。
**动作：** 选焦点和书写面，让一张纸成为后景或露边；人物轮廓/印刷标题与正文产生真实搭接。处理无关空边只在来源允许时裁切。
**操作：** `material.add`、`layer.update`、`layer.update`、`group.create`、必要时 `material.cut`。
**复核：** 缩看能分辨“谁在承托谁”；未遮住必要印刷字和脸。若任务要求完整展示物件，可保留全部原件，但仍需构建关系。

<a id="r02"></a>
## R02 · 让一个元素跨过恰当的边界
**症状：** 文字、人物和图案分别关在自己的矩形纸块内。
**动作：** 让短句、短线或小图案跨过相邻纸边；或让异形人物与两张底纸同时搭接，建立一条明确关系。
**操作：** `text.add`、`graphic.add`、`layer.update`、`layer.update`。
**复核：** 跨的是纸片/图文边界，不是无意跨装订中缝；遮挡不会破坏文字可读性。

<a id="r03"></a>
## R03 · 文字不能只剩同级小字
**症状：** 四五段话大小、重量、长度都相近，像统一商品说明。
**动作：** 先决定印刷标题、主要随写、简短回应与边注的职责；正文获得足够书写面，块内对齐、块间允许错位。优先调宽度、行距、正文长度和空间。
**操作：** `text.add`、`layer.update`、`layer.update`、`text.fit`；`size.width`、`style.fontSizePt`（pt）、`style.lineHeight`。
**复核：** 正常整页大小有可读的主要文字，第二层边注不会抢主体；已有强印刷标题不再叠同义标题。

<a id="r04"></a>
## R04 · 关键词需要轻强调
**症状：** 正文中确有一句转折或关键词，但没有视觉停顿。
**动作：** 先确定哪几个字值得强调，再在背后用短色带/marker 强调。不要先画很多黄色条再找句子。
**操作：** `graphic.add` 的 stroke 几何 + `style.penStyle="marker"`、`graphic.add` 的局部浅色填充，配合 `order.before` 或 `layer.update` 置于文字后方。
**复核：** 关键词与色带可辨，字没有被不透明图层盖掉；若纯拼贴或无重点可不加。

<a id="r05"></a>
## R05 · 让短笔迹或矢量回应具体素材
**症状：** 页面整齐但缺少随写感，第二眼没有细节。
**动作：** 沿花束或人物方向画一条简笔回应；从材料中的纽扣/星芒提取形状，在相关句旁重复一次；用短线或箭头连接具体旁注。
**操作：** `graphic.add`、`layer.duplicate`。
**复核：** 能说出它指向哪件素材或哪句话；拿掉后关系会减弱。不要每页固定撒星星、圆点和小箭头。

<a id="r06"></a>
## R06 · 调色彩对比与页面重心
**症状：** 所有内容色彩相近却发闷，或重色/大字都堆在一侧。
**动作：** 从原有素材取主色；拉开相邻元素的明度，选一个小范围的色彩跨区呼应。先移动或减轻重区，再决定是否需要小亮点。
**操作：** `layer.update`、`layout.align`、`layer.update.style`、数字图形。
**复核：** 第一焦点清楚；留白有停顿的作用，不因“平衡”强行填满两页。

<a id="r07"></a>
## R07 · 大纸或大矩形挤掉正文
**症状：** 实物占满纸面，新增文字被压到窄缝、缩得很小。
**动作：** 先把纸重新当成书写面或底纸；挪出正文位置。任务许可时取真正需要的印刷区域或裁成连接条。保持来源身份与实际毫米尺寸。
**操作：** `layer.update`、`material.cut`、`material.split`、`material.edge`。
**复核：** 必要印刷信息与主体还在，文字正常尺寸可读；mask 不产生实体余料，禁止重复消费。

<a id="r08"></a>
## R08 · 构图很整齐却缺少自然关系
**症状：** 每个物件对齐、单独旋转，像网格展览而非拼贴。
**动作：** 给一个局部组设共同方向，其他纸片局部错位，允许少量遮盖，但不随机倾斜每件材料。
**操作：** `group.compose`、`layer.update`、`layout.align`、`layer.update`。
**复核：** 局部组能找到视觉方向，素材边界依然真实；无意的重叠不覆盖正文。

### 选用记录（保持简短，无需输出冗长计划）
问题：哪个具体区域显得孤立／难读？
动作：做一个能解释的关系或重排。
工具：查询对应 Command 的当前 `describe`。
预期：哪个焦点、文字或连接应该变清楚？
结果：看真实 PNG；若效果不好，撤掉而不是再加装饰。

<a id="r09"></a>
## R09 · 素材少：让文字与图形成为主角
**症状：** 一两件小素材占页面一角，剩下只有小字和大片空白。
**动作：** 用具有视觉重量的标题/段落或主矢量组织页面；正文分块、大小有别。用大色块/边框/几何作结构，不默认建一堆小装饰。材料成为锚点或与图形相接，不能凭空增添实体库存。
**操作：** text.add、text.lettering、graphic.add、group.compose。
**复核：** 即使暂时隐藏素材，仍然能读到明确的文字/图形构图；不是把一小段字硬放大成整页。

<a id="r10"></a>
## R10 · 主体稳定以后，选择小件而非提前堆满
**症状：** 大材料刚摆好就停止，或一开始塞了太多小贴纸导致没有正文位置。
**动作：** 先稳定包括标题和文字块在内的主视觉重量，再用小素材、胶带、文字条、数字形状和笔迹回应具体空区/边界。小圆可藏半在纸后，标签可移到空区平衡重心；细节围绕主体而非散点铺满。
**操作：** material.add/tape/crop、graphic.add、layer.update/order。
**复核：** 点缀有联系、有疏密；没有合法胶带源时用数字色条并如实命名。保留能增加关系的，删除只是凑数的。

<a id="r11"></a>
## R11 · 字也可以是图形，不只是一种字体
**症状：** 新增文字全部相同字体、大小和颜色，缺少层级。
**动作：** 给短标题或一个关键词选一种主要效果：同侧阴影、完整描边、两三色渐变、偏移轮廓、小背景；必要时逐字换字体/笔重、轻微角度。正文保持舒适阅读。不要每个字都堆全部效果。
**操作：** style.outline/gradient/shadow、text.lettering、graphic.add；精确例子见 LETTERING.md。
**复核：** 字形可识别；效果不是字体的替代；正文和标题形成区别，不用花字掩盖空洞内容。

<a id="r12"></a>
## R12 · 大片空白不是靠小点缀补救
**症状：** 某一半页面、上下半部或材料内部留有大块没有作用的空区。
**动作：** 回到主块尺度与位置：调整标题、段落、数字主图形的面积和关系，必要时在已有事实内展开文字。以整页与局部两种尺度检查。不要拉伸真实素材，也不要以废话、复制贴纸和随机小圆填满。
**操作：** layer.update、layer.update、graphic.add、layout.align；design-check 仅作框级定位辅助。
**复核：** 空区缩减是因为内容组织更完整，不是机械增加覆盖率；仍有边距、行距与眼睛休息的位置。

## 把局部诊断转成操作，而不是寻找“点缀命令”
- 关键词需要呼应：先决定是短文字回应、线条强调，还是小图形；圈线可用 graphic.add + geometry.kind=ellipse、fill=null，相对该文字用 place。
- 纸片之间缺少连接：可以叠压小素材、跨放合法胶带/裁条，也可以用短句或色块，不默认全部画星星。
- 需要星芒或小花：使用通用图形 geometry.kind=star/sparkle/flower。与页面图案有关才加，尺寸和强弱通过公共 size/style 控制。
- 图形应成为主视觉：同一 geometry 放大并重排即可，不换到另一个接口。
- 删除后反而更清楚：取消这处点缀，不用另一颗星补回去。

可执行参数见 GRAPHICS.md；这些是选择方法，不是固定坐标模板，也不按点缀数量验收。

## 不吝啬装饰，不等于乱堆
从主结构进入细节后，主动扩大选择范围：短字、编号、图案、圈线、重叠小贴纸、真胶带、色带、局部背景和艺术字都值得尝试。每个区域的大小/明暗/方向有变化，细节之间可以重复呼应，不要求每一处都是全新符号。只在实图显示具体问题时减去对应内容。大空洞先补主块，完成主块后仍需细节，不能将两者混为一谈。
