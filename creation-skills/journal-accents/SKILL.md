# 点缀与细节

模板先解决位置与比例，点缀再建立素材之间的关系。完成主要图文后，观察最新预览：哪里需要强调、连接、固定或颜色呼应？有明确作用才添加；用户要求纯拼贴时只用真实材料，不擅自加绘画。

## 从真实案例提取的层次

1. **接触点**：标题与照片交界、纸片露边或胶带端部，形成一个局部小簇，不沿每张照片四周平均装饰。
2. **次级呼应**：在另一个内容簇放更小、更疏的同类细节。主簇与回声不等大，留出整段安静区域。
3. **近看细节**：纸边针脚、细线枝叶、小圈标记。远看不夺主视觉，近看有笔触。
4. **真实语义**：邮票、日期标签、票根、夹子、剪余料来自现有素材；与主题有关才加入。数字圈线可以呼应，不能生成假票据冒充库存。

## 选择方法

| 目的 | 方法 | 使用边界 |
| --- | --- | --- |
| 标题或照片角落的强调 | accent-spark | 少量四角光芒；适合活泼主题，不是通用填空 |
| 自然、安静的线条陪衬 | accent-sprig | 一两枝轮廓；调尺寸与色彩，别遮主体 |
| 纸边、标签的手工细节 | accent-stitch | 针脚组沿局部边缘排列，非整页围框 |
| 用颜色连接两处内容 | accent-rings | 大小不同的空心圈，保持透底与间距 |
| 活泼的小面积节奏 | accent-confetti | 色块与圆点局部成簇，最多两种呼应色 |
| 真实贴纸、印章、票根配组 | accent-materials | 输入实际 aliases 和比例 positions，保留原尺寸，不自动裁切或缩小 |

通过 read_skill 的 methods/detail 查图与完整参数，再用 creation_recipe 调用。配方共用可调范围、位置、数量、颜色、线宽与透明度；生成组可整体移动、旋转，内部图层仍可分别修改。枝叶与针脚是生成的可编辑路径，改变生成结构时重新调用配方，不能假称具有原生花瓣等形状参数。

## 放置、保护与停止条件

先按实际毫米尺寸确定局部 widthMm/heightMm 和 at。positions 使用这个局部区域的比例中心；protectedBoxes 使用同一区域内的比例矩形。把正文、脸部、日期和重要图案标成保护区。工具会省略越界、互相覆盖或进入保护区的单元，并在报告列出 skipped。省略不是失败，也不要为了凑数量强行缩小真实素材。此检查不识别内容、不读取整页遮挡；未提供的保护区不会自动被发现。

留白页先试一个主簇和一个轻微回声；繁复页围绕现有内容簇组织细节，簇之间留安静通道。这是起点，不是强制计数。已有大面积花纹时减少数字点缀，避免同页混用光芒、花朵、针脚和圆点。文字注释必须来自用户内容，不能编造日期、地点或经历。

整页与局部预览都检查：第一眼是否仍看见主体、细线在手机整页能否辨认、色彩是否来自素材、边缘有没有遮住有效内容、图层数量是否只是重复填空。模板已足够表达时可以不加点缀。自动预览后的视觉检查必须回答这些问题，不能以没有几何报错作为审美合格。

## 核查依据

对照现有阿C照片叙事模板中的箭头、胶带、邮票与局部小物，以及周末鱼块图案与线条组合教程，发现原工具已有单个图形，但缺少组合尺度、位置与保护规则。原来源及阅读范围见 photo-story、pattern-and-doodle；本专题的配方、位置算法和合成示意属于拾页归纳实现，不是原作者提供的工具，也未声称覆盖全部教程。
