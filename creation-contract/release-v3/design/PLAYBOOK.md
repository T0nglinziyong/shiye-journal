# 看见问题再选动作

按需读取。先解决主结构，其次文字与中尺度组合，最后丰富细节；不是从头到尾套用所有方法。

| PNG 中的问题 | 先尝试的动作 | 用什么验证 |
|---|---|---|
| 几张完整大矩形像展示板 | 把一件改成衬底/书写面；人物跨纸边；许可时取局部。用 layer.update、material.cut，不缩放实物 | 关闭新增字后仍能辨出承托/主次；重要印刷字不被误遮 |
| 左重右散、下重上空 | 移动一个主要图文组，或用正文/标题/主图形建立对重；不往空处撒碎点 | 缩看双页，视线能从一个主要区域走到另一区域 |
| 所有正文都是小图注 | 重新分配主文、短题和插话；增大正文空间，调整行长/行距，删重复而非一味缩字 | 正常尺寸能读主文；标题大小有区别，文字不撞纸边 |
| 有大主体和小点，却缺少内容层 | 建立“正文＋一段纸条/手绘＋局部材料”的中尺度组 | 第二眼能读到具体内容，不只是数星星 |
| 箭头/花形独立漂浮 | 将标记靠近或搭接它回应的对象；从该素材提取颜色、形状、方向；没有明确指向就换成非指示性图案 | 能指出它连哪两处、回应哪一句；不与人物争焦点 |
| 元素都关在各自框里 | 让短题、编号、人物或一条线跨过纸片边缘；不误跨中缝 | 跨边关系可见，字与底色的对比仍清楚 |
| 装饰不够丰富 | 从标题角、纸接缝、段尾、人物肩侧找能展开的局部，组合小材料/图形/笔迹/短字并跨区变奏 | 多处有可细看的关系，不是均匀的四角装饰 |
| 字和印刷标记互相打架 | 改位置/行长，避开素材的印刷标题、表格横线、白字；必要时重新分区 | 正文完整可读，不用挤字、压字或盖掉关键信息 |

Command 只表达几何和编辑，不表达“点缀”。具体参数用 describe；图形 style/geometry 看 GRAPHICS.md，文字轮廓/渐变/逐字效果看 LETTERING.md。优先复用通用参数，不自创高级工具名。
