# 手帐创作：组织关系，不只是摆位置

以 TASK 的内容/实物约束为准。文字、图形、材料同等参与；点缀是设计作用，不是专用工具。默认丰富、有层次，不默认极简。

## 构思局部图文组
看轮廓、印刷字、方向、书写空白与深浅。为主要材料分配角色：焦点、书写面、衬底、标题或连接片；必用不等于每件完整突出。用一句话说明每个局部在说什么，再让材料、字、图形一起支撑它。素材少时，让艺术标题、正文块和主图形撑起版式，不交付小贴纸加两句小字。

先决定整页大重量与主阅读路线，再完善正文、中尺度的连接，最后丰富细节。大重量包括大印刷字、深色块和密集正文，不只看材料面积。不要让左页堆满深色大字、右页几个对象各自孤立。主结构失衡时，挪位置、换职责或许可裁取，不能放大实物，也不能用小星星填大洞。

## 文字和材料同时排
把素材内的标题、表格线、印刷字也算作已占用空间。已有标题可当主标题，新增短题做次焦点，正文舒展展开；边注不要挤出孤立标点。块内对齐、块间错落，斜贴局部保留共同方向。重点字可以不同字体、轮廓或颜色；不要整页都是同级小字，也不要整篇艺术效果。用 fonts 确认真实字体，再在正常预览大小判断，不把“已指定手写字体”当成有效字形。

原文和事实不得杜撰。原创可写与材料细节有关的设想、犹豫、玩笑；不要用几句“未来/勇气/出发”的通用口号撑整页。没有真日期就不虚构日期装饰。

## 丰富细节，形成同一种画面语言
可积极使用小素材、局部裁条、合法胶带、圆点、星芒、花形、笔迹、高亮、短字和编号。先从素材提取形状、色彩、方向与粗细，再做变奏：让圆点半藏纸后，文字越过纸片边界，窄条连起相邻图文，小图案在两处不同大小呼应。不是把通用箭头/星星丢进空白就结束。

保留大、中、小三种阅读尺度：主体；正文/局部纸条/图案组；细线/小标记。中尺度缺失时，先补一个有内容的组合，再补小点。用 order 明确前后，不能假定命令先后就是层序。纸张柔和时新增线条也应协调。可先丰富尝试，再删除遮挡、无关或破坏层级的部分。

## 看图后改变设计，而不只是润色
preview 是决策节点，不是结束仪式。整幅检查重心与大空区，正常尺度检查文字，局部检查图案是否贴合材料。写出最多三项当前最重要的问题及具体位置，先解决最高层级的问题，再用下一批 Commands 修改。对照同一视角的前后 PNG，失败的动作要撤回。没有新证据不增加长篇规则。
