# 模板素材匹配统一算法方案

状态：**统一分配器 v1 已接入 14 个新模板**。三组模板保留各自的槽位几何与单槽适配判断，整页来源占用、默认候选、相邻纸张颜色检查、可选同源裁片和束搜索统一由 `unified-template-matcher.js` 处理。裁片方案由 `template-split-compiler.js` 编译为一次 `material.split`，仍由画布事务验证来源与几何。模板的量测、默认对象与画布编译遵循 [模板制作与验收规范](TEMPLATE_CREATION_WORKFLOW.md)。

本文件后续章节同时保留完整目标设计。尚未完成的部分包括：素材／模板画像缓存与后台 Worker、逐条拒绝码和完整评分分解、家庭适配评分公式进一步合一，以及移动端 30–50 模板性能验收。当前结果明确标为近似搜索，不宣称已证明全局最优。

## 目标与边界

给定一张模板、用户的素材及“必须用／可以用”要求，输出一个**可执行、可解释、原尺寸守恒**的初稿分配方案。初稿中的“必须用”提高选入优先级，不保证立即上画布；最终成品仍须满足必用要求。选模板是外层流程：对同一页型的每张新模板运行相同算法，再用同一量纲比较结果。旧模板和未验收的我的模板不参与自动推荐。

统一的是匹配与分配算法，不强迫所有模板长得一样。模板仍可声明各自的槽位、相邻关系、默认对象和允许的加工方式；不得再为某一批模板维护独立的贪心或束搜索入口。画布的 `material.split`、`layer.split`、`layer.mask` 等执行器继续负责实际几何和来源账本，匹配器不得自己假造一套耗材规则。

## 一、输入：槽位、关系、素材

每张模板转换成同一个 `TemplateSpec`，只记录已有量测与必须的创作语义；不复制一份与执行器不一致的图层树。

| 数据 | 最少内容 | 用途 |
| --- | --- | --- |
| `Slot` | ID、页、完整框／可见框、目标中心与角度、视觉作用、默认对象、重要性、可替换条件、允许加工、内容安全区 | 生成单槽位候选和默认方案 |
| `Relation` | 两个槽位 ID、关系类型、期望范围、硬约束或软权重 | 检查重叠、露边、图层、颜色、间距、边缘连接、跨页呼应 |
| `MaterialProfile` | 来源 ID／修订、真实毫米尺寸、可见轮廓、颜色分布、主体与印字保护区、可书写区、视觉作用、主题、完整性／裁片权限、库存单位 | 判断能否完整用、遮罩用或实体分片 |
| `UserIntent` | 最终必用／可以用、手选槽位绑定、文字与颜色覆盖、是否允许裁切 | 初稿提高最终必用素材的匹配优先级；手选绑定及加工权限仍需遵守 |

尽量从现有 `materialTemplateProfile` 和模板节点提取，不要求用户再填一套重复元数据。缺失信息采用保守处理：例如不知道印刷主体安全区时，不自动把印刷卡或异形人物切成两片；普通纯色或连续纹样纸可以按明确的完整性标记裁切。用户素材不靠缩放改变其物理毫米尺寸。预设胶带等允许多次取用的素材，由现有来源／库存规则声明例外；普通实体素材以一个来源单位计。

## 二、单个槽位：先可行，再评分

一个候选 `PlacementOption` 明确写出 `slotId、sourceId、sourceRegion、visibleRegion、place、rotation、method、scoreBreakdown`。每个槽位始终有一个可编辑的默认方案；“重要照片必须有真实素材”可让该模板在自动推荐时不合格，但不删除其默认预览。

1. **硬条件**只管能否真实、安全执行：素材授权及库存、真实尺寸与页面边界、来源区域非空、裁切权限、主体／文字保护区、模板明确要求的用途、用户手选绑定。硬条件失败时返回稳定的拒绝码和具体数值，不给候选分数。
2. **软评分**评价合适程度：视觉作用、题材与文字内容、目标尺寸及可见轮廓、可写面积、颜色、主体朝向、裁切损耗与加工复杂度。只有明确必要的视觉关系才设为硬条件；一般的颜色偏好不应因为某个固定阈值一票否决。
3. 合格候选归一到同一分数范围，并保留分项。候选可以是完整保留、显示蒙版、实体裁片或模板默认对象；显示蒙版**不释放被遮住的实体材料**。自动生成的纸、字、图形与实体素材分开标记，避免把默认对象误报为“已用用户素材”。

`scorePlacement(slot, option)` 是唯一的单槽位评分入口。模板差异放在 `Slot` 参数里，不再存在“单页评分公式／六张双页公式／三张双页公式”三个互不兼容的分值。槽位权重反映原案例中的视觉重要性：主照片、大纸、标题或关键异形主体可高于小点缀，但默认对象不应一概低分，否则算法会为提高素材使用数强塞不合适的贴纸。

## 三、相邻位置：稀疏关系图

只对模板中有实际关系的槽位建立 `Relation` 边，不做全页任意两对象的两两比较。关系由原案例的完整框、可见框、层级和人工确认的关键接触点构成；替换后用**实际裁片及可见轮廓**重新量一次。

| 关系 | 硬条件示例 | 软评分示例 |
| --- | --- | --- |
| 几何与层级 | 必须压在底纸上、标题安全区不可被遮住、胶带必须跨所连接的纸边 | 交叠面积、露边宽度、角度呼应是否接近模板 |
| 颜色与纹理 | 仅对明确要求分层的重叠纸，禁止两者最终可见边界完全无法区分 | 重叠面积较大时奖励清楚的明度／色相／纹理差异 |
| 内容与阅读 | 文字不得被主素材遮挡到不可读 | 相邻题材呼应、双页配色对照、对角／折线的视觉节奏 |
| 同源裁片 | 来源区域不得重叠，合计必须能从同一实体剪出 | 同源纹样连续性、合理的切口和剩余面积 |

“两张大量重叠的纸不能同色”应表达为**可辨性规则**：先确认该关系是否要求两张纸被看成不同层，再比较露出的边、明度、色差和纹理。颜色相同但有足够边缘／纹理差异可以合格；颜色略不同却几乎融成一片应受罚。这样比一条全局的“同色拒绝”更接近真实案例。关系检查只在其两个槽位都有候选时发生，不能由单槽位评分提前猜测。

## 四、同一素材填多个槽位：联合裁片候选

把“同一张大纸裁成两片，放在两个位置”视为**一项联合方案**，而不是两个可独立取用的素材。`CompoundOption` 带一个来源单位、2 个（必要时更多）槽位、每片在**来源坐标**中的几何与各自摆放位置、一次切分的成本及余料策略。

面积之和小于原纸面积只是必要条件，**不是充分条件**：两块 70 × 70 mm 正方形总面积小于 100 × 100 mm 纸的面积，却无法同时排进这张纸。必须检查每片边界都在源纸内、彼此不重叠、裁后仍满足各自槽位的真实尺寸和内容安全区。候选生成先尝试简单的横切、竖切与少量从槽位尺寸推得的矩形区域；不遍历连续坐标，也不默认把照片、印字卡或人物切开。需要复杂非矩形切口的模板须显式声明，之后由现有几何内核验证。

联合方案与“整张纸给槽位 A”“整张纸给槽位 B”互斥，因为三者占用同一来源单位。选中后编译为**一次** `material.split`，每个 `pieces` 带来源 `region`、自己的 `place` 和 `order`；未用余料按 `keepRemainder` 进入暂存区。数字纸使用 `layer.split`。原始毫米尺寸、来源占用与区域不重叠都必须由画布事务再验一次。现行 D153 同源胶带切两处是这一能力的模板特例，迁移后应由通用联合方案表示。

## 五、整页分配：统一的带约束优化

对固定模板，先生成单槽位选项、少量有价值的联合裁片选项和默认选项，再选择选项集合。分配必须满足：

- 每个槽位**恰好被一个选项覆盖**；联合方案一次覆盖多个槽位。
- 每个普通实体来源单位至多被**一个选项**占用；联合选项内的裁片共享该单位且来源区域互不重叠。可重复取用的预设与胶带遵循其明确库存规则。
- 用户标记的“必须用”素材在初稿获得更高选入优先级，但不适合现有槽位时可先不进入画布；未用素材必须保留在候选素材／待放区，供后续编辑。最终提交时才要求所有必用素材实际可见。“可以用”没有强制选入要求。
- 所有已选择选项之间的硬 `Relation` 成立；编译出来的纸层、文字安全区与真实尺寸可执行。

在可行方案中比较统一目标：

`整页质量 = 加权槽位适配 + 关键相邻关系 + 整页配色／构图 + 适度的可用素材覆盖 − 裁切损耗／复杂度 − 重要位置的默认替代成本`。

先满足来源、物理尺寸、裁切安全等硬条件，再比较上述质量；最终必用素材获得较高但有限的初稿分数，不能用大量小点缀的数量抵消主图错误。可用素材覆盖采用**有上限、边际递减**的奖励，每个来源单位只算一次，联合裁片虽占两个槽位也只算使用了一件素材。用户没有要求全部使用时，留下几件不合适的素材可以是最优结果。所有模板用相同权重口径与归一化方式，跨模板才可以公平排序；不要再把一批模板的平均分与另一批模板的“填满比例”直接混用。

输出 `AssignmentPlan` 至少包括：每槽选项、来源单位／裁片坐标、默认对象、关系得分、整页分数分解、未用素材及原因、匹配版本。编译初稿时，把全部未用素材加入待放区；必用缺项只作为待完成状态，不让初稿失败。默认图层顺序与模板关系由编译器生成，替换物不自动跳到最上层。

## 六、求解与速度

目标规模是**几十个模板、十几件用户素材**，不能把完整几何搜索和所有裁切组合都在主线程上做一遍。

1. **一次画像，多模板复用**：素材角色、物理尺寸、可见轮廓、主题与颜色特征按素材修订缓存；模板槽位和稀疏关系图预编译。页面筛选（单页／双页）先于评分。
2. **便宜的全模板初筛**：全部模板都做单槽位硬条件与基础评分，不生成复杂裁片。由“每槽最佳可能分 + 所有关系／覆盖的乐观上界”得到安全上界；已经不可能超过当前最佳的模板可以跳过精算。先给用户可用的初步推荐，不阻塞页面。
3. **精算有希望的模板**：只对可能进入前列的模板产生联合裁片、计算相邻关系和完整分配。每槽保留少量高分且**来源、颜色、角色有差异**的候选，始终保留手选绑定和默认选项；被截掉的候选若仍可能改变最优结果，必须能按上界重新展开。
4. **单一求解器**：优先处理可选项最少或视觉权重最高的未覆盖槽位；每加入一个选项立刻检查来源占用与已形成的关系。小问题可穷举并证明最优；大问题用有上界的分支限界或固定扩展预算的确定性搜索，保留当前最佳可行解和未搜索完的上界。时间预算耗尽时如实标注“近似结果”，不宣称全局最优。
5. **后台与增量**：在 Worker 中求解，页面先显示缓存或初筛结果，再原位更新完整推荐；素材、模板或用户绑定变化时，只失效相关缓存。用户取消或切页要中止旧任务，不把旧结果覆盖新选择。

性能验收以实际中档手机和桌面浏览器测量。建议设定并验证：30–50 个模板、10–20 件素材时，首批推荐 **200 ms 内**可见，完整前列推荐的 P95 **800 ms 内**完成，交互期间主线程无明显长任务。这是**待实测的目标而非当前性能声明**。固定输入与算法版本必须得到相同分配和解释；搜索提前结束时报告预算与质量上界。若目标不达标，优先减少重复画像、几何枚举和非相邻配对，不能通过静默丢掉最终必用素材的候选记录、裁片方案或整页关系来伪装提速。

## 七、编译、解释与回归

匹配结果只引用单一 `TemplateSpec` 与现有画布命令。编译器按模板层级发出页面颜色、默认对象、`material.add`／`material.split`／`layer.mask`、文字和点缀操作；同批原子执行。画布验证若发现来源重叠、无法放置或文字被遮挡，则否决该分配并尝试下一可行方案，绝不保存半成品。

模板库点击一个对象时，展示其硬条件、软评分、通过／拒绝的素材及**具体失败码**；当前第一名未被整页采用时，展示被哪个槽位或相邻关系改变了选择。整页视图另列：每件素材的去向、同源裁片图、未用原因、默认对象、关系检查与总分分解。右侧说明必须从**同一能力定义、候选和求解结果**生成，不另写一套可能漂移的自然语言规则。

迁移按以下顺序进行：

1. 给现行 14 个模板建立同一数据合同；保存当前默认图、真实素材初稿和每槽解释作为比较基线，不把既有匹配分值直接当新算法标准。
2. 先用统一候选／分配器覆盖不裁切情况；所有模板仍能生成可编辑默认图，手选绑定与必用素材有明确结果。通过后删除三套旧的分配循环。
3. 加入联合裁片选项，先覆盖纸张和 D153 同源胶带；用真实来源账本验证两片、余料、再次取用拒绝与事务回滚。
4. 加入稀疏相邻关系与跨页评分；逐模板对照未经裁剪的原案例及真实素材初稿，确认层级、交叠、颜色、文字和尺寸。必要时调整模板自身量测或关系，不在求解器里写案例 ID 特例。
5. 运行性能基准、手机／平板／桌面验收，再开放统一算法推荐。未来新模板只提交 `TemplateSpec`、默认编译和独立验收证据，不再新增第四套匹配器。

自动测试至少覆盖：同类型但尺寸不合格；两张重叠纸颜色融为一体而候选各自单分很高；两槽争同一件素材；一张纸两片面积足够却几何装不下；成功分片且来源不重叠；重要主体不可裁；必用素材无法放置；可用素材留空比硬塞更好；默认对象完整；30–50 模板性能。视觉测试仍须按每张模板的真实原图和真实素材逐页验收，算法分数不能替代审美检查。
