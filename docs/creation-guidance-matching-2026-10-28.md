# 创作方法、内置预设与搭配改进（2026-10-28）

## 范围与架构

继续使用唯一 Scene v2、统一 Command、当前 Canvas 真渲染与来源/物理尺寸校验。没有新增模板引擎、视觉参考图片库、并行存储格式或网络搜索服务。公开创作包只包含方法提炼，原作者图片和用户素材仅留本机验收目录。

### 教程研究及覆盖边界

延续已有学习档案，本轮补查三个原帖：

- [水岸芝芝：拼贴排版](https://www.xiaohongshu.com/explore/6963484c000000001a029e01)：抽查约 176 秒视频的关键画面；局部平行边、差异露边、字图层级与色彩呼应。
- [阿勒好多塔：照片与文字](https://www.xiaohongshu.com/explore/6a075e570000000008025713)：抽查约 384 秒视频；按照片/文字多寡分配图文重量，少量照片也可充当局部配角。
- [阿C：电子手帐排版](https://www.xiaohongshu.com/explore/6930201b0000000019024d27)：实际观察 11 张图中的 1–4；局部照片组、编号、关键词、形状变化组织阅读单元。

这些是关键帧/部分图文观察，不是完整看完所有教程。已将时间点、来源、观察与推论的区别保存在本机教程资料库，另保存两张实际加载的原图。不复制作者模板、原素材或以教程数量证明质量。

### AI 自选预设

搭配页新增默认关闭的开关，沿已有本机 session 与账号设置同步。开启后按任务排序选最多 6 件、每类最多 2 件胶带/贴纸/印章；排除项不进入包，手动选择优先。自动补充项始终 available，即使“全部候选必用”开启也不强制使用。普通推荐最多 18 件，UI、API 和 ZIP 共用同一个 scope，修复 UI 只显示 18 件而导出可能带上全库的问题。

只打包本次选中预设的 PNG 及已有元数据，运行时与素材库共用资源。测试两包自动预设原图分别约 98 KB / 103 KB；整包约 4.92 MB / 4.40 MB（十进制）。不包含全部 27 件预设。

### 搭配排序

内容匹配不再把 paper、sticker、focal、和纸等泛标签当成主题。使用已有标题、内容/语义标签、补充想法、颜色、素材职责和物理尺寸做本地排序；候选前部抑制同类重复。实体超过单页可用尺寸时给出裁取提示，不自动缩放。

这仍是元数据启发式，不是多模态检索模型；匿名素材/缺少标签时判断能力有限。同一输入结果确定，不用随机变化伪装多样性。

### 双页与帮助

TASK.page.regions 给出物理毫米安全区，正常 B6 中缝两侧各 5 mm，窄页按比例缩小；左右页内先组图文，跨缝用颜色/方向呼应。真实 Scene 的 design-check 使用嵌套旋转后的世界边框列出靠缝/跨缝对象。只作建议，不裁剪、移动或缩放用户内容；透明空边/蒙版可能误报，要看 PNG。

补充 patterns / spread 方法、图文多少分支、词组层级、局部平行边。入门页明确检查真实可写面与印刷标题的职责，并在浅层 describe 中明示 at 默认按对象中心定位，减少坐标修复成本。

## 真实创作验收

使用用户已有识别素材，以正式 createOfflineHandoff 生成包；独立 agent 使用 gpt-6-sol / medium，不手写 Scene 或辅助绘图程序。

| 案例 | 结果 | 观察 |
| --- | --- | --- |
| 8 件真实素材 + 6 件可选预设 | 首轮约 4 分钟；复盘后结构精修约 3.5 分钟。真实裁取 Future 标题，票面写字、扣子圈注、咖啡与文字对应 | 首稿仍是过大完整矩形；技术通过没有保证设计。精修后仍有较多上方留白和水平胶带，不能宣称彻底解决 |
| 3 件真实素材 + 6 件可选预设 | 冷启动约 3–4 分钟，3 次真实 PNG、2 次修订；188 字原创随想；选用 1 件预设；无中缝几何提示 | 左右页叙事有差异，保持尺寸；仍偏疏朗，局部交错、文字层级可以继续提高 |

两组都经 review / pack；正式导入器重新导入成功，Scene v2、物理尺寸与结构检查通过。JSON 单独导入仍如实标为 preview unverified / reading pending：外部看过 PNG 不应伪造应用内视觉验收。真实 PNG 已由主 agent 独立打开审查。

用时是这两次运行观察，包含复用本机 Canvas 依赖，不是跨模型或干净环境性能保证。一次 place.rotation 错字段和一次错误 describe 主题调用被拒后修正，不能宣称零摩擦。
