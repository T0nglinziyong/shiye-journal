# 基于真实 PNG 的交付判断

实际打开当前 output/preview.png 后再判断。check/pack 成功、思考耗时和修改次数都不能证明美观；design-check 只有框级几何提示，preview 的 pixelReview 也只粗略标出低笔触区，两者都不能替你看图。

`review pass` 是对当前 PNG 的完成态判断。若你自己仍能指出主标题压倒整页、某页纹样纸只有底纹作用、正文对比不足、或某件小素材与内容没有联系，就先 `review fail` 并局部修改；不能一边列这些未解决的问题，一边把技术可交付写成视觉通过。若本轮修改反而变差，回到更好的候选，勿为保留尝试而硬塞图层。

先缩看并用一句话指认每页的**主结构、跨素材的联系、贴近字句或实物的细节**。在“丰富层叠”中，至少实际预览一次含主图形关系的候选，再看另一页是否也有有用的圈注、笔迹或荧光；两页的回应不必同类同量。若只能指认“小圈、短线、高亮”，但两页仍是几块独立图片和漂浮文字，应继续改主块或连接；不要把这些小图形当成完成证据。`review` 返回的 geometryAdvisories 是待核对线索，不是自动审美判定。尤其检查荧光是否盖字、主图形是否真取自本次素材，而非只为满足图形尺度提示而放大。

若 TASK 选择“丰富层叠”且允许新增文字，分别在左右页指出三个真实可见的阅读尺度：远看主块、能连续读下去的书写、贴近具体实物或字句的局部发现。它们可以由原素材提供，不是三类命令的配额；但一页只有完整的大印刷标题、一个整洁文本块和远处一枚小贴纸时，还不能称为完成态。可写卡片大片空置、主要笔迹都离素材很远、所有新增字都规整地写在独立框里，也需要继续把文字和实物组织到一起。浅色圆形承载整段居中文字时，检查它是否像应用界面卡片；若失去手帐的书写感，改成偏置边注、纸边题字或有目的的局部色形。

## 1. 主结构：文字／图形／素材谁在组织画面？
第一眼能找到焦点和承托关系吗？标题、正文段、图形、材料大小是否有区别？只有一两件素材时，是否仍只贴它们并写两句小字？这时应让标题/段落/数字图形承担主要版式，而不是等待不存在的更多贴纸。

## 2. 文字：正常尺度能否读，形式是否有角色？
检查主文可读，长短块、字号、粗细、行距、左右/居中对齐是否服务内容。大印刷标题之外的所有文字是否都退化为同级小图注？艺术字只处理有意义的关键字；描边、渐变、阴影与字体选择须有区别，不能伪装为未实现的效果。文字内容不虚构，不为填空编经历。

## 3. 点缀与第二层细节：是否真正尝试丰富，而不只口头审视？
查看小素材、贴纸、胶带/裁条、数字图形、手绘和局部强调是否与主体有关系。主动尝试藏边、跨纸边、图案重复与变奏、手绘回应、旁注和不同尺度的色彩呼应。人物周围、标题旁、正文转折和纸片交界不必全都空着。缩图时先看图形是否参与主结构，放大后再看局部圈线/高亮是否指向具体字句或实物；只有粗箭头加一圈小物件仍可能是初稿。若仍像初稿或素材展板，继续细化；仅在实图中出现遮挡、拥挤、层级冲突时撤掉具体元素。没有数量配额，也不为不愿动手找“克制”的借口。

## 4. 空白与重心：不能把未完成叫留白
除非明确的极简/大留白需求，逐一检查大块空区。它是边距/停顿、主体轮廓需要，还是素材太少/正文太小/布局松散造成？后者必须重排；优先补文字层次或主图形、调整主块，而非在四角机械加星星。整页应充实但不堵塞，行距与可读空隙仍保留。

特别检查画布纸面的空白：它可以直接承载随写、旁注、线形和局部高亮，无需先贴一张纸。若文字全在单一卡片，而另一页大片画布无内容，先移动文字或重建阅读聚合，再决定是否补图形。

分别看两页与整体。深色、面积、字多段落和大标题都具有重量；不能用左右相同数量或固定 Z 模板冒充平衡。颜色在区域间呼应，近似色也要拉开深浅；亮色只在关键处承担作用。
若真实 PNG 的一页已经有穿插的主块，另一页却只剩一件整卡、单个规整段落和大片纸色，不要把前一页的完成度算成整幅完成。先让较轻的一页出现与本批素材有关的可读随写，再选择一两处真实细节做圈注、短荧光或轮廓回应；每个新增元素都应能指出它对应的物件或字句。相同的手绘语言可以在两处不同实物间变奏，形成呼应，而不是只画一枚圈后停止。`pixelReview` 的两页差异只用于提醒看图，不是填色目标。

## 5. 边界与收尾
放大检查字形/换行、重要遮挡、误跨中缝、真实材料边缘和来源。整张纸片横跨中缝时，想清楚它是否真的要贴成跨页折条；若只是为了填满两页，应改到一侧并在另一页建立独立的书写关系。看每张叠放纸片是否留有辨认其材质或轮廓的边，书写面是否真的可读；若把纸片称作书写面，检查文字、圈注或笔迹是否真正使用了它，而不是只在纸片外解释它。遮住主角面部、印刷字或纸片全部边缘的叠压须重排。新增元素全在可编辑 Scene 中。只有旧预览时不得 pass。

缩看配色：能否分出大面积主色、相近色的明度层次与少量强调色？圆圈、编号、胶带和高亮是否落在具体的阅读节点，而不是平均撒在空位？这只是看图问题，不设固定色数或装饰数量。

再看纹样纸与印刷字卡：大纸若只贡献底色和图案，应缩成有用的局部、与正文叠压或让图案中的具体细节得到圈注回应；大字卡若吞掉其他焦点，应调整它的面积、露出方式或周围正文的视觉重量。不要仅靠在两者旁边摆一行小图注宣布完成。

素材本身若是手机截屏或设计模板，检查工具栏、键盘、状态栏等界面痕迹是否抢眼；它们若与本页表达无关，可合法裁取或让其他纸片遮住，再把省下的位置用于真实观察或随写。保留有意义的素材内容，不为掩盖界面而伪造实物。

每轮留下简短结论：主结构状态；文字可读性；点缀选择；最大空区用途；还需改的具体对象。可记录在 work/design-notes.md，但不复制一整篇分析。发现明显问题就用新事务修正；没有新问题就交付，不为凑轮次继续堆元素。记录必须如实区分“已看真实 PNG”和“只执行了结构诊断”。

快速判断时先缩看整幅：第一眼是否有主角，第二眼是否能读到具体内容和素材间的关系；再放大查书写面、露边、遮挡和高亮落点。只修正这轮发现的具体问题。素材少时重点看文字与现有纸面的互动；素材多时重点看主次及局部聚合，避免等大陈列或同心叠放。参考真实手帐的手写、贴压和局部标记，但不要复制案例中的句子、贴纸位置或固定装饰数量。

特别检查两种容易漏掉的失败：一是现成印刷标题夺走大半视觉重量，新增正文只剩小图注；二是文字反复说“先写、下次再写、留给以后”，却没有展开这批素材引出的具体观察、态度或问题。这些句子有时确实成立，但不能成为未完成页面的挡箭牌。若 PNG 仍呈现大矩形左右并排、可写面闲置、重要正文对比不足或高亮只圈了无关空处，应记录 `fail` 并修正具体对象；不能仅凭技术验收声明 `pass`。

局部复核再看三件事：标题或正文若横跨两种深浅不同的底色，整句是否始终可读；标题、实物上的字、正文是否重复同一个念头；圈注与批注是否贴近所指物件，线条是否真的把两者连起来。先改这些可定位的问题，再考虑增加新图层。
