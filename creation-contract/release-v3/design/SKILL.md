# 手帐创作 Skill：结构 → 内容 → 点缀 → 视觉闭环

适用于初稿和精修。文字、图形、素材都参与构图；任何一种都可以是主体，不把数字图形或文字固定成贴纸的附属。以 TASK 的主题、文字策略和加工权限为准。纯拼贴不新增正文，不凭空添加用户经历。

## 一、判断资源与版式重心
看真实原图而非只读 metadata。关注可写面、印刷字、人物朝向、空边、图案和深浅；按页面显示面积而非图片像素判断材料大小。

- **素材丰富**：先用主要材料确定层次和风格，给正文和次级信息留实际位置；小材料后加，不让每张完整纸都同样抢眼。
- **素材稀少或视觉很轻**：由大字标题、正文块、矢量/色块/线框建立骨架；小贴纸成为锚点或呼应。不要孤零零贴一件素材、写两句小字就交付。
- **文字很多**：先按主题分段，块内采用统一左/右/居中对齐，块间错落，用标题、字号、笔重和段落形态形成层级。行距不是越紧越省地；读不清先重排。
- **已有大印刷字**：把它纳入主重心；周边正文与图形仍需有重量。新增标题不必同义重复，但允许短回应或艺术字成为次焦点。

先用 3–5 句确定主块、正文、点缀职责及阅读路线即可，不写长分析。比较的是图文关系，不只是交换左右或转几度。必要时只做轻量结构试排；不要同时精修两个完整方案。

## 二、先主块，再内容和关系
“大”是视觉重量，可来自大图片、大字、密集段落或深色图形，不等于只能先摆实体素材。先稳定这些重块的位置与方向，然后共同完善正文和材料关系。

背景／打底纸／文字区／上层元素之间要可见地互相承托。试着让短句、数字、图案或人物跨过一处纸边；不让所有对象都被关在自己的矩形里。斜贴的同组保留部分平行边，避免随机旋转。跨边不能遮掉脸、重要印刷字或误伤中缝。

文字不只有一种形式：连续正文、短插话、列表、横竖向标题、大小字搭配、单字强调、曲线标题都可按内容选择。长正文优先完整可读；艺术处理优先用于一两个关键字/短题，不把整篇正文做成混乱字样。字体与字效分开选择：描边、阴影、渐变、偏移轮廓各有不同作用。

## 三、独立进行点缀设计
主结构初步成立后，必须做一次细节判断，不因“按需使用”而默认省略。候选包括：小素材/贴纸、许可的胶带或窄条、数字几何、手绘图案、关键词高亮、局部背景、短字与编号。

每处保留的点缀至少承担一个作用：连接两区域、回应某句话/素材、强调、改善方向、补足重心、制造局部细看价值。可以把小圆部分藏在纸后、把色条穿过两个区域、把手绘呼应放到词旁；形状可来自素材里的纽扣、花、星芒等，不固定每页撒点。

若同一页已经层次丰富，点缀审视可以决定删减或不新增。理由必须针对实际画面，不能一概用“简洁”替代判断。没有素材来源的实体胶带不可虚构；数字色带/图形可以独立使用。

## 四、充实而不堵塞：处理空白
除非任务明确要求极简或大留白，默认追求有内容支撑的中等偏充实。检查上半部、下半部、左右页与材料内部有没有大块无作用区域。

- 空洞来自主块太小：扩大**数字文字/图形**、改变版式、移动材料；不能放大真实素材。
- 空洞来自没有内容：在原意与事实允许内展开表达，或用图形/插画担任主体；不编造事件、日期或用废话凑满。
- 空洞来自材料间完全隔离：调整距离和叠压，建立跨元素连接，而不是放十个小圆点。
- 边距、段间呼吸和主体周围的停顿应保留；不能用机器覆盖率当审美 KPI。

## 五、实际预览、局部修正
看当前 PNG：第一眼是否有明确主次？正常尺寸是否能读正文？第二眼能发现关系和细节吗？字体、色块、素材三者谁承担主要重量？有没有过大无作用空白？

使用 design/REVIEW.md。可用 design-check 辅助寻找框级空区和字号过于接近的问题，但它没有看懂图像。把发现的问题合并为少量明确的局部 Commands，再预览。不要把长时间思考、修改轮数或操作数当成设计成果。

## 默认字体与周边图形
新建文字默认艺术手写，不再默认普通宋体。标题/单字可用不同艺术字体和描边、渐变；长正文保持可读而非堆满效果。离线先 `fonts` 查询实际字体，未安装的名字不等于已获得字形。

主体构图后专门看一遍周边：人物肩侧、标题角落、纸片接缝、段落结尾是否适合有意义的圈线、星星/闪光或少量圆点？从本页的纽扣、星芒、花朵、话语中提取形状，轻重/大小有区别，不围着所有对象撒一圈。`draw.decorate` 的 circle/star/sparkle/dots 可直接依目标放置，仍是可编辑笔迹；完整填充图形用 `shape.add`。没有需求可以不用，但不能因为不知道如何计算坐标而全部跳过。
