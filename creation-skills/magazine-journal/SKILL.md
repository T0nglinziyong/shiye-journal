# 杂志式图组

先读照片的共同主题和本次已有文字。照片是内容主体，标题、图案和小标签帮助建立阅读节奏。不要把所有材料都变成同款卡片，也不要靠英文长句制造风格。

## 构图步骤

1. 从照片里提取主色倾向，选已有纯色或低干扰底纸。背景应让照片显出层次，而不是再增加一个竞争主体。
2. 选一张在实际尺寸、主体和细节上适合作为重点的照片。其他照片围绕内容关系分组，局部错位或叠压，并保留能辨认主体的区域。
3. 在组的边缘加入相关的小物、植物线条或标签；至少有一项语义或颜色联系。没有适合的装饰就留白。
4. 标题和短句落在图组间的空区。用户有具体事实时准确表达；不要复制教程的季节、日期、英语语句或旅行经历。

`magazine-light` 展示浅底照片群、局部半透明层、短标题与小装饰的关系。它是结构参考，不能照搬素材数量、比例或坐标。深底案例采用浅线条和浅文字；实际页面根据背景重新检查对比。

## 拾页实现

先查询 material.add、place、text.add、graphic.add 的合同，成批放置基础图组，再依据自动预览修改。实物照片保持真实尺寸；教程数码拼贴中的任意缩放、复制、镜像不能直接采用。可以通过留白、选材和合法裁切调整视觉主次。关于跨页内容组织可读取 `photo-story`，关于文字可读取 `journal-lettering`。

停止条件：主照片明确、辅助照片有内容关系、文字可读、装饰没有形成第二个拥挤中心。不要以增加贴纸数量作为改进。
