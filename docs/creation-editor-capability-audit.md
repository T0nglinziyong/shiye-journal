# 创作能力在编辑器中的可达性（2026-10-26，进行中）

目标是让 AI 创作结果能在界面继续编辑。Schema 中存在字段、面板出现控件、模型执行测试通过，均不能单独证明界面可用。需核对选择对象 → 修改 → 实际显示 → 放弃/完成 → 重开。

## 已修复：笔迹属性

`EditorPage` 能补充查找笔迹并显示检查器，但 `app.js` 写回和效果操作用 `editorEntry(...ink:false)` 找对象。透明度因此没有作用，绘制效果落入“新文字默认值”分支。

- `editor-inspector-model.js` 让面板与写回共用选中对象查询，包含局部组合中的笔迹。
- 增加颜色、毫米粗细、五种笔型、正常/正片叠底；透明度和轮廓、渐变、阴影真正作用于选中笔迹。
- 共用 Scene 属性内核与隔离编辑会话，保留压力点、来源和布局关联。不能把笔宽误当图形框宽度，也不逐次把滑块预览提交云端。
- 浏览器发现颜色控件仅更新输入值而未提交。颜色字段改用原生 input 事件；以保存重开后的颜色作为成功证据。

## 验证

- `editor-ink-inspector.test.js`：嵌套组、毫米转换、压力点和 linked 保留、非法参数/锁、隔离会话、保存重开和实际 Canvas 图像变化。
- 真实 Chromium 在隔离 browser-test 站点用指针画笔迹，再从图层树选择；修改颜色、粗细、笔型、透明度、混合和渐变描边，保存重开确认；另一次修改放弃后粗细恢复。
- 390×844、768×1024、1024×768、1280×900 无页面横向溢出。截图和 DOM 记录保存在本地研究目录。真机 Safari/Pencil 未验证。
- `ink-inspector-browser.mjs` 将同一路径加入 Interface Browser CI，增加 IndexedDB 保存断言。本轮通过 CUA 执行浏览器流程，该独立 CI 脚本待远端运行。
- 全量 1483 项（1482 通过、1 跳过）；UI/路由、生产构建和 CloudBase 配置审计通过。
