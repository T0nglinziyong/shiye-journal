# 创作能力在编辑器中的可达性（2026-10-26，进行中）

目标是让 AI 创作结果能在界面继续编辑。Schema 中存在字段、面板出现控件、模型执行测试通过，均不能单独证明界面可用。需核对选择对象 → 修改 → 实际显示 → 放弃/完成 → 重开。

## 已修复：笔迹属性

`EditorPage` 能补充查找笔迹并显示检查器，但 `app.js` 写回和效果操作用 `editorEntry(...ink:false)` 找对象。透明度因此没有作用，绘制效果落入“新文字默认值”分支。

- `editor-inspector-model.js` 让面板与写回共用选中对象查询，包含局部组合中的笔迹。
- 增加颜色、毫米粗细、五种笔型、正常/正片叠底；透明度和轮廓、渐变、阴影真正作用于选中笔迹。
- 共用 Scene 属性内核与隔离编辑会话，保留压力点、来源和布局关联。不能把笔宽误当图形框宽度，也不逐次把滑块预览提交云端。
- 浏览器发现颜色控件仅更新输入值而未提交。颜色字段改用原生 input 事件；以保存重开后的颜色作为成功证据。

## 本轮补齐：跟随对象

- 文字、图形、笔迹、实物素材检查器可选择页面、左右页、所在组合或其他图层作为位置参照；支持保持当前位置、上下左右、居中、毫米间距和跟随旋转。
- 文字、图形和笔迹可绑定宽高比例。实物素材不开放持续缩放，保留物理尺寸规则。
- 可独立解除位置或尺寸关联，解除保留当前外观。沿用隔离会话的完成、放弃和撤销；不新增 Scene 格式或云端请求。
- 当前原生 UUID 可能以数字开头：可执行 Command Id/Reference 与 linked size 验证现已接受原生编号，仍拒绝路径、空格等非法字符。静态候选合同不替代可执行的运行时合同。
- 真正拖动暴露并修复了显示缺口：内核已更新跟随图层，但普通 Fabric 单对象变换仅记住当前签名，未刷新其余变更。现在拖动提交后立即按签名增量重绘跟随对象，无需打开面板或刷新整页。

验证：`editor-layout-model.test.js` 覆盖嵌套局部坐标、原生 UUID、保持位置、参照移动/旋转/尺寸、手动偏移、循环回滚、锁定、实物尺寸限制、保存/放弃/重开及非法编号。真实 Chromium 操作创建色块和椭圆、绑定右侧 2 mm、宽高 50%、保存重开、解除后放弃，以及指针拖动参照后检查两个对象的真实画布位置。390×844、768×1024、1024×768、1280×900 页面无横向溢出，面板位于视口内，控制台无错误。证据在本地研究目录 `shared-core-browser/layout-inspector.json`。

`fabric-stage-browser.mjs` 增加显示对象与 Scene 同步的回归断言。本轮实际浏览器操作由 CUA 完成；新增 CI 断言尚待远端运行。此次未把持续拖动中的跟随预览、组合整体属性或真机 Safari 验证标记为完成。

## 本轮补齐：组合属性与组内编辑

- 组合悬浮操作新增“编辑组合”，不再误显示第二套叶对象操作栏。
- 名称、整体透明度、混合模式、阴影开关/颜色/毫米模糊/偏移共用 Scene 属性内核，保留子对象独立属性。
- 面板可进入子对象并返回父组；在同一隔离会话中完成组与子对象修改，一次完成或放弃。切换对象重置表单和面板滚动位置。
- 有局部定位框的组合复用“跟随对象”；手工普通组合尚未自动建立定位框，此差异未被包装成能力完成。
- 直接解开带阴影组合会丢失组级效果，因此解组校验增加阴影保护；用户先关闭效果后可解组。

证据：`editor-group-inspector.test.js` 用双层局部组合与笔迹验证颜色、透明度、阴影、保存/放弃、锁定与非法参数回滚，比较实际 Canvas PNG 与重开 PNG，确认组外观更新不改写局部子对象和压力点。真实浏览器从空白作品添加两个图形并编组，修改组和子对象、完成、重开、放弃；核对颜色值、组名称、透明度和阴影毫米值。四视口及长组名无横向溢出；子对象切换后 scrollTop=0，控制台无 error。测试站只用隔离本机空白作品，不访问私人素材。

`group-inspector-browser.mjs` 已接入 Interface Browser CI，另有 IndexedDB 暂存与保存断言；本地实际交互由 CUA 完成，该新增 CI 脚本尚待远端运行。真实 Safari/Pencil、多层局部组的完整浏览器交互和组级遮罩一致性仍需验证。

本轮门禁：1490 项（1489 通过、1 跳过、0 失败）；UI/路由 7 视口、生产构建与 CloudBase 配置审计通过。既存 chunk 大小警告仍在。本轮尚未部署。

## 本轮修复：跨组关联与空间组后续编辑

- 图层改换父组时保留当前世界位置、旋转和尺寸，同时把 parent 尺寸比例换算到新父组；位置关联更新偏移，之后继续跟随新父组。文本保留原先请求的最小高度，不把排版溢出的实际高度误当成新约束。
- 空间编组、解组复用上述重绑定；无有效定位框的目标在结构修改前拒绝。空间组的自动定位框改在父级坐标中计算，包含笔迹，不再由 Command 层重复计算。
- 更换纸张时，整页平移只应用于根坐标，嵌套局部坐标、组定位框及文字最小高度按物理比例转换。
- 真实浏览器发现并修复 `GraphicEffectPreview` 对世界坐标代理直接 structuredClone 导致的 DataCloneError。预览现在先提取值再深拷贝，效果预览不修改权威 Scene；组内图形可打开、应用描边、保存和重开。

验证：`scene-parent-change.test.js` 的 7 项回归覆盖旋转父组换入/换出、父级比例、显式图层跟随、文字溢出高度、失败回滚、真实 Canvas PNG 前后及重开字节一致、嵌套纸张转换和代理图形/压力笔迹预览。全量 1497 项（1496 通过、1 跳过、0 失败），UI/路由 7 视口、最后生产构建、CloudBase 配置审计通过。既有 chunk 大小警告仍在。

真实浏览器通过 JSON 导入合成空间组，使用图层树拖动圈注到另一旋转组；位置保持，检查器返回父组为“右侧纸片”，宽高比例正确显示 31.25% / 28%。应用描边后完成、重开保留效果。390×844、768×1024、1024×768、1280×900 无页面横向溢出，面板在视口内。修复前的错误日志保留为问题证据，修复后同一路径未新增 error。本机证据：`教程方法创作验证-2026-10-26/shared-core-browser/parent-change.json` 与 `parent-change-mobile.png`。
