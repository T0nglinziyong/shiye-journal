# 创作方向与表达

## 搭配页面

四项方向与页面模式、纸张规格合并为三列两行，手机也保持同宽控件。第一行视觉风格、画面疏密、文字内容；第二行页面用途、页面模式、纸张规格。下面是可空的“补充想法”；纸张仅使用现有预设，不再展开自定义宽高；已有作品尺寸保持原样。方向选项与标签均为四字。

- 视觉风格：随材而定、清新淡雅、美式拼贴、复古旧物、日系文具、童趣可爱、杂志排版。
- 画面疏密：自动安排、疏朗留白、均衡编排、丰富层叠。
- 文字内容：灵感随写、日常记录、纯粹拼贴。
- 页面用途：自由创作、清单计划、主题封面。

各项第一项为默认值。移除素材加工和文字表现控件及其云端/本机偏好恢复入口；新任务固定自由拆解和 mixed。已有作品的真实图层不修改。失效方向值重新选择当前默认，不转换旧格式。补充想法与素材篮仍仅保存在本机；方向设置按账号同步。

设置不再提供“创作方式”选择；应用内 AI 统一使用可编辑工具流程，原生工具与 JSON 调用协议由模型能力与连接配置决定。旧本机或云端设置中的创作方式不再影响执行，也不再写入偏好。网页包继续交付同场景的 JSON 与 PNG；最终 JSON 文件与复制代码块均为单行紧凑格式，字符串中的换行保持转义，字段不省略。

## 共同创作逻辑

`creative-content-brief.js` 决定内容边界；`creative-page-brief.js` 统一素材使用、加工、空间、文字、配色与看图复核。API 可编辑、API 图片与网页 ZIP 使用相同指导。网页 `web-creation-guide.js` 只补充工作文件、运行命令和交付要求。

灵感随写可以表达第一人称态度、疑问、愿望、俏皮对话和未完成想法，不声称用户经历了未提供的事件。日常记录保留零碎事实与原有口气，缺事实时少写；纯粹拼贴不添加文字，原素材印刷字保留。反复报颜色、通用治愈口号、英文页脚与逐件说明不作为默认内容。

`journal-case-study.js` 根据素材角色、语义和比例选出构图方法；相同方向下，字块、异形贴纸、食物照片、票据和可写纸片得到不同候选。元数据只是低成本线索，AI 仍须观察真实图片，确认可写区与印刷内容。候选参考不保证成品审美，模型需要比较两种图文关系并看最终画面修订。

先确定素材职责，再决定是否剪裁、开窗、叠压或完整使用。长、中、短文字版本只用于内部取舍；按真实空间选一种，不同时贴上去、不无限缩字号。参考模板不能覆盖素材本身。多样性来自主次与图文关系，不靠随机角度或额外模型调用。未引入新的网络识别或后台数据库查询。

## 表达复核

灵感随写需要让想法有所展开，段落、对话或连续边注均可；不把“轻松”解释为每页几句口号。先观察素材轮廓、朝向、印刷字与空白，结合表达构思书写空间，再共同调整素材位置、加工和文字长短。不先陈列大素材再给文字找缝，也不先划固定正文框强迫素材让路。数字图形、图案和笔迹参与同一次构思，用于引导、回应、强调或节奏，作为独立可编辑图层；没有作用就省略。所有素材被标为 focal 不能替代本次看图后的主次判断。无需强制裁切数量、装饰数量或字数配额。

工作台 scene-summary 与交付清单输出本次实际正文摘要，便于发送前对照图片核对。它不自动判断文案质量，也不能控制外部 AI 最后选择哪个聊天附件；只有同一场景的最终 PNG 与 JSON 才是有效的一对交付物。

## 数据与验收

仍使用 Scene v2、同一工具/工艺合同和固定素材版本。不能放大实物、重复用普通来源区域或伪造未拥有素材。复杂工艺是可选表达手段，不设数量指标。纯图片模式明确是快照。

网页可编辑任务仍须同时交付 JSON 与同场景 PNG，由 Node Canvas 预览，无 HTML 依赖；沿用来源指纹、几何、逐件取舍与预览摘要核验。手工创作继续编辑同一对象树。

自动测试覆盖当前四项选择、失效偏好、账号隔离、三种内容策略、素材驱动参考差异、各路径提示一致与 ZIP 合同。响应式测试覆盖手机、iPad 横竖屏与桌面。真实模型的表达质量和实体 Safari/Pencil 仍需实际作品与设备验收，不能用提示词断言替代。
