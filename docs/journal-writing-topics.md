# 手帐内容选题与正文写法

## 来源与观察

- 用户提供的《365天不重样的手帐主题》PDF 有 365 条连续编号。内容横跨感官观察、细小事件、关系、愿望、回望、清单和想象练习；按月份组织，但题目不必只在对应月份使用。程序保留全部题目于 `src/data/journal-writing-topics.json`。
- [手帐可以写的100个话题分享](https://www.xiaohongshu.com/explore/68a80e3b000000001c012b48) 把问题作为提笔的入口，正文说明这些题目是灵感，而非规定写法。
- [几种简单又有创意的日记法](https://www.xiaohongshu.com/explore/6afd0051000000002a00dbba) 列出 321、流水账、四象限等组织方法；说明短条目和结构化记录也是手帐内容。
- [每天可以写的n件小事](https://www.xiaohongshu.com/explore/69ba0c9d000000001f0004f3) 强调琐碎日常可成为记录对象。用作观察方向，不复制笔记的句子。
- [所以手帐写什么？](https://www.xiaohongshu.com/explore/6a5e33ae000000000f01e1ab) 展示了个人疑问、自我纠正和口语化叙述；手帐可以写尚未解决的想法，不必处处收束成结论。
- [通用的基础留白公式](https://www.xiaohongshu.com/explore/6a9faee90000000025036f4d) 明确提出素材少而精、间距与排列关系；据此在摆素材前先规划书写区，而不是最后填缝。
- [文字居多的排版技巧](https://www.xiaohongshu.com/explore/6a29267d0000000006023374) 与 [尝试用便签来排版](https://www.xiaohongshu.com/explore/67ecf1ae000000001d039306) 展示长文字和便签也能成为版式的主动部分。页面图示只提供布局启发，不复制原作。

## 产品实现

后台按素材名称、描述、标签、主题词和弱季节权重检索题库，给首轮模型一个主候选和两个不同写法的备选。随机扰动由任务开始时间确定：新任务可变化，同一任务恢复时选择稳定。模型可用 `search_writing_topics` 换题或搜索用户指定的词，工具每次最多返回八条；题库不会整体进入模型上下文。

`journal-writing` Skill 教模型把题目写成具体片段、观察清单、书信、想象、对话或回望。原创模式允许虚构天气、动作、地点和小事件作为作品叙事；用户事实与原文仍须准确，纪实模式不使用虚构片段。正文开局按预计素材占比给出简短、适中、展开三种暂定范围；每次真实渲染后再根据当前纸面素材占比更新建议，最终以可写区域和文字框可读性决定。标题、H2/H3 与正文分别安排层级，不把整段文字都做成装饰标题。

`journal-text-layout` Skill 与 `journal-composition` 在同一构图阶段使用。`creation_plan.writingZones` 记录标题、正文、边注所在的纸面或素材内部、预计容量与对比；同一段正文可通过 `flowGroup`、`sequence` 穿过多个书写面。`composition.layering` 记录底纸、上层素材、文字与局部装饰的叠放关系。真实 Scene 通过 `text.add` 的相对锚点及 `order` 实现文字随底层素材移动，自动预览审查文字与图层的先后、可读性及阅读路线。素材面积估算会扣除明确标注的可写区域，但仍要以实际图像为准。

## 验收重点

同一批素材应能选出相关话题，换一批任务应有变化；恢复同一任务不换题。零素材也应有可写切口。`visual` 和 `textMode=none` 不提供写作候选；`documentary` 排除想象型题目。画面密度提高时正文建议变短，但若最终留出充足书写面，模型需根据真实预览增加内容。不能把素材印刷字、题库题目或参考案例文案直接当成最终正文。
