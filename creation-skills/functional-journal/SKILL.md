# 功能记录与时间轴

先确认本页已有信息：用户给出的日期、事件、时间顺序和需要记录的条目。信息缺失时保留可写位置或使用不含具体时间的分组；不能从教程示例借用他人的日程。

## 简单骨架

有明确时间顺序时，可以用纵向轴连接若干段记录；同一时间段的信息放在轴的两侧，长短按真实内容决定。不必每条占相同高度，也不必画完整表格。

没有时间关系时，按主题分组，并用少量标题、短线和留白界定。日期、段落标题、正文只需清楚的层级。素材少时，文字、细线和有意义的小图形本身就可以形成完整页面。

所阅教程从日常物件外形提取纵轴，再把事件放在两侧。学习的是结构和信息顺序，原例中的日期、人物、食物与日程不属于本次任务。该原图没有完整拍入纸面，因此使用另一篇教程的 `tape-axis` 展示纵轴与两侧条目的关系。示意中黄色正文对比不足，实际创作应改用清楚的深色正文，不照搬配色。

## 图案与内容

小图形应对应事件或实际素材。简单轮廓、圈注和箭头适合帮助阅读；无法可靠表达的具体物体，宁可使用文字或现有贴纸。只为填空而添加许多无关图标，会破坏快速回顾的作用。

用 text.add、graphic.add 和已有素材搭出可编辑结构，日期和正文不烘焙进图片。预览检查记录顺序、字距、两侧对应关系与后续书写空间。能读清并能继续记录即可，不以装饰密度作为完成标准。

## 文字较多时

先按内容分段，再决定每段的素材与留白。三段式可以左右交替，也可以由页首横向素材引入，或由页尾便签收束；段落不必等长。可写区域与图案区域分别判断，不因素材叫便签就把文字覆盖整张。

`record-on-material` 接收已放置素材 `target`、可写的局部比例框 `box`、完整 `text` 和字号、颜色。文字跟随素材的位置与旋转，但不会为塞进框而删字或缩小字号。检查实际末行是否越界，必要时拆段或改排。想移动整个标题、纸片、正文组合时再使用现有组合工具。

装饰对应段落中的内容，在段首、段尾或图文连接处少量使用；不要给每段强加相同的花边。圈注、短线、数字和气泡可以从现有方法选择，保持正文的读序。
