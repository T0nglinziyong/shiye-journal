# 统一识别研究集成与验收

研究交接包保存在仓库外。五张私人照片、冻结 Mask 和合成真值均不提交 Git；本仓库只保存浏览器实现与复测脚本。

## 识别路径

默认设置为 `unified + auto`：整页候选调用研究 V8 的浏览器实现，逐件透明 Mask 调用研究 V5 的通用轮廓仲裁。候选和分割分别设置；显式选择 `legacy + morphgac` 可以回退。手动补框直接进入局部 MorphGAC，不重新执行整页候选发现。空 Mask 或失败不能作为成功素材。

研究包的五张真实案例先使用**人工确认的四角**校正，再冻结候选与 Mask。包内 `paper_detection.py` 明确是研究用简化纸角，未证明能在这五张照片上自动找准纸张。因此 App 保留提交 `2c0c72b` 的 800 像素找角器作为唯一默认实现，并修正白色区域碰到照片边界时四角被整批拒绝的问题：越界区域只能作线拟合起点，结果仍需通过凸性、纸张比例和四边对比检查。没有恢复旧版 400/1200 像素级联。

默认 JPEG 识别先用固定版本的 MozJPEG WASM 解码，忽略用于显示的 ICC 转换，按 EXIF 方向旋转，并保存原始整数像素作为后续校正的输入；画布读回不能重新改变识别像素。随后使用 `900×636` 或 `636×900` 校正分析图及 OpenCV4 线性插值取整。高清素材输出继续使用原图和现有画布裁切。旧算法的图像解码与手动操作独立保留。切换新旧候选算法时，会清掉该照片旧解码模式下的校正和候选缓存，重新识别。

候选阶段新增三条可解释的证据规则：只有四边梯度都有支撑才扩展模糊卡片；小型内部候选若被高质量、实心完整外轮廓包围则采用外轮廓；普通边缘失败的大载体才尝试保边滤波，圆形线索失败才尝试对比度增强。滤波不会直接把框当成透明 Mask，仍需逐件分割成功。

## 已验证结果

| 验收项 | 结果 | 范围 |
| --- | --- | --- |
| 五张实拍，研究四角 | 7、8、7、5、4 件；30/31 个透明 Mask 与冻结预测逐像素一致。第 2 张浅灰卡片由研究包的文字小框改成完整实体卡片 | 本地 Chromium，App `detectPaperCandidates` 路径；冻结预测不是人工真值 |
| 同一 JPEG 的像素输入 | 五张研究照片在 Node 与 Chromium 解码后的像素 SHA-256 一致；Chromium 重复解码两次也一致 | 固定 MozJPEG WASM；实体 Safari 尚未实测 |
| 用户本次上传的五张原图 | 7、8、7、5、4 件；无空 Mask | 与研究文件不同的 JPEG 表示，使用研究人工四角；第 2 张完整浅灰卡片是有意改进 |
| 分辨率、亮度、旋转、噪声、轻微模糊 | 每组五张的候选数量均为 7、8、7、5、4；噪声为半分辨率约 3% 混合，轻微模糊为半分辨率半径 0.5 像素 | 共 25 张派生图，研究人工四角按尺寸或旋转映射；数量一致不代表逐像素边界一致 |
| 五张实拍，网页自动找角 | 五张均找到四角；与人工确认纸面的 IoU 为 0.974、0.996、0.979、1.000、0.992；网页自动导入仍为 7、8、7、5、4 件 | 本地 Chromium 的完整导入界面；自动四角与研究人工四角不完全相同，因此不承诺自动结果的 Mask 逐像素相同 |
| 手机宽度预览与手动校正 | 五张均可拖动四角、应用校正，素材图无损坏且页面无横向溢出 | Chromium 390×844 模拟视口；不是实体 iPhone Safari 验收 |
| 12 张独立真值合成图 | 浏览器加权 IoU 0.7630、TP 38、FP 10、FN 12；研究基线 0.746664、TP 37、FP 10、FN 13 | 双方都在原图坐标按独立真值评估；浏览器使用 App 默认校正插值，和 Python 研究器仍有实现差异 |

真实五张照片没有独立人工逐像素标注。30/31 是**研究输出复现率**，不是实际识别准确率 100%；第 2 张的研究输出仅覆盖浅灰卡片上的文字，因此不能把逐像素复现当成正确实体边界。自动找角与研究人工角不同也会改变边缘像素。实体 Safari 的首次解码、性能及手势仍需真机验收。

更强模糊（半分辨率、半径 1 像素）仍会显著削弱一些极浅色边界：第 2 张的星纹纸可能退化为小块，第 4 张人物剪贴的轮廓需要人工复核。第 1 张极浅色中间卡片在另一种 JPEG 表示下虽识别为同一件，边界与研究冻结预测的 IoU 约 0.77，已标记为需要检查边缘。此类冻结预测不是人工标注，后续应建立人工真值再决定是否扩大滤波强度或调整边界。

## 重现

先启动本地测试站，再设置解压后交接包的根目录：

```bash
SHIYE_RESEARCH_ROOT=/path/to/research SHIYE_TEST_URL=http://127.0.0.1:5173 npm run test:research-real
SHIYE_RESEARCH_ROOT=/path/to/research SHIYE_TEST_URL=http://127.0.0.1:5173 node tests/recognition-decoder-parity-browser.mjs
SHIYE_RESEARCH_ROOT=/path/to/research SHIYE_TEST_URL=http://127.0.0.1:5173 node tests/recognition-research-import-ui-browser.mjs
SHIYE_RESEARCH_ROOT=/path/to/research SHIYE_TEST_URL=http://127.0.0.1:5173 node tests/recognition-research-synthetic-browser.mjs
```

第一个脚本验证 App 完整识别路径、30 个冻结 Mask，以及浅灰卡片的完整边界；第二个脚本验证固定 JPEG 解码器在 Node 与浏览器得到同一像素；第三个在网页中导入五张照片，断言自动找角、数量、手动校正及移动布局；第四个把预测 Mask 投回相机原图坐标，与研究包的独立真值按同一规则匹配。
