## 继续核查的能力

- 文字：旧 LETTERING 的整字描边、偏移轮廓、阴影、渐变与词组布局已接入。偏旁拆解、任意改笔画尚未实现；不能伪装为字体旋转。倪以七六种标题的全部七图和正文已核对，Skill 逐项区分排版可执行部分与笔画能力缺口；其他历史来源仍按各自阅读记录判定。
- 标题下划线：长标题使用最后一行的实际换行结果确定线长；旁注即使与标题同文，也不会被误认作标题正文。已用实际 Scene 事务验证，仍需在真实创作页面观察不同字体的视觉对齐。
- 关键词高亮与圈注：词组换行后按实际占用行分别生成可编辑的底色或细圈，行间空白不再被一整块装饰跨越。已检查长词组的本机渲染；不同字体的精确轮廓仍以实际预览为准。
- 图注与记录条目：组合高度改用 Scene 同一套确定性文字测量；长中文、英文和双栏条目以实际节点高度核对，不截字也不预留多余整行。已抽看更新后的清单、双栏和图文示意。
- 胶带：单段与双角示意现在含实际照片、纸片或便签，能检查覆盖关系；可为每段指定局部位置、角度和长度。组合边界包含旋转后的整段胶带，默认与整体旋转场景均以 Scene 几何核对，实体来源保持真实尺寸。

- 构图示意复核：原“三点呼应”的第三点与纸底近色，现用三种可辨色示意；“错栏图组”原与普通错落照片共用横排，现改为主图加侧栏，图注仅附主图。两项仍使用同一个按需加载的 `creation_recipe`，没有扩充顶层工具清单。
