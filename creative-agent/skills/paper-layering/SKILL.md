# 纸层与叠放

## 打底不是整页换底色

整页背景负责统一气氛；局部打底负责承托具体内容并建立层次。这两者可以并用，但铺一张几乎覆盖全页的纸、再把所有素材放在上面，并不能单独完成打底构图。先明确“这片纸承托谁、从哪边露出、与哪一片接合”，再决定纸的大小和层序。丰富层叠需要看得见的局部轮廓与穿插，不靠背景纸面积计完成度；也不要求每件素材各垫一张小卡。

例如，纹样纸从人物一侧和标题后共同露出，局部写面搭进这组纸边，另一片窄纸跨接正文与图像；这些关系可以由现有材料、裁片或数字纸组合。已有大纸可以保留，但应让局部纸簇承担不同内容，避免两页各铺一张满版矩形后就认为打底结束。整页铺纸在用户需要的风格中仍然合法，不统一限定覆盖比例或纸片数量。

## 何时读

需要决定哪张纸在下、露出哪条边、哪里能写、怎样连接两件素材时读本专题。打底是关系，不要求每件素材各有一张背景卡。已有纹样纸、可写卡、照片或图形都可能承担底层；标签不决定用途。

按用户疏密决定层次范围：疏朗页可把叠放集中在一个局部，丰富页可让几组纸层在整页呼应。人物主体、长正文或已有印刷标题决定哪些区域先保护。先大后小适合搭框架，从小簇向外扩展适合零散材料；不规定所有任务同一种顺序。教程照片中的桌面、笔、杯子和夹在本子外的道具不算纸面素材，拍摄透视也不等于对象本身需要旋转。

明确选择 `丰富层叠` 时，打底应能支撑教程所示的充实终态：大纸与小纸穿插、露边有变化、胶带或贴纸跨接，后续图文可以进入纸上、纸间和露出的原页。只有平铺几张分离矩形，或只有一处轻微搭边，不足以证明层叠目标已实现。阶段预留须说明后来由什么内容承接；完成态不能仍以“预留”为由保留大片无作用空区。层叠无需遮住可读正文，也不要求把整页先铺满底纸。

## 先分清纸层的职责

大纸可以成为很好的主承托，不必为了避免卡片感而全部拆小。丰富层叠中，纸片可以分别承担深浅衬托、图案过渡、局部承字和跨接：较深或有彩度的底层从主纸的不同位置露出；浅色或低密度区域保证正文可读；纹样片与图像、短标题交叠，改变主块的完整外轮廓。也可用同色系的深浅与纹样完成这些关系。按实际需要组合，不能一纸一职机械铺满。

数字纸若全是相近米白，增加纸纹通常仍不能让层序清楚。先看露出面积与相邻明暗，再决定是否需要深色纸、彩纸或印花片。黑纸、深蓝、灰、牛皮与鲜明彩纸都是常见纸材；不把“自然纸感”等同于统一浅淡配色。高彩度可用在局部，也可随用户风格成为主色。纹样纸可用 paper 的 grid/dots，或 graphic.add 的 stripes 等，纹样大小与真实素材协调。

## 做法

1. 看真实尺寸和图案密度，先摆承托层与主要素材簇。按最终露出的形状决定纸的尺寸与位置，不先为每段话生成一张完整卡片。底纸可以同时托住两件素材；小贴纸、题签或短胶带可跨在接缝上。底纸或主要卡片可以放正，用少数倾斜对象形成节奏。
2. 预留连续可读写面，正文可分段写在同一纸片的不同处、不同纸片、素材内部或原纸。深色纹理纸也能用浅色字承载正文，先检查纹理是否妨碍辨读；不用自动盖上浅色矩形。后放的纸不能盖住关键字、脸和原有标题。看 `creation_inspect.layerTree`，用 `layer.update.order` 调整前后；关联对象可先用 `group.create` 成组，再用 `layer.update` 移动该组。
3. 只有新纸层能改善承托、颜色、阅读或连接时才加。两页都铺同尺寸同高度的色卡易像展板，可变化露边、高度或承托类型。短胶带和细长色形有固定或连接作用即可，不必四角都贴。
4. 近看真实孔洞、撕边与透明度。实物只有一份：裁切、开窗与余料保留来源，不能重新 `material.add` 复制。照片主体与原印字优先可读；半透明层不应让正文失去对比。

完整纸需要分成几块时，可直接 `material.split` 的 `asset` 指定素材别名，在 `pieces` 中给每片的区域与位置，一步完成取用、分片和摆放。已经取用的图层则用 `target`，两个入口不能同时给。分片会撤下原图层，想同时保留的大块和小块都要列在 `pieces` 中。`keepRemainder:true` 将未列出的余料放到暂存区，不会把原大纸留在画面。分片沿用原层序；哪片应在前需随后用 `layer.update.order` 调整，不把库存别名填进 `target`。

缺少素色纸、简单纹样或文字贴片时，可重建相近的视觉作用：先保留色块比例、纹样疏密、透明度和露边节奏，再决定哪些细节可简化。不是把所有纹样都降成光滑矩形。`graphic.add` 可用 `grid`、`dots`、`stripes` 的 `geometry.options` 调整重复纹样，`washi` 表达撕口纸形；具体参数按需查询 `shapeOptions`，不必为每个圆点或每根网格线单独写一条命令。纹样和底形应同向、同框；刻意错位才分开。复杂插画或真实纸纤维不能用基础形状冒称恢复，缺少的印字在文字阶段用可编辑文字处理。

## 方法选择

`paper-color-card` 生成可编辑素色纸；窄纸条、错位打底和普通套叠用基础 `graphic.add` / `material.add` / `layer.update` 按真实画面试摆。需要准确露边读 `paper-peek`；裁切读 `paper-tear` / `paper-split`；真孔读 `paper-window`，若要连窗芯一起再利用，用同一方法的 `parameters.variant="reuse-core"` 并给 `corePlace`；穿纸读 `paper-weave`。真实胶带的固定用 `tape-fix`，双角固定或分隔分别用它的 `variant="corners"` / `"divider"`。胶带、透明承托和旧物拼贴都是可选关系，不是所有页面必备。未确定方法时读 `methods` 比较；已选中方法可直接读目标 `detail` 获取精确参数。实体裁切和层序以当前工具合同为准。

预览时看：纸层是否真在承托内容、接缝是否形成一个簇、露出的纸边是否有意、文字与主体是否可读、下层是否透孔、页面边缘是否仍有纸边。当承托、写面、边缘节奏及用户要求的疏密都已成立时停止加层；只摆好大块不等于丰富页已经完成。

## 组合纸层，而不是累积底卡

同一张底纸可以在不同位置分别承托标题、主体与正文；露边可宽窄变化，让读者看出纸之间的前后关系。纹样纸与干净写面可交错，边缘、孔洞、撕口也能参与构图。加一张与内容脱离的全新矩形，只会把文字隔离；先尝试现有露出区、移动与层序，再决定是否新建写面。真实材料的纹样、印字和缺口是设计条件，不是必须盖掉的缺陷。

参考中大纸框架、便签局部衬底、自由书写后补装饰可以组合。可翻动纸袋、补充页和立体挂件属于实体工艺；静态作品不能靠盖住正文再声称可翻开阅读。照片提取的可见片段与完整原材料不同：用户要求复原整料时，应先完成独立的素材复原，标记同源拼合和推测补全，再把确认后的整料交给创作；不能通过复制实物或普通图形命令声称恢复了隐藏纹理和字迹。白色印花与真实孔洞先辨别，再决定透明度。


多作者交叉来源、实际阅读范围和方法边界见 `creative-agent/research/tutorial-expansion-same-source-2026-11-23.md`。

纸层不必覆盖所有未来文字：上下纸簇之间的原纸可以承接标题或连续书写；大底纸也可同时托住多个写面。落字前后对照见 `creative-agent/research/rainbow-layout-stage-2026-11-23.md`。照片中的整本封面、桌面与活页环不属于当前纸页，先划定纸页边界再判断打底面积。

## 数字纸面的质感

图形承托可以使用 `style.paperSurface:{kind:"matte",intensity:0.45,seed:17}`，纤维较明显的纸用 `kind:"fiber"`；设为 null 可去除。这是可编辑的数字纸面，不是实体库存。与 `style.fill` 搭配，颜色先呼应实际素材的冷暖、明度与饱和度；不统一用米黄或纯白。质感为细微颗粒、纤维和缓慢色差，强度服从素材与文字可读性，不以做旧为通用目标。实体图像已经有纸纹时优先保留，不叠加模拟纸纹。

直裁纸可以保留直边；需要撕口才使用 washi 或自由路径，不把所有底纸变成锯齿。真实叠放可配轻微 shadow（offsetMm、blurMm、color），避免厚重悬浮阴影。图形色块也可能是平涂笔迹，无需全部纸化。先比较相邻材料是否协调，再决定加纹理、改色、改边缘或调整接触关系。

撕边纸有现成预设：`style.paperSurface:{kind:"torn"}` 即可获得细微纤维和真正透明的不规则纸边，默认强度 0.45、seed 17，可按需覆盖 intensity 与 seed。适合 rect 底纸或题签，不用叠白色锯齿遮罩，也不需要逐点画撕口。边缘尺度按毫米生成，大纸不会变成巨大锯齿。用 rect 搭配该预设即可，避免再叠加规则 washi 齿边。并非所有纸都应撕边：真实素材保持原样，直裁纸可选 matte 或 fiber。

## 一次调用的质感纸张

高级图形 `graphic.add.geometry:{kind:"paper",options:{paperPattern:"ruled",grain:0.65,torn:true,rows:12}}` 会生成一张可编辑的有纹理横线纸，不必另铺底卡再逐条画线。paperPattern 可选 plain / ruled / grid / dots；透光程度 translucency 为 0–0.85，0 为不透光，0.45 左右可作半透明薄纸，文字另放在纸上保持清楚。fill 控制纸色，stroke 控制印纹色，strokeWidthMm 控制线宽；印纹行列、纸纹、撕边可以分别调整。默认无阴影。

纸色可选本白、米白、牛皮棕、灰纸、黑纸及常见彩纸，允许同色相邻，也允许反差；不要用一片完全平涂的色块代替所有纸面。厚重悬浮阴影不适合普通拼贴，通常不需要 shadow，必要时只用贴边的极轻阴影。层次主要来自露边、纹理、印纹、透明叠色与内容关系。不是每张纸都需要横线或撕边。半透明纸叠在纹样、图片或不同底色上才看得出透光；避免覆盖人脸和重要字，不能把图层整体变淡后让正文也失去对比。

## 数字纸入口

新建数字纸用 `creation_paper`，可一次创建多张：`style.fill` 选与周围协调或对比的纸色，`style.stroke` 选印纹色；`texture` 为 subtle / medium / rough 纸纹强度；`edge` 选 straight / torn；`pattern` 可选 plain / ruled / grid / dots；`translucency` 为 0–0.85。默认无阴影。每张纸的 `order` 明确前后关系，例如 `{before:"body"}` 放在正文后面。纸仍是可编辑高级图形，后续用 `layer.update` 改位置、尺寸、层序或 geometry.options。普通色块可用矩形，但不将纯色矩形当作已完成的纸张质感。实际素材纸仍通过 material 工具取用。
