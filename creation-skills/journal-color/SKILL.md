# 配色与明暗

先观察本次素材的大面积色、明暗和纹理密度，选择需要突出的内容。已有照片、实物纸片的颜色是约束；先调整邻接关系、露出面积和文字颜色，不为套配色而给照片染色。

## 选择关系

- 同色或邻近色：用深浅、冷暖或纹理差别建立主次。颜色接近且明度也接近时，换一张承托纸或留出纸色间隙。
- 明显异色：让其中一种承担主面积，另一种只在需要引导视线的位置出现。不是每个角都需要同等点缀。
- 多彩素材：先以本次关键照片或主体定基调，少量其他颜色通过标题、短线或现有小材料回应。彩色图案之间加入干净的承载区。

颜色面积由实际材料、留白和遮挡共同决定；不把 6:3:1 等示例比例设为硬目标。浅底深字、深底浅字先保证可读。色彩不足时可以用已有纸色和文字组织，不必增加装饰物。

## 从少量素材建立整页配色

先从照片或实体素材中取两种最能代表本页的颜色，写明各自来源。让一种负责较大面积的底纸或主物，另一种负责相邻页面、标题承托或局部纸片；第三种只在需要引导视线的地方点出。这里的“三种”是控制视觉主导色的起点，不是禁止素材里出现其他细色。

跨页有两种清楚的做法：两页重复一两种颜色，靠深浅与面积变化呼应；或左右使用不同主色，一页的少量点缀引用另一页的颜色。先决定哪一种，再布置纸张、文字和物件，不要等排完才随意补色。

参考 A6per 的实际页面：紫与灰作两页大色，少量荧光黄提亮；可可棕与浅蓝跨页撞色，用白字稳定阅读；苹果绿作大面积，红苹果只占小处，仍能形成鲜明关系；白与粉红对页，水果与小标签带出极少红色。它们的物件不多，效果来自色块面积、跨页呼应、明度对比和点缀位置。颜色灵感可取自本次素材中的食物、植物、天空等具体对象，不照搬案例的色值。

计划里写下：色彩来源、主色、辅助色、点缀色、两页是呼应还是撞色、哪几处使用点缀。看图时先判断一眼看到哪种色、视线如何走，再决定是否需要 `color-echo` 或 `color-bands`；并非每页都要额外添加色点或色条。若实体素材已经完成呼应，就不再画装饰。

## 示意与操作

`blue-lilac-layout`：低饱和大色块承托深色焦点，小承载区和文字方向形成层级。学习颜色分工，不复制英文标题或坐标。

`blue-tone-rhythm`：同色系中深色结构块与浅色内容区交替。中间角色连接两个区域；真实素材只有一份时不能照图复制。

先合批完成底色、标题色与关键邻接关系，再查看整页预览。如果一眼找不到主内容，优先减小非关键色块的露出面积或调整位置。不要反复微调几个相近 HEX 值代替构图。
