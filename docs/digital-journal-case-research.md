# 电子手帐案例分析

案例库位于 `src/creation-library/digital-cases.json`。每条记录保存来源、页面模式、适用风格与对象、构图、配色、对象使用顺序和缺料时的处理方式。创作服务按单页或跨页检索，再用 `read_case` 读取完整分析。案例图像没有进入素材库，模型只借鉴组织方法。

## 观察到的做法

| 做法 | 创作时的判断 |
| --- | --- |
| 先立主次 | 大照片或主要纸片先确定视点，小照片、文字卡和贴纸围绕它安排；素材不必等大。 |
| 色彩来自内容 | 文字卡、底纸和点缀从照片或实体素材取色；亮色集中在少量位置并跨区域重复。 |
| 点缀成组 | 三处装饰、环形路线或跨页对角线都能引导阅读；零散物件不应均匀撒满画面。 |
| 保留层次 | 纸芯、撕边、标签、半透明印章和轻微阴影让元素看起来相互接触；阴影方向保持一致。 |
| 文本最后校准 | 先给照片和纸片留位置，再安放标题和正文；印刷字不自动等于整页主题。 |
| 按页面模式选择 | 双页案例的书脊、镜像和跨页路线只用于双页；单页案例不补出第二页。 |

这些是从下列创作者讲解提炼的可迁移规则。页面位置、具体色值与素材数量仍应由本次真实素材和纸张尺寸决定，不能照搬原作。
