# 图文共同构图、可编辑字效与创作闭环

## 设计流程

文字、数字图形和实体素材共同组成页面；主要视觉块不等于必须先贴全部大素材。先判断任务资源和内容，决定由谁担当主体，稳定主块后完善正文，再主动选择小素材、贴纸、合法胶带/裁条、数字几何与笔迹。素材少时依靠标题/文字块/主图形承担版式，不靠把一件素材配两句小字。

点缀是必须审视的阶段，不是强制凑工具数。每个动作服务连接、强调、呼应或重量平衡；若删除更好就删。默认充实、疏密有序，不保留大片无作用空区；任务明确要求极简或留白时尊重。大空洞优先调整主块而非随机撒小装饰。纯拼贴和事实约束继续有效。

固定指南不包含用户素材、私人作品或外部课程画面；流程、方法卡、字效说明与示例通过现有固定内容构建器打包。正常使用只读短入口与 Skill；按问题查 Playbook/Lettering 和当前 describe，不通读完整递归 Schema。

## 文字效果是真实 Scene 数据

公共 style.outline（color、widthMm、offsetMm）编译为 textOutline 的原生长度；style.gradient（angleDeg、递增 stops）保存为 textGradient。创建、text.update、layer.update 和人工共享内核都使用同一数据。null 明确清除。

完整描边使用 strokeText 后 fillText；偏移轮廓使用同一轮廓的局部偏移；渐变使用 CanvasGradient 填入字形，不是叠两段字。阴影继续使用共同 shadow。颜色停止点从 0 到 1，拒绝无效颜色、未排序或重复 offset。排版为描边预留空间，避免将效果截在文字框外；极端参数会拒绝，而非静默裁掉。

同一 drawSceneText 供 Node Canvas、浏览器导出和 Fabric 非输入显示使用。Fabric 输入光标仍由原生字形度量支持；结束输入后共同渲染恢复效果。缩放、套索及纸张单位换算会同步缩放物理描边参数。字体仍依赖环境，不宣称跨设备像素相同。

## 便捷工具

- text.lettering：将最多 32 个字素的单行标题编译成普通 Group/text 子节点。统一 style，可通过 letters[index] 指定不同字体、色彩、字效、轻微角度和位移。id-g1/g2 可继续独立编辑。只针对短标题，不替代阿拉伯文等连写语言的整词 shaping。
- draw.decorate：underline/highlight/bracket；按目标的文字测量估计或对象框生成普通 ink，固定 seed 保证重放一致。默认跟随目标位置，高亮在文字后方。不分析句内关键词、不假称人工笔触，也不在目标改字后自动伸缩；需要时重新生成或编辑 geometry。
- fonts：列出字体类别偏好和当前本机发现的字体名称；发现不可用时如实返回。没有字体二进制传输、自动下载或授权推断。
- design-check：当前 Scene 的只读诊断。统计图层类别、字号/字体/效果和 24×32 框级占位，提示大未覆盖区域。它不读取 alpha/字形像素或纸内印刷，所以不能作为真实留白比例，更不能决定美观或自动 pass。它不改变 Scene，也不触发修改/同步。

## 测试与边界

测试覆盖真实描边和多色像素、完整/偏移轮廓不同、字素分组、字体/效果独立编辑、非法输入原子拒绝、重开、手工与 AI 更新一致、缩放/linked、标记遮挡顺序和确定性、字体目录/诊断的只读性。导出 ZIP 在 Node 与 Chromium 都运行 check/apply/preview/review/pack/reopen。浏览器专项截图覆盖手机、平板横竖和桌面模拟视口。

不新增另一套 Scene 或旧操作兼容。没有自动图像人物边界识别，没有文字任意路径排版，也没有实现跨平台字体嵌入。已有自由裁剪使用明确闭合 region。页面美观仍需真实模型创作和人眼评估；合成例子证明能力与流程，不证明提示改动必然提升每个模型的审美。
