## 本轮修复：独立跟随设置、原生导入引用和屏外对象操作

- 位置参照与尺寸参照分开编辑，避免共用选择器误改已有关系。应用一个设置不会清掉另一个设置中尚未应用的滑块值；解除和重开也重新反映各自当前状态。
- 常用间距改为滑块与贴边/紧凑/宽松按钮；宽高比例改为滑块与一半/相同/一倍半按钮。新增只按宽度或高度跟随，图形保持原宽高比，文字按其真实换行/最小高度语义执行。精确毫米与比例移到折叠区。
