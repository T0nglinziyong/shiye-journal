# 纸层与叠放

## 从素材簇建立纸层

纸张、主体和文字共同构图。先看素材里最值得展示的人物、数字、插画或印字，再选择相邻的纸色、纹样和写面，把它们组织成一个或几个互相呼应的簇。背景决定整页气氛，局部纸层决定主体落在哪里、边缘从哪里穿出；二者可同时使用。用户选择疏朗或丰富决定整体疏密，材料的角色与相互关系决定局部层序。

同一材料可以兼有几种用途：纹样纸既衬托人物，也从标题后露出；浅纸的一部分承字，另一部分进入照片背后；原页和深纸也能写正文。先用决定面积与重心的少量大素材试摆这些关系，其余素材保留待选；之后沿实际露出的边角和字群空间逐步加入小件。小件的落点回应主簇，而不是先铺满再被纸盖住。文字区域不等于一张新纸。

## 按内容安排显露与遮挡

主体层保留能辨认、能表达主题的部分；承托层让颜色、纹理或撕口从主体周围显露。素纸与重复纹样可大幅藏住；人物、数字、插画和有意义的印字则依据具体内容选择可遮部分。矩形照片或图案卡同样可能是主体，不能按外框形状决定谁在底层。选用局部时，保留下来的图案仍应成立；暂时不用的材料留在素材区。

深叠压主要发生在相互承托的纸之间，主体跨压纸缘并参与局部穿插。先确定最终可见的边角，再倒推位置：上层纸可同时沿横向、纵向移入下层，露出宽窄不同的边；纸本身可以放正。判断依据是层次、主次和读序，不是统一重叠比例或统一倾角。每次调整后看实际画面，确认新增纸没有吞没原本选定的主体。

## 把写面嵌进已有构图

文字先寻找现有的低纹样空间：纸的空白区、深纸上的浅字、素材簇之间的背景。一个段落可跨相近底色；多段可分布于不同空间，或在同一空间用小标题分层。印花与正文冲突时，先重新安排字群宽度、位置和分段，或裁取合适的纸片，保留印花本身的表现作用。

确实需要新增写字纸时，把它作为簇的中间层：纸的至少两处边缘分别压在两个其他对象下，中央保留连续可读空间。例如左上角进入照片下，右下边进入人物或图案贴纸下；正文随后写入显露的中央。邻近、同色或旁边放一个圆点不等于压住。这样纸既连接对象也承载文字，不会成为浮在最上层的独立便签。独立票据等本身已有内容的素材按其叙事用途处理。

## 从整料得到合适的轮廓

素材尺寸是原料条件，最终轮廓通过选用、移动、裁切、撕分和层序共同形成。纸过大时，可以保留需要的区域、切去多余边，或撕分成同源的两片呼应；不必为了塞下整料而把主体盖住。窄条用于跨接接缝，或两端进入其他对象下，只露中段；短句则可直接写在相关对象附近。

纸层沿对角或 Z 形安排的是视觉落点，不是统一旋转角度。两片可同大或一大一小，可深入叠放，也可分开让背景承字；正放、斜放与间隔各自选择。需要实体连接时，第三片纸可从两片背后穿过；也可让同源撕口与色彩跨空隙呼应。深纸与浅纸形成的连续簇、上下分置的同源裁片、横竖交错的纸带都可以与图像和字群组合。单双页均先看主次和阅读路线，再看哪些局部需要接触。

实际操作可同轮完成取用、裁切、移动、改层序和写字，也可在后续插入某一层。`material.cut` 保留或移除指定区域，`material.tear` 沿轨迹撕分；需要多片同时摆放用 `material.split`，并保留来源与余料。裁片沿用原素材坐标框，移动前看可见轮廓。实体材料不靠缩放或重复取用增加用量。

## 从预览判断关系是否成立

缩看主体是否仍清楚、纸块是否相互承托、色块和露边是否形成节奏；近看文字是否落在真正可读的空间、新增写字纸是否嵌在两个对象下面、胶带与圆星是否接触真实纸缘。层次不足先调整已有纸的落点和显露，内容被埋则让承托纸后退或裁去多余部分。达到用户的疏密与内容目标后停止加层，保留已经成立的关系。

## 方法选择

数字纸优先用 `creation_paper`；`paper-color-card` 是可选纸面方法。窄纸条先确定跨接、露边或穿插关系，再用纸张工具创建或合法裁取真实素材，通过 `layer.update.order` 安排遮挡；普通色块才用 `graphic.add`。需要准确露边读 `paper-peek`；裁切读 `paper-tear` / `paper-split`；真孔读 `paper-window`，若要连窗芯一起再利用，用同一方法的 `parameters.variant="reuse-core"` 并给 `corePlace`；穿纸读 `paper-weave`。真实胶带的固定用 `tape-fix`，双角固定或分隔分别用它的 `variant="corners"` / `"divider"`。胶带、透明承托和旧物拼贴都是可选关系，不是所有页面必备。未确定方法时读 `methods` 比较；已选中方法可直接读目标 `detail` 获取精确参数。实体裁切和层序以当前工具合同为准。

预览时看：纸层是否真在承托内容、接缝是否形成一个簇、露出的纸边是否有意、文字与主体是否可读、下层是否透孔、页面边缘是否仍有纸边。当承托、写面、边缘节奏及用户要求的疏密都已成立时停止加层；只摆好大块不等于丰富页已经完成。

## 数字纸面的质感

图形承托可以使用 `style.paperSurface:{kind:"matte",intensity:0.45,seed:17}`，纤维较明显的纸用 `kind:"fiber"`；设为 null 可去除。这是可编辑的数字纸面，不是实体库存。与 `style.fill` 搭配，颜色先呼应实际素材的冷暖、明度与饱和度；不统一用米黄或纯白。质感为细微颗粒、纤维和缓慢色差，强度服从素材与文字可读性，不以做旧为通用目标。实体图像已经有纸纹时优先保留，不叠加模拟纸纹。

直裁纸可以保留直边；需要撕口才使用 washi 或自由路径，不把所有底纸变成锯齿。创作不使用阴影，以露边、纹理和透明叠色表达叠放。图形色块也可能是平涂笔迹，无需全部纸化。先比较相邻材料是否协调，再决定加纹理、改色、改边缘或调整接触关系。

撕边纸有现成预设：`style.paperSurface:{kind:"torn"}` 即可获得细微纤维和真正透明的不规则纸边，默认强度 0.45、seed 17，可按需覆盖 intensity 与 seed。适合 rect 底纸或题签，不用叠白色锯齿遮罩，也不需要逐点画撕口。边缘尺度按毫米生成，大纸不会变成巨大锯齿。用 rect 搭配该预设即可，避免再叠加规则 washi 齿边。并非所有纸都应撕边：真实素材保持原样，直裁纸可选 matte 或 fiber。

## 一次调用的质感纸张

高级图形 `graphic.add.geometry:{kind:"paper",options:{paperPattern:"ruled",grain:0.65,torn:true,rows:12}}` 会生成一张可编辑的有纹理横线纸，不必另铺底卡再逐条画线。paperPattern 可选 plain / ruled / grid / dots；不透明度统一用 style.opacity，范围 0–1，1 为不透明、0 为全透明，0.55 左右可作半透明薄纸；纸张和胶带使用相同参数，文字另放在纸上保持清楚。fill 控制纸色，stroke 控制印纹色，strokeWidthMm 控制线宽；印纹行列、纸纹、撕边可以分别调整。默认无阴影。

纸色可选本白、米白、牛皮棕、灰纸、黑纸及常见彩纸，允许同色相邻，也允许反差；不要用一片完全平涂的色块代替所有纸面。创作不使用阴影。层次主要来自露边、纹理、印纹、透明叠色与内容关系。不是每张纸都需要横线或撕边。半透明纸叠在纹样、图片或不同底色上才看得出透光；避免覆盖人脸和重要字，不能把图层整体变淡后让正文也失去对比。

## 数字纸入口

新建数字纸用 `creation_paper`，可一次创建多张：`style.fill` 选与周围协调或对比的纸色，`style.stroke` 选印纹色；`texture` 为 subtle / medium / rough 纸纹强度；`edge` 选 straight / torn；`pattern` 可选 plain / ruled / grid / dots；纸张和胶带统一用 `style.opacity`，范围 0–1，1 不透明、0 全透明。默认无阴影。每张纸的 `order` 明确前后关系，例如 `{before:"body"}` 放在正文后面。纸仍是可编辑高级图形，后续用 `layer.update` 改位置、尺寸、层序或 geometry.options。普通色块可用矩形，但不将纯色矩形当作已完成的纸张质感。实际素材纸仍通过 material 工具取用。
