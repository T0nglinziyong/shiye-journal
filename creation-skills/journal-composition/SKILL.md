# 图文共同构图

先查看真实素材，辨认图像主体、印刷文字、可写空区、图案密度和裁切边界。素材标题和分类只是线索，不能代替看图。用 creation_plan 记下本页表达、主次关系及哪些材料值得保留；不要给每件素材同样的视觉份量。

## 决策

- 图片多：先分两三组语义关系，选一组承重。其他组通过色彩、朝向或文字产生呼应。尺寸由实物决定，不能为了版式放大或缩小普通实物。
- 图片少：由标题、短段落、笔迹和可编辑图形共同承重。允许主素材只占一角；不要放大它或自动重复。
- 文字多：先留可读写面，再用素材压住段落外缘、连接小标题。文字不是一块统一的页底说明。
- 纯拼贴：让原素材的图像、印刷字和负形承担叙述，不强加日记正文。随写可以写感受或想法，不冒充用户经历。
- 双页：左右可以不同密度，但应有内容或视觉联系。书脊附近避免小字和人脸；不是把两张单页拼在一起。

## 操作

先 creation_help 查询 material.add、text.add、place、size；用一批 creation_apply 试摆结构。位置按实际毫米或 page.left/page.right 锚点；组内用 parent。局部对齐可以让材料看起来经过安排；不要求所有边都平行，也不随机旋转全部材料。需要真实裁切再查询 material.cut/window，不用白色色块伪造裁片。

收到预览后看：第一眼落在哪里？第二眼到哪里？标题是不是压倒所有材料？正文是否形成能读完的段落？材料之间是否只是互不相干的空隙？优先修改尺度关系、分组和写面，再加细节。creation_review 写具体位置和实际问题，避免只报“和谐、丰富”。
