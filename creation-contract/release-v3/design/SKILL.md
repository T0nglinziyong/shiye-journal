# 手帐创作 Skill：结构 → 内容 → 点缀 → 视觉闭环

适用于初稿和精修。文字、图形、素材都参与构图；任何一种都可以是主体，不把数字图形或文字固定成贴纸的附属。以 TASK 的主题、文字策略和加工权限为准。纯拼贴不新增正文，不凭空添加用户经历。

## 一、判断资源与版式重心
看真实原图而非只读 metadata。关注可写面、印刷字、人物朝向、空边、图案和深浅；按页面显示面积而非图片像素判断材料大小。

- **素材丰富**：先用主要材料确定层次和风格，给正文和次级信息留实际位置；小材料后加，不让每张完整纸都同样抢眼。
- **素材稀少或视觉很轻**：由大字标题、正文块、矢量/色块/线框建立骨架；小贴纸成为锚点或呼应。不要孤零零贴一件素材、写两句小字就交付。
- **文字很多**：先按主题分段，块内采用统一左/右/居中对齐，块间错落，用标题、字号、笔重和段落形态形成层级。行距不是越紧越省地；读不清先重排。
- **已有大印刷字**：把它纳入主重心；周边正文与图形仍需有重量。新增标题不必同义重复，但允许短回应或艺术字成为次焦点。

先用 3–5 句确定主块、正文、点缀职责及阅读路线即可，不写长分析。比较的是图文关系，不只是交换左右或转几度。必要时只做轻量结构试排；不要同时精修两个完整方案。

## 从试摆到写字：顺序由素材决定
真实拼贴常先沿主体轮廓取舍、试摆大纸与书写纸，调整露边和遮挡，再写字；也会先在独立纸片上写好一段，再连同纸片贴入。不要把“先摆素材”或“先写正文”固定成唯一顺序。判断是哪件素材规定了书写空间，哪句话反过来需要移动纸片。

- 首批 Commands 完成可判断的整体稿：主角、支撑纸面、实际文字与关键细节同时出现。有明确结构分歧时才用 `preview --commands work/commands.json` 比较，不把粗排当成必经步骤。实际内容进入后才能判断书写空间是否成立。
- 素材上的空白纸面可以承载文字；需要整体移动时，将纸片与对应文字组成组。文字要避开孔洞、图案和重要印刷字，不能因为纸片外框够大就当成整块可写。
- 素材上的圆点、格子、印刷标题若进入叙事，可让一句短注、圈线或书写动作与具体位置发生关系；不要只在纸片外另写一段“这张纸有什么”。可写纸面仍需承载有意义的内容，留空时要有可读的原因。
- 小素材和数字图形可压住纸片的一角，或让编号与人物轮廓轻微搭接。检查有用边缘是否还看得见，主体的脸、文字和动作是否仍清楚；不要把“叠层”做成所有素材同心堆放。
- 配色先看大面积纸片的主色与明度，再从素材中挑一个小面积强调色。圈注、圆点、撕边条和高亮服务局部焦点，不预设每页都要用。

## 二、先主块，再内容和关系
“大”是视觉重量，可来自大图片、大字、密集段落或深色图形，不等于只能先摆实体素材。先稳定这些重块的位置与方向，然后共同完善正文和材料关系。

背景／打底纸／文字区／上层元素之间要可见地互相承托。试着让短句、数字、图案或人物跨过一处纸边；不让所有对象都被关在自己的矩形里。斜贴的同组保留部分平行边，避免随机旋转。跨边不能遮掉脸、重要印刷字或误伤中缝。

文字不只有一种形式：连续正文、短插话、列表、横竖向标题、大小字搭配、单字强调、曲线标题都可按内容选择。长正文优先完整可读；艺术处理优先用于一两个关键字/短题，不把整篇正文做成混乱字样。字体与字效分开选择：描边、阴影、渐变、偏移轮廓各有不同作用。

## 三、不要吝啬装饰：主动完成细节层
主结构初步成立后，主动展开一轮细节创作。默认追求丰富、完成度高的手帐，不默认极简，不把“没有必要”“保持简洁”当作跳过点缀的万能理由。点缀不只是一条线：可以在多个区域形成轻重不同、彼此呼应的细节组合。候选包括：小素材/贴纸、许可的胶带或窄条、数字几何、手绘图案、关键词高亮、局部背景、短字与编号。

每处保留的点缀至少承担一个作用：连接两区域、回应某句话/素材、强调、改善方向、补足重心、制造局部细看价值。可以把小圆部分藏在纸后、把色条穿过两个区域、把手绘呼应放到词旁；形状可来自素材里的纽扣、花、星芒等，不固定每页撒点。

不要在真正尝试之前过早自我限制。可以先画出候选圈线、星芒、旁注、色条或叠放小贴纸，在真实预览上选择保留、调整或删除。只有遮挡正文、破坏层级、挤压呼吸或与主题冲突时才减去对应内容，而不是因“装饰已经有了”停止。明确极简任务或本身已经细节充分的画面可以例外，但须能从 PNG 说明。没有素材来源的实体胶带不可虚构；数字色带/图形可以独立使用。

## 四、充实而不堵塞：处理空白
除非任务明确要求极简或大留白，默认追求有内容支撑、细节丰富的充实页面。检查上半部、下半部、左右页与材料内部有没有大块无作用区域。

- 空洞来自主块太小：扩大**数字文字/图形**、改变版式、移动材料；不能放大真实素材。
- 空洞来自没有内容：在原意与事实允许内展开表达，或用图形/插画担任主体；不编造事件、日期或用废话凑满。
- 空洞来自材料间完全隔离：调整距离和叠压，建立跨元素连接，而不是放十个小圆点。
- 边距、段间呼吸和主体周围的停顿应保留；不能用机器覆盖率当审美 KPI。

## 五、实际预览、局部修正
看当前 PNG：第一眼是否有明确主次？正常尺寸是否能读正文？第二眼能发现关系和细节吗？字体、色块、素材三者谁承担主要重量？有没有过大无作用空白？

使用 design/REVIEW.md。可用 design-check 辅助寻找框级空区和字号过于接近的问题，但它没有看懂图像。把发现的问题整理为明确的局部 Commands；可以在同一批中对多个区域增添相互呼应的细节，再预览。不要把长时间思考、修改轮数或操作数当成设计成果。

## 默认字体与周边图形
新建文字默认艺术手写，不再默认普通宋体。标题/单字可用不同艺术字体和描边、渐变；长正文保持可读而非堆满效果。离线先 `fonts` 查询实际字体，未安装的名字不等于已获得字形。

主体构图后专门看一遍周边：人物肩侧、标题角落、纸片接缝、段落结尾是否有值得增强的关系？可以使用小素材、贴纸、合法胶带/裁条、短句与编号，或者从本页的纽扣、星芒、花朵提取图形。轻重、大小有区别，不围着所有对象撒一圈。

**点缀是作用，不是工具类别。** 先说明哪个区域缺少联系、方向、重点或细看价值，再选择合适的已有能力。圆形既可以是大面积主体，也可以作为一个小标记；没有“点缀对象”或一键装饰命令。图形和绘画统一用 graphic.add，区别只在 geometry、size、style 和 place；用法按需查看 GRAPHICS.md。无需默认加星星，也不能因为工具需要参数就放弃所有局部精修。

## 六、统一工具让变化更容易
创建文字/材料/图形分别用 text.add、material.add、graphic.add；普通内容、几何、样式、位置和层级只用 layer.update。显示遮罩用 layer.mask；实体 keep/remove 用 material.cut 的 region+mode。不要重新学习旧同义入口。

用 layer.duplicate 复制普通数字对象/组合后改变样式与大小，生成有规律而不完全相同的细节；包含实体的组合须逐节点 materialMap 映射合法来源。重复不是目的，变化要形成节奏。

outline、gradient、shadow 可用于文字和支持的图形/笔迹。艺术短标题可 text.lettering 创建、text.reflow 改整段文字与字位。字体、轮廓、渐变、方向、大小可以组合变化，长正文仍需可读。

圈线/背景需要随文字框变化时，使用 size 的 reference+ratio+behavior=linked；place 的 linked 独立控制位置。普通 size 是一次求值。不要依赖未实现的语义关键词检测，不自动把所有边注做成同一模板。
