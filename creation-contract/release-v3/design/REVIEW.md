# 预览必须带来可检查的决定

实际打开当前 output/preview.png。check、design-check 和 pack 不会替你评价美观；不得把未看图写成 pass。

依次查看双页缩图、每个单页、正常尺寸文字及关键局部：
1. **主结构**：指出最重区域与最大无作用空区。是有意停顿，还是缺少主块/正文/连接？先改结构，不用碎装饰填洞。
2. **文字**：主要内容能否读清？艺术短题、正文、边注是否各有角色？正文是否压在印刷字/表格横线/复杂图案上？
3. **关系与细节**：指出几处实际搭接、跨边、藏边或颜色呼应。圈线确实圈住词、高亮确实落在目标行、箭头是否有终点？不能画完工具形状就当作关系成立。大中小尺度是否连贯？不要吝啬有依据的丰富变化。
4. **边界**：重要文字、人脸、中缝、材料尺寸/来源与编辑性是否保留？

仅记录当前最重要的最多三项：`区域/对象 → 可见问题 → 下一步操作 → 预期变化`。下一张 PNG 对照确认变好了还是变差；没改善就重新判断，不反复加同类装饰。还存在明显结构/可读问题时不能交付；完成后不要为凑轮数继续加物件。视觉结论是本次审阅，不是跨模型稳定质量保证。
