# 配色与明暗

先观察本次素材的大面积色、明暗和纹理密度，选择需要突出的内容。已有照片、实物纸片的颜色是约束；先调整邻接关系、露出面积和文字颜色，不为套配色而给照片染色。

## 选择关系

- 同色或邻近色：用深浅、冷暖或纹理差别建立主次。颜色接近且明度也接近时，换一张承托纸或留出纸色间隙。
- 明显异色：让其中一种承担主面积，另一种只在需要引导视线的位置出现。不是每个角都需要同等点缀。
- 多彩素材：先以本次关键照片或主体定基调，少量其他颜色通过标题、短线或现有小材料回应。彩色图案之间加入干净的承载区。

背景可用不同颜色：原页、浅底、深底或彩底均可，不能把常见纸张颜色理解为只有米白。双页可以交换主辅色或形成有联系的反差；颜色的呼应和构图位置的互补一起判断。颜色面积由实际材料、留白和遮挡共同决定；不把 6:3:1 等示例比例设为硬目标。浅底深字、深底浅字先保证可读。色彩不足时可以用已有纸色和文字组织，不必增加装饰物。

## 从少量素材建立整页配色

从照片或实体素材中确定有来源的主导色及其职责；需要时再选辅助色和点缀色。教程里既有一主色配黑色，也有两种主色配数种辅助色；色数不是合格线。克制或多彩取决于用户的视觉方向，不能由画面疏密推断。丰富层叠可以同色系，疏朗留白也可以有鲜明撞色。

跨页有两种清楚的做法：两页重复一两种颜色，靠深浅与面积变化呼应；或左右使用不同主色，一页的少量点缀引用另一页的颜色。两种关系可以混用，并随着纸层、文字和物件的实际面积调整；不把它们设为互斥路线。

参考 A6per 的实际页面：紫与灰作两页大色，少量荧光黄提亮；可可棕与浅蓝跨页撞色，用白字稳定阅读；苹果绿作大面积，红苹果只占小处，仍能形成鲜明关系；白与粉红对页，水果与小标签带出极少红色。它们的物件不多，效果来自色块面积、跨页呼应、明度对比和点缀位置。颜色灵感可取自本次素材中的食物、植物、天空等具体对象，不照搬案例的色值。

计划里记有用的色彩来源和分工；单页不写跨页关系，无需强设辅助色或点缀色。看图时先判断一眼看到哪种色、视线如何走，再决定是否需要 `color-echo`：默认是局部色点呼应，`parameters.variant="bands"` 是主辅色条。并非每页都要额外添加色点或色条。若实体素材已经完成呼应，就不再画装饰。

## 示意与操作

`blue-lilac-layout`：低饱和大色块承托深色焦点，小承载区和文字方向形成层级。学习颜色分工，不复制英文标题或坐标。

`blue-tone-rhythm`：同色系中深色结构块与浅色内容区交替。中间角色连接两个区域；真实素材只有一份时不能照图复制。

先合批完成底色、标题色与关键邻接关系，再查看整页预览。如果一眼找不到主内容，优先减小非关键色块的露出面积或调整位置。不要反复微调几个相近 HEX 值代替构图。

单色页也能用实心/空心、深浅、线宽与纹样形成丰富层次；多色页可让主图、文字、纸边分别接续不同颜色。既可以用低调底色平衡鲜艳贴纸，也可以采用有主次的撞色。判断具体邻接是否清楚，不用色数或固定比例代替看图。

多作者交叉来源、实际阅读范围和方法边界见 `creative-agent/research/tutorial-expansion-same-source-2026-11-23.md`。

双页先分别确定两页的主面积与焦点，再用少量共同色或互换主辅色把它们联系起来；不需要镜像布局或同面积色卡。底纸可以有反差，纸片也可以与周围近色，靠纸纹、线条、露边和文字分层。半透明纸让下层颜色与纹样透出，可以桥接两种色；不能靠大阴影建立纸感。新增复核来源：不是鸭鸭《A6per手帐配色思路2.0》视频（6ae29df20000000033010256），其三色建议是易用方法，不是固定色数上限。
