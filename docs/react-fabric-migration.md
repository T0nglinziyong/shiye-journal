# React 与 Fabric 编辑器迁移合同

本分支的目标是让 React 管理所有页面、工具栏、表单和弹窗，让 Fabric.js 管理创作画布中的对象选择、变换、文字编辑和绘制。已保存作品仍以 Scene v2 `layers` 为唯一持久格式；Fabric 对象只作运行时投影。云端存储、图片队列、同步 outbox、实物库存和物理校验沿用现有合同。

## 当前实现状态（尚未切换产品编辑器）

- `?fabric-editor` 现在可在账号作品页打开真实作品，以 React 工具栏与 Fabric 画布完成笔迹、毫米笔宽橡皮、文字点按编辑、图形与实物素材插入、纸张设置、图层选择、撤销重做和保存。画布的两指缩放会取消尚未完成的笔迹，缩放按钮与视口状态复用现有 Panzoom。作品仍按 Scene v2 保存。此入口仅用于验收，正常入口仍使用旧画布。
- 搭配页的方向表单、版本方案、主要按钮及进度改由 React 更新。真实 Chromium 中模拟流式模型响应，验证了草稿落盘、重进打开、提升为作品、重置只清方案和手机／平板／桌面视口。该模拟没有验证真实 AI 服务质量。
- 当前分支已重新通过 `npm test`（928 项）和 `npm run test:ui`；Fabric 作品流程及搭配生成流程也通过真实 Chromium 专项测试。它们只覆盖本段明确列出的行为，不能作为完整迁移验收。

- 已有独立的 Fabric 场景投影与 React 画布组件；图形、文字、裁片蒙版、矢量蒙版、笔迹及组合可以显示，图层并行解析，完成的对象按原顺序立即进入画布。素材裁片蒙版和矢量蒙版取交集；组合蒙版使用整页坐标。非编辑文字和笔迹使用原有 Scene 排版与平滑路径，避免预览、编辑与导出明显错位。
- 已核对单个实物素材不能通过控件缩放，组合只能移动、旋转；图层变换写回现有 Scene v2 字段。编辑器原有双重点击分发已修正。
- 新笔迹使用纸张毫米换算的粗细和压感描边；鼠标无真实压感时按运动模拟，手写笔保留真实压感。橡皮按实际毫米半径切分笔迹，并插值到擦除边界，连原始采样点之间的长线也可擦除。新格式只用于新笔迹，旧作品的笔迹仍按原算法重现。画布与 PNG/PDF 共用同一压感轮廓。
- 画布组件已能按 Scene 修订增量替换、删除和重排图层；异步图片的迟到结果按图层版本丢弃，替换图像完成解码前保留旧对象。浏览器已验证选择、双击文字输入、笔迹、橡皮、外部图层增删重排、慢图像原位替换，以及素材、图形、文字、组合蒙版与 Scene 导出对照。
- 正式创作页仍使用 `mountCanvasEditor`、`renderSceneDOM` 和直接 DOM 控制器。新组件已有真实账号作品预览入口，但输入法组合态、套索／框选、荧光笔、组合编辑、PDF 导出及跨设备同步尚未完成新画布端到端验收。
- 设置页的识别方法说明、AI 服务商／模型选择现由 React 管理事件；创作页属性面板和 AI 面板也已改为 React 元素，AI 进度通过状态事件送达组件。备用工具分发不再因单击文字或图形立即插入默认对象。Fabric 素材投影可等待现有图片队列异步提供 URL。
- 当前 `src/app.js` 的整体路由、通用弹窗、匹配会话、导入画面控制器及 Swift 画布工具仍有直接 DOM 操作；React 路由根仍在完整路由渲染时重建。不能将局部 JSX 迁移视为框架统一完成。
- 搭配的旧回退实现、作品即时封面、通用弹窗和旧画布仍含 HTML 字符串岛。迁移门槛未达到，不能合并 `test` 或部署。
- 导入确认页的系列选择和作品名称已由 React 事件维护。系列、作品及系列详情的排序不再移动 React 管理的卡片节点，避免翻页和往返后点击落到错误目标；系列返回恢复了原有的页面历史语义。
- 浏览器发现并修复了两个同路由更新问题：从“为系列添加素材”取消时必须重挂系列详情；导入识别结束后局部更新必须恢复曾因忙碌禁用的按钮。后台整理后卡片修订号也同步更新，已解码封面不会因随后刷新而重建。
- 当前隔离 Chromium 验收已覆盖 7 种视口、系列/作品/设置往返、手机编辑器套索与笔迹、后台整理并行请求和图片节点复用。完整 `npm test`、`npm run test:ui`、编辑器 88 屏、批量选择 34 屏及后台整理 11 屏通过。旧的长流程 `test:browser` 在空白手动补框应被拒绝的断言处仍失败；识别合同尚未重新验收，不能据此删旧画布或合并部署。

## 切换条件

1. `src/react-routes.jsx` 不再依赖页面 HTML 字符串或 `dangerouslySetInnerHTML`。作品封面可继续使用非交互式缩略图生成器，但 React 必须拥有其 DOM 生命周期。
2. `src/app.js` 不再通过 `view.innerHTML` 或全局 `data-act` 委托驱动用户操作。页面、弹窗、工具栏及设置输入由 React 组件和统一 Action/State 入口负责；不存在一次点击触发两个所有者的情况。
3. Fabric 编辑器必须逐项覆盖：素材原图与裁片、透明蒙版和开窗、实物尺寸与库存、文字排版及中文输入、所有图形、自由笔迹与橡皮、组合和图层顺序、撤销重做、缩放与触屏手势、备选区、导出及历史作品重新打开。对象身份和数字坐标往返 Scene v2 不漂移。
4. 用户操作先响应并本机可靠暂存；Canvas 的高频指针事件不得触发整页 React 重渲染。远端同步和图片下载仍在后台进行，不夺取输入焦点或当前手势。
5. 旧编辑器只在新引擎通过同场景视觉对照、浏览器交互回归和备份恢复验证后移除。迁移未达到这些门槛时不合并到 `test`，不部署测试站。

## 验收场景

- 空白作品、已有作品、导入作品与跨页作品，在手机、iPad 横竖屏和桌面视口中保持布局、对象层级及打印尺寸。
- 同一 Scene 在旧、新引擎中比较裁片孔洞、旋转素材、复合图形、中文多段落文字、手写笔迹及组变换；导出 PNG / PDF 的物理尺寸保持一致。
- 首次点击文字、图形或素材工具不得偷偷插入默认对象；画布文字选中和进入编辑均可即时响应，输入法组合态与连续书写不丢字。
- 素材库和作品封面快速滚动、翻页、详情往返后复用已加载图像；编辑中跨页、断网重进和双标签同步不丢草稿。
- 完整运行 `npm test && npm run test:ui`、编辑器与导入专项浏览器回归，再用准确提交 SHA 验收测试站。
