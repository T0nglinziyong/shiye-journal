# 点缀与细节

点缀可以参与初始构图，也可在书写和叠放中加入、移动或删除。观察最新预览：哪里需要强调、连接、固定或颜色呼应？有明确作用才添加；textMode=none 时不新增文字；用户明确要求只用真实材料时，不添加数字图形。

## 从真实案例提取的层次

1. **接触点**：标题与照片交界、纸片露边或胶带端部，形成一个局部小簇，不沿每张照片四周平均装饰。
2. **次级呼应**：需要时在另一个内容簇用同类细节回应，尺度和密度可变化。安静区域的范围服从用户画面疏密，不要求所有页面保留大片空白。
3. **近看细节**：纸边针脚、细线枝叶、小圈标记。远看不夺主视觉，近看有笔触。
4. **真实语义**：邮票、日期标签、票根、夹子、剪余料来自现有素材；与主题有关才加入。数字圈线可以呼应，不能生成假票据冒充库存。

点缀还可以沿阅读路线落在不同层面：一处靠近底纸露边，一处贴在图案或标题接缝，另一处落在可写区外的纸面。保持主簇与回声的尺度差，不把圆点、星形平均撒满四角。大实心圆也是有效的色彩锚点：用 `graphic.add` 的 `geometry.kind=ellipse`、`style.fill` 与物理毫米尺寸画一到数个不同大小的圆，先看与标题或纸片的比例，别都缩成手机预览里看不见的小点。细长 `rect`、marker 笔迹或 path 也可像胶带一样压在两层交界；它们是可编辑画笔图形，不消耗真实胶带。先缩小看这些元素是否把相邻对象连成关系，再放大检查是否盖住正文。图案纸本身已有重复纹样时，新增图形只补转折，不重复铺满同一种花纹。

## 实心圆与星形怎样贴住纸边

实心形状与空心圈承担不同作用：实心圆、五角星能形成清楚的色彩锚点，空心圈更轻、透底；不要一律选空心圈。丰富层叠页先观察底纸露边、两纸交界、标题底形的端部：可把实心形状的中心放在纸边附近，让它一部分压纸、一部分探出，把相邻层连起来。用大小不同的同色或呼应色在另一页回应，位置不必镜像。

简单形状直接用 `graphic.add`：`geometry.kind="ellipse"` 或 `"star"`，`style.fill` 为实际色，`stroke:null`；圆的宽高相同。位置、尺寸、层序跟随观察到的纸边，不照搬页角坐标。星形放在纸层上、正文下，或从纸后局部露出；圆可以和短胶带组合，但避免胶带把它完全遮掉。先选手机整页中能看到的尺寸，再看局部边界，不能用不可辨的微点代替色彩锚点。

这不是每页必须添加圆星：若选择它们，就检查是否确实接触纸边或连接字群，而非悬空撒点；保护正文、标题字心、人物面部。丰富度由用户决定，不把上述做法缩成每页固定一两颗的上限。

## 选择方法

| 目的 | 方法 | 使用边界 |
| --- | --- | --- |
| 纸边接缝的色彩锚点 | `graphic.add` 的 `ellipse` / `star`，实心填色 | 与纸边重叠，检查前后层序和文字遮挡 |
| 标题或照片角落的强调 | `accent-spark` | 默认少量四角光芒；适合活泼主题，不是通用填空 |
| 自然、安静的线条陪衬 | `accent-spark` + `variant=sprig` | 一两枝轮廓；调尺寸与色彩，别遮主体 |
| 纸边、标签的手工细节 | `accent-spark` + `variant=stitch` | 针脚组沿局部边缘排列，非整页围框 |
| 用颜色连接两处内容 | `accent-spark` + `variant=rings` | 大小不同的空心圈，保持透底与间距 |
| 活泼的小面积节奏 | `accent-spark` + `variant=confetti` | 色块与圆点局部成簇，最多两种呼应色 |
| 真实贴纸、印章、票根配组 | `accent-materials` | 输入实际 aliases 和比例 positions，保留原尺寸，不自动裁切或缩小 |

通过 read_skill 的 methods/detail 查图与完整参数，再用 creation_recipe 调用。配方共用可调范围、位置、数量、颜色、线宽与透明度；生成组可整体移动、旋转，内部图层仍可分别修改。枝叶与针脚是生成的可编辑路径，改变生成结构时重新调用配方，不能假称具有原生花瓣等形状参数。

## 放置、保护与停止条件

先按实际毫米尺寸确定局部 widthMm/heightMm 和 at。positions 使用这个局部区域的比例中心；protectedBoxes 使用同一区域内的比例矩形。把正文、脸部、日期和重要图案标成保护区。工具会省略越界、互相覆盖或进入保护区的单元，并在报告列出 skipped。省略不是失败，也不要为了凑数量强行缩小真实素材。此检查不识别内容、不读取整页遮挡；未提供的保护区不会自动被发现。

留白页可先试一个主簇和轻微回声；丰富层叠页围绕现有内容簇组织更充分的细节，并保护可读通道。这是起点，不是强制计数。已有花纹也可能支持更丰富的叠放；是否新增或混用图案看用户风格、视觉主次和具体关系，不把“少即是好”作为统一标准。文字注释服从任务的 contentPolicy：纪实只写确认事实，原创可写想象但不冒称用户经历；textMode=none 时不写注释。

整页与局部预览都检查：第一眼是否仍看见主体、细线在手机整页能否辨认、色彩是否来自素材、边缘有没有遮住有效内容、图层数量是否只是重复填空。画面已足够表达时可以不加点缀。自动预览后的视觉检查必须回答这些问题，不能以没有几何报错作为审美合格。

例如灰蓝冬日纸上已有印刷星纹时，新增点缀不必再画满底纹。可沿主图、标题和正文之间已经存在的视觉转折，试不同尺度的实心圆、实心星、空心圈或短线；手机整页看不见的 1mm 点阵不能算完成。先用 `creation_recipe` 的 `accent-spark`（空心圈用 `parameters.variant="rings"`）试一簇，再用 `creation_apply` 的 `layer.update` 调整已有对象的星角、线宽、颜色及前后层序；新增对象才用 `graphic.add`。不是每个空角都要装饰；真正作用是让内容组相互呼应。

## 与内容一起设计

装饰不只是一套星星与圆点。树形、天气、食物或物件轮廓可回应内容；线条、编号、箭头可连接对应图注；黑白对比、局部纹样和短笔迹可回应材料的质感。同一页可以组合这些方式，数量和范围服从用户方向。四角布局本身有效，问题是四处装饰没有内容关系或全都争抢注意。

丰富页若只有几块纸和规整正文卡，检查大块之间是否缺少中等尺度的标题、边注、纸边连接或局部图案；极小碎点无法弥补这个层次。留白页则可以将相同方法集中在局部。装饰与纸层、字群互相调整，不因进入“点缀”就禁止改构图。

## 从已有结果判断是否值得添加

装饰前后都要比较同一张页面：新的线、色块或图案究竟连接了哪两个对象、强调了哪段内容？已有装订孔或圆点栏时，不再沿页边复制一列近似孔洞的实心圆来增加数量；如果需要圆点作呼应，应与具体字群或接触点形成不同的局部关系。页边标签可以探出纸层，但要区分材料纸边和整页裁切边，避免无意裁掉有效图形。丰富不等于均匀加满：与内容无关的重复点列、四角小标签、星形也可以删掉，换为相关批注、局部线稿、关键词强调或接缝连接。保留素材本身的丰富度，不靠装饰数量作验收。

装饰阶段移动已有文字时，不要顺手放大字号破坏已成立的层级。改字体、字号或文字框宽度会重新换行，height 仍只是最小高度；狭窄便签、举牌短句和竖排边注应再次使用 `text.fit`，单行短句设 `maxLines:1`（整句旋转前的一行），字号范围接近原来已经可读的正文尺度。不能把副题或图注自动提升成主标题。若新增装饰反而挤坏文字，应先退回装饰或局部调整，再检查完整句子。
