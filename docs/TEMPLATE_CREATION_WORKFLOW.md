# 手帐模板制作与验收规范

本文件是**制作、修正或批量匹配模板前的必读入口**。先读本文件和目标模板已有的槽位、量测与验收记录，再看未经裁剪的真实案例，之后才写坐标和执行代码。模板是“参考案例中的对象关系 + 可替换槽位 + 确定性执行函数”，不是把某张成品图当背景，也不是一套机械的百分比框。后续复现中发现可复用的新问题，直接修订本文件和相应测试；历史运行记录保留当时的事实，不承担现行规则。

模板库只区分**新模板、旧模板、我的模板**。新模板须有可执行的量测定义、对象替换条件和原尺寸匹配验证，才能进入自动推荐与起稿；旧模板保留供查看，不再作为匹配候选；我的模板供账号内查看，尚未完成同等验证前也不参与自动匹配。当前首批新模板为五张单页、六张 A6 双页及三张排版分享双页，共 14 张。以后通过同一验收门槛的新模板加入现行目录即可参与匹配。

## 开工顺序

1. **读现状**：确认目标是单页、双页、复现还是“模板 + 输入素材 → 初稿”；读现行模板定义、源图量测、槽位角色、匹配器、最近一次渲染与问题记录。若有旧模板，先列出已知偏差，避免重复试错。
2. **看完整来源**：优先使用未经裁去中缝、书页或上下结构图的原始成品。结构图可帮助数清对象和判断类型，**位置、尺寸、角度、形状、颜色和遮挡以成品为准**。先标出每页真实边界，排除桌面、装订环、孔洞、白色中缝和展示用水印；这些不是画布对象。来源不清或被遮住的部分记为“待核”，不要假装已精确量到。
3. **逐件盘点并量测**：在动手制作前，一次记录每个可见对象的 ID、所在页、可见外框、推测的完整外框、旋转、形状、视觉作用、颜色/透明度、文字内容/字号层级、相对锚点、前后遮挡。尤其检查露出的底纸是否其实向照片或主纸下方延伸。
4. **先建立关系，再填素材**：确定大纸、照片/异形主体、文字、胶带与点缀的图层顺序和空间依附关系；把每个槽位的替代类型、默认值及安全裁切方式记清。先让空槽位的几何和层级成立，再接入真实素材匹配。
5. **先做结构对照**：用可编辑纸、文字、图形和必要的原案例素材校准模板，检查一整页的比例、位置、层序和视觉重心。此阶段可以用原案例素材作为量尺，最终“真实素材初稿”不得混入这些校准素材。
6. **再做替换测试**：使用有实测毫米尺寸的真实用户素材运行同一个模板函数；输出可编辑场景、PNG 和匹配报告。逐页对照原成品与新结果，并记录“结构一致”和“内容/审美合适”两个不同结论。修正源量测或槽位逻辑后重渲染，不靠给单张 PNG 打补丁。

## 原图量测与对象关系

把原图当作坐标真值：先记录图片宽高和左右页的四边，再量每件对象的四边及角度。源像素框只测一次，转换到该页的标准化坐标或毫米；不要在不同代码文件各自手填一份“近似框”。如果作者作品有透视或照片倾斜，记录测量误差范围，并在渲染叠图中核对，而不是把摄影视角误当对象旋转。

**每件对象同时分清三种范围**：

- 完整范围：纸/素材被压住以后仍实际存在的范围；底纸的层序和与上层物的交叠据此判断。
- 可见范围：用户最终看得到的外轮廓，包括透明素材的真实轮廓；用于视觉比对。
- 内容安全区：印字、人物翅膀、标题和正文必须保留或可书写的区域；用于裁切、遮挡和文字布局。

不要把两张纸相接处误判为一张纸，也不要把一张大底纸露出的细条当成整张小纸。对于“同一张纸是否延到照片下方”，从其边线、纹样延续、遮挡方向和结构图共同判断；不能确认就标注推测。双页左右各自有页坐标和底色，对象是否跨中缝必须由原案例明确支持，不能把装订缝连成画布。

每个对象除了绝对框，还要写**关系**。例如“中间照片盖住上蓝纸 1/5 照片高度”“白纸位于灰卡与标题之间”“两枚圆点纵向对齐但留空隙”“胶带跨纸边并被照片一角盖住”。为重要关系保存有向的前后层级约束和几何断言：谁盖住谁、应交叠多少、应分开多少。图层 z 值只是执行结果；**成对关系才解释为什么这样叠**。依附同一构图簇的字、纸、胶带用父对象或参考锚点定位；父节点平移时子节点应随之改变，同时每个输出仍可单独编辑。

大小、位置、角度先从来源量出，再根据替换素材的真实形状微调。对角/折线关系看主要对象的中心与留白，不能靠随手旋转制造。圆、星、箭头、胶带检查**完整形状和长宽比**，不能把装饰压扁。胶带要贴住真实边界并有合理长度；不要以一张卡纸代替同一条胶带的另一处复用。纸张可以大面积压住或清楚分离，若只重叠极窄一条，须确认原案例确实如此。

## 槽位记录与替换

每个模板槽位至少记录以下内容。字段可按现行代码格式实现，不必为文档另造一套运行时格式。

| 信息 | 需要回答的问题 |
| --- | --- |
| 来源与几何 | 对应哪张未裁剪成品、哪一页、源像素框与完整范围、角度/形状、允许的几何容差？ |
| 视觉作用 | 主视觉、底纸、书写面、连接、标题、数字、胶带、点缀中的哪一种？与哪些对象组成一簇？ |
| 关系 | 参考哪个对象或页边定位？盖住谁、被谁盖住？边缘需贴合或留多大间距？ |
| 默认输入 | 没有用户素材时用什么可编辑纸、字、数字或图形？内容、纸色、图案、透明度可否覆盖？ |
| 替代条件 | 可接受的素材类型、主题/色彩倾向、尺寸范围、可书写率、主体朝向、完整性要求？ |
| 加工策略 | 原尺寸摆放、显示蒙版、纸张裁切或留空中的哪一种？是否需保留裁切余料？哪些印字/主体不可裁掉？ |
| 验收证据 | 在原图叠图及真实素材初稿中，如何确认尺寸、层级、文字和素材完整？ |

“数字”可以由可编辑字体或合适的用户数字素材承担；标题纸、卡片、星形点缀、便签同理。默认值与用户显式指定值分开，用户指定纸色、文字、数字或素材时优先采用。通用纸张可裁成合适形状，重要印字卡、人物/动物/蝴蝶等异形主体优先完整保留。用户素材**不靠缩放改变实物毫米尺寸**去硬塞槽位；可用显示蒙版展现合适局部，只有安全可裁的纸和边饰才做实体裁切，余料留在待放区。不合适的素材留空或换模板，记录原因，不能用语义无关的素材占位却报“匹配成功”。

记录素材画像时至少包含原始宽高毫米、图像可见边界/透明区、外形类别、主色与印刷内容、可写面积、主体是否能安全裁切、适合的槽位角色和主题标签。匹配先看角色与物理尺寸，再看内容/色彩和可读性；主照片/大件优先，小装饰最后选。一个位置缺少合适实物时，可用**可编辑的基础纸/字/图形**完成结构；不要临时画丑的仿制贴纸来伪装原素材。区分“完整结构已有默认对象”和“必须用真实物件但缺素材”两种缺位。

## 文字、纸张与层次的检查

文字与数字应从原成品判断视觉等级。正文当前模板常用 **10.5 pt 作为起点**，不是全局固定值；标题、日期和构图数字要按源图的视觉比例设置，尤其不要默认缩成正文大小。记录字块位置、宽度、行距、对齐、角度及跨区域关系。文字可以写在纸上、照片可读区或页面底色上，不能因为工具方便就给每段话单贴一张孤立白纸。短标题、日期、字幕、英文小字分别检查是否缺失、过小或错位。

对需要精确配合的内容，用**实际渲染后的字形边界**核对：数字是否贴合背后卡纸、标题与纸边是否留足边距、荧光笔是否在字下而不是穿过文字、字块是否真的处于目标空白区。必要时用按行字形范围生成荧光笔，不把固定矩形盲贴到每个文本版本。复现不要求正文逐字相同，但字数密度和空间占用应相近，不能把整段正文变成两行小字。

纸张颜色按原成品的相邻关系核对，接近背景的白纸也应保持必要色差。硫酸纸是透明纸面，检查其**实际范围、透出下层的程度与上下关系**，不要把它缩成一枚小便签。非矩形纸、撕边、闭合背板以真实形状建模；不能用错误多边形或只有边框的图形冒充实心纸。胶带、纸张、照片、异形主体和点缀的图层关系逐对核验，重点看接触点，而不是只看整体 z 排序。

## 验收门槛

**结构验收**：对象清单无遗漏；页边、源框、尺寸、角度、形状、颜色、透明度和层级都有独立来源；自动检查关键对象的可见框、完整框、间距、相交面积、图层先后、出界、文字溢出与素材原始毫米尺寸。测试不能只证明“执行结果等于同一份模板数据”，还必须用从原案例独立量到的框和关系作断言。

**视觉验收**：在同一尺度并排看“未裁剪原成品 / 校准版 / 真实素材初稿”，再检查局部放大图。按页从大到小扫一遍：底色与大纸 → 主照片和异形主体 → 标题/数字与正文 → 连接物/胶带 → 小贴纸和点缀；同时逐个查看遮挡边。尤其关注：大底纸是否被量成小条、右上纸是否只和中间素材碰边、圆形是否相切、胶带是否悬空、上下便签是否错层、异形素材是否被切去要害。单页合格不代表双页合格，六张模板要逐张看，不能只看拼在一起的总图。

**替换验收**：用真实素材测试至少一个内容适配且一个尺寸/内容受限的样本；报告写明选入与未选入素材、缺位、裁切/蒙版、原尺寸核验和不合主题的替换。坐标误差小只能证明执行准确，**不能替代对“是否像来源”“是否好看”的人工判断**。单独标记“结构校准通过”“替换初稿可用”“视觉复现通过”“可上线”；前一项不自动推出后一项。

修一次错误时，先定位是**原图理解、量测、槽位规则、匹配、执行工具还是渲染**哪一层出错，再修对应的单一真值来源与回归断言。不要在输出图片上临时挪像素，不要只调一张测试图而让模板函数保持错误。把新发现压缩成一条可迁移的规则和一个具体案例，修订本文件或相关槽位说明；避免堆积针对单一作品的禁令。

## 新模板交付记录

每个模板完成时留下：原案例链接或本地来源及查看范围、未经裁剪的对照图、页边和对象量测、槽位/层级/替代规则、可编辑场景、单张预览、匹配与几何报告、人工视觉结论、已知差异。输出图可引用私有验收目录；仓库中不提交私人素材、作者原图或密钥。将最新验证命令写在该模板的说明中，使下次能从相同输入复现结果。

模板进入新模板目录时，再核对三种不同展示：卡片与“抽象模板”显示该模板在**空素材输入**下执行得到的默认封面；“真实案例”显示对应来源成品，存于受登录保护的预设存储；“元素构成”可逐件查看槽位的必须条件与建议条件，说明区不能被封面比例裁掉。三者不可用同一张示意图代替。
