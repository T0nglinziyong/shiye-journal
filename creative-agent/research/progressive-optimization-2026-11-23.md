# 按构图、配色、标题、点缀推进的真实研究

用户授权自主迭代，顺序为单页构图、双页构图与配色、标题内容、点缀装饰。保留所有失败结果，不把执行成功当作视觉通过，不以少量样本断言总体稳定。

## 已验证的问题与修正

1. 接续测试每轮将起点图重新放到最新预览后，可能干扰对当前版本的判断。现在新预览产生后不再附上起点，其他案例参考仍可保留；加入回归测试。此前 `structure` 轮在修正前启动，保留其完整证据，不拿它证明修正版效果。
2. `creation_plan.writingZones.surface` 限定为 page/material/graphic，真实模型对跨纸面写字的合理构思被拒绝，连带同轮编辑因未创建计划失败。此字段只为文字计划，无执行权限，改为有界的写面描述，支持原页与素材等联合写面；实际对象 surface、来源和 Scene 验证没有放宽。Harness 测试核实计划正常接受并保留跨写面描述。
3. 模型只在 `layer.update.place` 中传 rotationDeg 时缺失坐标。现在错误返回明确说明可用 layout.nudge 的增量旋转，或补全绝对位置，不修改执行语义。
4. 构图 Skill 曾多次追加近似段落。现压缩为目标、图文组织、原料处理、看图后的修改尺度、双页与参考，保留研究来源。不会禁止大纸、规定数量或固定路线。
5. 回看真实教程（研究者观察，不输入对应测试案例答案）可见，大纸本身可以很好地统一画面；问题是纸层职责、露出轮廓、深浅与图文接续。数字纸常被做成相近米白正文卡，因此补充黑纸、深蓝与常见彩纸的合理用途，以及深浅承托、纹样过渡、局部承字的分工；构图测试一并预读 journal-color。
6. 单张其他案例成品对布局关系的表达有限。引入已归档、裁净的另一篇小小彩虹成长记《万能“S”形手帐排版分享》（698f233c000000001a027a90）的框架/成品配对图。它不属于 D143/D146/D153/D158/D162，所有输入使用同图，同一阶段指导与用户提示，不照搬路线、坐标、素材或字句。五案例两难度及双页共十二份输入先准备，再调用模型。
7. 研究阶段预览采样由三张增加至五张，避免把一次只有底纸的自动预览也算成一次完整构图迭代后过早结束。仍按请求与时间预算留存阶段结果，不改变产品生成上限，也不压缩深度思考输出 allowance。

## 实验隔离

所有输入沿用同一 user intent。`structure` 从上轮盲测草稿接续；`concise` 从空白盲测；`roles` 从空白使用同一 D158 风格图，含 D146/D153 两难度；`paired` 从空白使用另一案例的框架/成品配对图。参考和阶段采样不同的轮次不能当作单因素消融；同轮中只因素材与页面配置变化。

素材 PNG、输入 TASK、原作禁用哈希、每请求输入审计、全部 PNG 与可编辑 Scene 均在仓库外 `验收归档/运行记录/双难度教程研究-2026-11-23/progressive-optimization`。原始素材含此前明确标记的遮挡推测补全，不冒称商家扫描。

`structure` 和 `concise` 的主块修改或简化指导均未充分解决独立卡片问题。前者验证了模型能合法裁分实体纸，不能据此声称审美通过。后续结果继续按真实 PNG 判断。

## 用户确认的视觉方向

用户看到新一批结果后明确反馈：“新的一批这几个都挺好的，就是这种效果”。展示过的 `roles` D146-full/D153-full 与 `paired` D146-rebuild/D153-rebuild 中期图均原样保留。后续以这一批的图文穿插、纸层露边和色块关系为方向，停止以“避免大纸”为理由拆散已成立构图。用户没有逐文件指定唯一优胜图，因此不把这句反馈标成对每一张最终预览的逐图验收。

`paired` 两例各完成五次预览；D146 的纸影仍偏重，D153 标题还只是基础字群，留待局部优化。双页开始沿用同一个其他案例框架/成品配对参考，从空白生成 blue 和 contrast 两组；不输入这两组的原作或中间图。

用户随后对已展示的标题反馈“没事的这样很好看”。先保留当前标题，不以技巧数量替代用户审美判断；将这一原则写入 journal-lettering。用户进一步澄清：在此基础上增加描边、背景等变体可以更好，但不作为强制要求。因此标题技法作为可选提升，不等同于取消后续标题能力研究。`lettering` 研究阶段的独立纸边装饰也已分离，避免以后把标题和装饰变化混在一起。

双页两组均完成五张阶段预览：blue 在左右页交换蓝/米白底色，并用深蓝纸条呼应；contrast 用蓝色统一两页、粉色与红色小素材形成局部呼应。初版标题压印刷纹样及意外换行已在后续修正。双页保留原有标题内容，进入局部点缀阶段，不以更复杂字效为前提。

## 双页小纸片接合修正

用户指出部分小纸与大纸重叠过少，产生孤立、突兀感。补充构图 Skill：检查实际可见接合，选择充分搭接、夹入两层、收近内容组等方式，同时移动承字纸的文字与关联点缀；不规定重叠比例，也不强制所有标签都覆盖。新增 connections 研究阶段，以两组 spread-accents 为同轮起点，统一阶段指令，仅修正接合，不重做配色与主体。

## 收尾选择与验证

单页 D153 的局部点缀增加橙色实心圆与纸边连接，保留已认可标题与主体。D146 点缀轮出现围住正文的重复虚线框及不清楚的深色组合图形，收益不明确；选择保留其 titles 阶段，完整失败尝试仍归档，不把“后生成”当成“更好”。两组双页点缀可见圆点跨纸边并跨页呼应，随后针对用户指出的接合问题继续局部研究。

本轮全量验证：npm test 共 2067 项，2066 通过、1 跳过、0 失败；npm run test:ui 七种视口通过。新增接合研究阶段后，study-stage 四项回归通过。真实字体测量核对两张单页及两张双页点缀结果，文字自身框溢出均为 0；该数字不代替局部对比、遮挡和审美观察。

接合轮两组各完成三次预览。可见变化包括蓝色组通话标签收进主纸边缘、右侧题签和图注靠近所属内容；对比组的深蓝侧条搭进纹样主纸、便签靠回布标、下方短注纸与蓝纸及人物靠拢。保留了主标题、正文内容和整体配色。部分小纸的接合仍较轻，不据这两例宣称所有丰富层叠场景已经稳定；后续以用户对实际画面的反馈继续校准，不规定统一重叠比例。最终两组文字自身框溢出均为 0。

当前保留版本位于归档 selected：D146 选 titles，D153 选 accents，两组双页选 spread-connections；索引页提供原尺寸 PNG 与可编辑项目，原始各阶段仍可展开查看。用户认可的是展示批次的方向，selected 中的后续版本是研究者选择，不冒称用户逐图确认。
