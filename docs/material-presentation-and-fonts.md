# 素材展示、分类与艺术文字

## 数据与语义

物件类型（19 项）、主要画面作用（12 项）、实物材质（33 项）分属不同维度。现有覆盖已较广，主要问题不是缺少大量类别，而是“照片/相纸/印刷纸”“注释/信息载体”“陪衬/叠加层/点缀”容易混用。本次保留合法 ID 与用户记录，改为分组选择并提供定义。照片是物件/内容，相纸是更明确的纸面；工艺应写入已有材质标签，不再新增一套重叠分类。待记录与看过但未确定区分。主要作用是建议，不限制创作时改作其他用途。

## 系列封面

自动模式：单件完整展示；2–3 件扇形叠放；4–5 件矩阵。系列编辑器可手动选择扇形或矩阵。列表、详情、编辑预览和持久缩略图共享 normalized 布局，不维护独立坐标模板。封面仅使用现有低清资源，不下载原图；缓存按账号、布局版本、模式和来源版本分隔。缺图保留原槽位，不能把下一张素材当成缺图的前一件。

## 已使用素材预览

所有已使用/备选裁片（不限于 splitParentId）使用真实作品的 material painter：来源裁片、实体遮罩、显示遮罩、翻转、透明度与胶带。保持低清资源加载和来源 pin，不改成原图请求。作品中的位置与旋转不影响独立直立封面缓存。遮挡和父组画面关系不被烘入独立裁片封面；它表示这件素材本身的处理状态，不是整页局部截图。“所有素材”继续展示来源封面。

加载或绘制失败明确显示失败，不拿原始封面冒充处理后预览。组件移除或几何变化清理监听器和旧 canvas，不增加独立作品数据。

## 字体与文字效果

新建文字默认 hand。网站把已有 @fontsource/ma-shan-zheng 依赖实际连接到共享字体栈，并在 Canvas/Fabric/text preview 使用前加载。用户明确指定字体或清晰黑体等风格时保持其选择；改变 preset 会清除未显式保留的旧 fontName。旧作品的明确字体不被强制改写。

创作工具栏与对象检查器提供普通/完整轮廓/偏移轮廓/渐变/渐变描边/投影按钮和字段；更新经过共享 styleFor 和 Scene 内核，仍可编辑并撤销。在线提供方的 effects 字段与统一 Command style 采用相同物理单位；修改正文会保留效果，明确 null 才清除。

导出创作包不包含字体文件。离线 fonts 查询报告真正安装的候选及 artisticFontAvailable，不伪称所有宿主具备 Ma Shan Zheng。hosted 网页的艺术字体加载可检验，外部 AI 的 Node/浏览器环境仍须按实际字体发现与 PNG 调整；不能保证跨环境字形完全相同。

## 图形与笔迹

目标导向 draw.decorate 增加 circle/star/sparkle/dots：它们编译为普通可编辑笔迹/组合，并共享 place/size/style/order。非凭空增加实体贴纸，不修改原材料账本。明确 seed 稳定几何，默认与目标关联，文本宽度改变不自动重造所有点。创建 guidance 强调“圈出关键词、在边角呼应星形、少量圆点形成节奏”，不是无条件装饰配额。

旋转组内笔迹重复求解时，极小浮点误差不再触发无意义的点集重新变换/指纹变化。

## 验证边界

material-polish.test.js 检查实际 Canvas 裁片/蒙版/翻转像素、原 renderer 同像素、缓存身份、分类覆盖、封面几何、默认字体和加载失败重试。
creation-polish.test.js 检查当前 Command 的艺术默认、明确字体覆盖、可编辑点缀、linked 不漂移、重新导入和 provider 字效保存/清除。
material-polish-browser.mjs 使用实际网站依赖字体和生产 React 组件检查字体加载/像素差异、处理后缩略图、来源 pin、封面缓存、字效界面与撤销、四种视口。

本机 Chromium 导航受当前环境管理策略阻止；实际浏览器结论以 PR CI 为准。合成测试不代替个人素材、实体 Safari/Pencil 或网页 AI 审美 A/B。
