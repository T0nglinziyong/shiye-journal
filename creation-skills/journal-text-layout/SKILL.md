# 文字与素材一起排版

文字不是最后填空的图层。先从真实素材图找出可承载文字的区域，再决定图像主体和文字块各占哪里。卡片、便签、浅色纹样、素材内部空区、纸面留白都能写；深色区域只要文字有稳定的明度对比也能写。这些只是候选，不能为了“写在素材上”而压住原有标题。不要仅凭素材类型断定能否写，须查看实际图像、印刷字、花纹密度和裁切后的可用面积。

## 试摆顺序

1. 先确定本页要写的内容和大致篇幅。将标题、正文、H2/H3、边注中真正需要的角色写入 `creation_plan.writingZones`，每个区域记 `surface`、`anchor`、`capacity` 和 `legibility`。一段正文跨多个区域时，用相同 `flowGroup` 和递增 `sequence` 标记阅读顺序。未确定具体位置时描述相对位置即可；看过预览后更新计划。
2. 第一批放大素材时，把计划文字区当作真实对象占位。同一区域可以有底纸、上层照片或贴纸、文字和小图形；叠层必须围绕阅读内容服务。宽而平稳的区域适合连续正文；窄条和异形边缘只适合确实短的标记或边注，不能把一段正文挤成单字竖列。需要较长正文时，为可读面保留足够宽高，不能靠过小字号解决。
3. 文字可以直接进入已有素材。用 `text.add` 创建可编辑文本，`place.reference:"node:<素材图层ID>"` 和 `at:[x,y],unit:"ratio"` 定位在素材内部；需要随素材移动时设 `behavior:"linked"`、`rotationSpace:"reference"`，并用 `order:{after:"<素材图层ID>"}` 保证文字在上层。文字的位置以真实预览为准，不能只按素材外框居中。
4. 若底图亮，用深色文字；若底图暗且平稳，用浅色文字。跨越明暗、花纹或印刷字时，优先移动文字、裁切素材或缩短内容；确有必要再加局部、克制的半透明底色。避免用统一大圆角卡掩盖所有材料。
5. 自动预览后检查阅读路线：标题先被看到，正文能按顺序读完，边注贴近对应图像；段落没有压到重要主体、印刷标题或高频花纹，纸面与素材内部的文字大小有层级。特别检查浅字落在浅底、文字框太窄、正文在卡片边缘垂直排成一字一行等问题；发生时把它移到更宽的纸面或另一张素材，不要只减小字号。发现问题时，先重排图文关系，再微调字号。

允许一段正文穿过数个可读区域，拆成有意义的连续段落，但不要把一句话拆得难以阅读。可以先用大纸或便签打底，再让照片、较小纸片或贴纸跨边叠上去，文字穿插在剩下的可读面；也可以让一张图片承重，直接沿其浅色区域排字。控制 `order`，让装饰盖住纸边、照片角或局部文字以形成层次，但不要遮断正文的阅读。便签并非只能作背景，图像也并非只能被观看；若某素材的浅色位置能清楚写字，就让图文在同一物件上发生关系。纯拼贴或用户要求不写字时，不规划新增文字区域。
