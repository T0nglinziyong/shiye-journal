# 创作指导：从素材关系到可编辑作品

本文件不包含本次任务的素材、风格、纸张大小或用户经历。任务取值统一读取 TASK。

文字、图形、素材是并列的核心构成，不是“贴纸主体加文字注解”。素材少时让真实材料、纸面书写、字级变化和来自材料的局部手绘共同承担版式；不因素材少而默认大片空白，也不要改做大标题加两条彩色信息栏的海报。先稳定主要视觉重量（可以来自任一类别），再补内容、点缀和连接。除明确极简任务外，整页应充实且有层级，保留必要边距而不留下无作用的大洞。

## 先判断材料能说什么

看真实图像的轮廓、方向、印刷文字、视觉重量和可书写空白，再看元数据。不要把素材里印刷的地点、日期、人物当作用户经历。没有图像证据时不要编造细节。

区分主视觉、承载正文的纸面、印刷标题、连接材料和点缀。材料不必全部承担同一种角色。实体尺寸与库存是约束，不是建议。

## 从局部组合开始

先找两个或几个真正有关系的对象：人物与方向、照片与旁注、印刷词与回应、底纸与书写。用 group.create 保留组合内部结构，再用 layer.update 调整整体；不要先把所有完整矩形摆满再往缝里填文字。

在心中比较两种真正不同的关系，而不是只换颜色或旋转角度。构图不必固定为顶部标题、大图、圆角正文框和英文页脚。主次、密度、留白应服务表达。

## 主动考虑加工，但不为工艺数量加工

包装字块、纸片边条、照片局部可以通过裁切形成连接；真实开窗、分片与穿插可创造前后关系。每种工艺应解决一个明确问题。完整使用也可以很好，但要靠图文对话、叠压和视线关系组织，而不是陈列素材。

裁切改变实体可用区域；显示遮罩不等于获得余料。单张材料不能既完整使用又重复使用被切走的部分。透明效果、阴影与白边不能冒充真实镂空。

## 文字和布局一起设计

先找真实书写区域，再决定一段正文、短句、边注或对话。正文可以有推进、停顿和转折；不要求每页都有相同字数，也不要用一串可互换的口号替代内容。

画布的空白就是手帐纸，也能直接书写；不要误以为只有贴上的卡片才可写。若可写卡片太小、图案纸不宜压长文，就把一段随写放在素材之间或沿实物边缘的纸面上，留出可读间距。大片空白通常需要这样的内容与素材关系，而非等下一件素材来填。

内容策略按 TASK.contentPolicy 执行：original 允许原创态度和想象，不虚构用户经历；faithful 忠于原文和提供事实，不添加事件；collage 不自动新增正文。original 不必把每件素材逐项说明成“左边是什么颜色、右边是什么形状”；可从一个看得见的细节写到联想、疑问、轻微的自言自语，再留一个不急于回答的念头。不同文字块应有不同职责和语气，避免整页都是展品说明。

内容足够具体再排版：每页先抓一两个本次素材独有的细节，让一处长一点的随写和几处短旁注从细节生长。不要反复改写同一句抽象主题，也不要把所有新增文字塞进唯一一张卡片；可写纸面、纸边、实体印刷字旁各有不同的阅读距离。少素材时尤其如此，不能用“留给以后再写”替代这一页应有的内容。

文字应与材料共同增加含义，不逐项解释颜色和物件。避免无关英文小标题、通用鸡汤、制作说明和强行积极总结。不要抄示例里的句子。

## 可编辑细节

完成主要构图后，不要吝啬装饰，主动进入细节创作：小素材、贴纸、许可的胶带/裁条与数字图形、短笔迹、艺术字都可以连接区域、回应主题或调整重心。不要还没画就用“保持简洁”否定变化；先实际尝试再看 PNG 取舍，不能把“按需”简化成总是不做；也不能把缺少主块的大片空区用零碎装饰填满。具体方法与工具查 SKILL、PLAYBOOK 和 LETTERING。

线条、矢量图案、手写、荧光笔用于强调、连接或回应，不能默认撒星星圆点。数字图形可以自由设计，但不能伪装成用户拥有的实体贴纸。

优先利用已有纸面的空白，而不是自动覆盖一张通用底色卡。文字放不下先改写、调整宽度或重排，不通过缩小到不可读、放大实物或无提示裁切解决。

## 视觉检查

缩小看第一焦点、阅读路线、整组关系；放大看换行、文字对比度、素材边缘、遮挡和加工细节。双页同时检查左右单页与整体，是否跨页按任务要求。

单独通读新增文字，检查是否有实质内容、是否无凭据地声称用户经历。暂时遮住文字，再看材料是否只是散放。去掉无用装饰，保留必要留白。

实际画面必须从当前 Scene 渲染，不能用近似图替代。Scene 合法只是结构与约束合格。必须打开真正从当前 Scene 渲染的 PNG 后，再决定是否完成。
