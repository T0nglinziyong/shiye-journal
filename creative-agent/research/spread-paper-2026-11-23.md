# 双页呼应与高级纸张图形研究

## 来源与学习范围

复核用户给出的 [不是鸭鸭《A6per手帐配色思路2.0》](https://www.xiaohongshu.com/explore/6ae29df20000000033010256)。已登录浏览器可读文案，下载页面实际视频（18.02 秒），每两秒取帧，观察八组双页：黄蓝、紫灰、绿红、浅蓝黄、棕浅蓝、粉黑、灰绿、白粉。视频与原帧保存在仓库外的双页配色资料目录。作者把主色、辅助色、点缀色作为配色思路；其三色以内建议不转为程序硬门槛。

棕蓝组的左页以棕为大底、白字和黑白心形为焦点；右页浅蓝大底上再引入棕纸。右页局部半透明片跨过棕与蓝，两个下层颜色仍可辨认，深色字与原纸书写形成连续阅读。结论是以面积和局部重复联系左右页，不是镜像版式。照片中的封套、桌面、活页环不当作纸面设计内容；教程画面只由研究者分析，本轮模型不接收此视频或帧。

高级纸面参考现有方案的组织方式：

- [Notebook Backgrounds](https://github.com/ollygadiot/notebook-backgrounds)：重复横线、方格、点阵等笔记纸图案的分类及 SVG 表达。
- [Transparent Textures](https://transparenttextures.com/)：以可选底色叠加轻量表面纹理的思路。
- [Made Good Designs Paper Texture](https://madegooddesigns.com/tools/paper-texture/)：区分纤维、颗粒、色差与做旧，纸感不必靠阴影。

只借鉴通用视觉方法与参数组织；本轮使用项目自己的程序生成代码，没有复制第三方纹理文件或网站实现，不将网页上的素材当成本次实体库存。

## 实现

新增一个高级图形 paper，沿用 graphic.add / layer.update，不另增模型工具。geometry.options 包含 paperPattern（plain/ruled/grid/dots）、grain、torn、translucency、rows、columns。fill 和 stroke 仍沿用共享样式合同。默认米白纸、轻纸纹、无阴影；颜色可替换成常见纸色或与素材形成反差。半透明采用整张纸面统一 alpha，正文作为独立文字图层保留原对比；不是将纸底变浅来伪装透光。不模拟真实光学散射。

图案、纸纹、撕边同属一个可编辑高级图形，缩放时纹样随图形缩放，调整行列数保持既有高级图形的单格尺寸语义。编辑器增加枚举选择控件，同一个参数定义用于 UI、命令 schema 和持久校验。Fabric、缩略图和 PNG 共用 SVG。

纸层与配色 Skill 补充无阴影/极轻阴影、近色或反差、线条纸与半透明层的取舍；双页指导强调各页焦点、主辅色交换、隔缝呼应与重要内容避缝。仍允许用户选择疏朗或丰富，不用教程色数限制用户。

## 真实模型实验设计

两组独立素材池：D143+D153，以及 D146+D162。每组完整素材和精简重建两档，共四组双页。全部统一为每页 110×157 mm，整个双页 220×157 mm；相同用户 prompt、每阶段相同指导、相同工具版本。从空白开始，先打底，再接续自己的打底完成标题、正文和装饰。

无原作、无中间图、无逐例指导、无搜索参考、无 Skill 示意图；模型仅见本次素材和自身渲染。Skill 文字包含已学习的方法，所以不宣称未见教程泛化。原材料仍有先前从遮挡照片推测补全的成分，不是商家原始扫描。

打底 1 张预览，成图最多 2 张有变化的预览；这是阶段停止条件，不是产品生成上限。保留正常深度思考额度，不加独立付费审美审核。结果图和项目、提示词、请求审计及统计统一归档到 spread-paper-study。

## 追加纸纹反馈与固定作品对照

用户认为第一版仍太光滑，新增参考 [画个画吧《Procreate 纸张纹理免费分享》](https://www.xiaohongshu.com/explore/688f4474000000000500a81e)。阅读其图文说明并观察封面和下载一个已加载的纹理样本；没有声称逐张分析全部 18 图。方法是将水彩纸纹理置于绘制内容上方并使用正片叠底。本项目借鉴其密集细颗粒和纸面明暗起伏，不复制分享图片到产品，也不改变真实素材图片。

增加自行生成的周期性多尺度噪声，与原有细纤维叠加，grain / paperSurface.intensity 调整强度。不是只增加纸边或投影。先尝试内嵌 PNG 纹理，发现 Node SVG 渲染器忽略内嵌 image；已移除该实现，改为同一噪声的分级矢量纹理块，保证 Node 与浏览器实际绘制。新增像素回归专门核对噪声层产生可测差异，不能只查 SVG 字符串。

四组付费模型输入与项目仍保留原始运行记录。noise-render 使用同一项目字节重新渲染，构图、文字、素材、纸色和位置均未改变；不冒充一次新的模型创作。纸纹更新期间已启动的模型进程使用各自启动时载入的渲染器，故不将整轮称为严格冻结二进制的统计试验。局部纹理变化用该固定项目对照隔离观察，不为纸纹再付费重跑创作。

## 收尾：标题与纸边实心点缀

再看配色视频中的黄蓝、紫灰、浅蓝黄、棕浅蓝组：红/黄圆点常压在小纸的左右边缘，星形常接住卡片角或不同色纸的交界。实心形状有明确的色块重量，不能用空心圈替代所有关系。它们不是要求每页四角均匀撒点的模板。

发现 Skill 与实现不一致：文字 Skill 曾把局部笔画处理笼统写成不支持，但 `title-composed` 已有按局部 box 遮罩并补笔画、上下拆字、字后图形和字效组合。现改成准确的能力与边界，并将“只换字体不等于艺术标题设计”写入选择流程与看图验收。`glyph.strokes` 仍需准确指定位置，不具备自动理解笔画的能力；错落、旋转是字群排布，不冒称笔画变形。点缀 Skill 增加实心圆/星压纸边的具体选择、前后层序和跨页呼应，仍保留空心圈、胶带等方法，不设统一数量上限。

研究新增 `polish` 阶段，对两组精简素材的自生成双页接续收尾：两组同一用户原始 prompt、同一阶段指令与 Skill，保留主题、标题原文及正文；只优化标题和纸边关系，允许局部调整和删除失败装饰。没有原作、中间图、研究者逐例坐标指导或 Skill 图片。固定保留收尾前结果并用当前纸纹重绘，避免把纸纹变化误算为标题优化。新阶段最多两次变化预览、正常思考预算，不重新生成完整作品。

纸纹调试中还修复了生成器改尺寸时误把 SVG 插值写成逗号表达式的问题：它曾输出数字而不是矢量纹理，使噪声层无像素效果。实际像素回归捕获了此问题；现恢复正确插值且通过回归。测试失败过程保留日志，不将失败版本称为完成。

第一轮收尾暴露问题而非全面通过：两例都开始使用实心色点，contrast 例把色点落在纸边，但标题只加蓝色底条；blue 例逐字标题使用 70pt，字群严重压住正文，第二次预览仍未修好。原因之一是 `creation_inspect` 简要记录返回原生像素 `fontSize`，而写命令用物理 `style.fontSizePt`。现改成简要记录直接给 `fontSizePt`，full 原生字段保留并明确像素单位；不同画布分辨率下均核对同一 18pt 返回 18，不改作品字体本身。用实际失败定位合同单位问题，不只是继续加提示词。

第二轮 `lettering` 从各自原始 finish 项目重启局部测试，避免沿用第一轮失败大字。两例仍使用相同指令：物理字号和可用范围为起点，选择字形处理并组合字后图形或描边，不能只加矩形底条；保留正文和主题。此要求是本轮能力验证目标，不作为所有用户作品必须使用复杂标题的硬规则。第一轮失败图照常归档。

第二轮仍有明显偏离：blue 仅变色加淡影，contrast 改写与增加了非目标文字。继续追到上下文整理发现：`modelContext` 的窗口从首个 assistant 开始，开场追加的 user 阶段要求和预读 Skill 位于其前，会在第一次工具调用后从后续请求消失；fallback memory 没有保留该 user 原文。这比单纯提示不够强更直接地解释了研究范围漂移。现在将首次 assistant 之前的纯文本 user 补充要求固定保留一次，已有初始任务与图像管理逻辑不变，单元测试覆盖 12 轮、有/无当前项目、原消息不变。

再次以同一 `lettering` 阶段要求、原始 finish 项目测试，输出另存 `lettering-fixed`。将本阶段预览预算增加到 4，容纳配方替换时的删除、重建及观察修正，不把只删除旧标题的一张中间图当作足够的视觉迭代。保留正常模型思考输出量及原有 HTTP/时限保护。这个预算仅用于研究，不限制产品创作。

## 本轮结果与保留问题

- 四组双页完成布局及成图，之后两组精简素材各完成三轮局部研究。合计 14 个阶段、59 次 HTTP 请求，服务返回 total_tokens 合计 2,794,880（输入输出合计，未按缓存价换算费用）。最终修复后两例分别 8、7 次请求；未为纸纹单独调用模型。后续暂停追加付费装饰，避免在构图退化的基础上反复微调。
- 输入/项目审计通过：同一阶段内提示一致，无外部参考和案例指导，当前可编辑项目与报告 PNG 版本对应。没有把工程测试通过当作审美通过。
- blue 最后版本恢复清楚的描边错落标题，橙蓝实心点压在牛皮纸边；中间拆字效果难读，被撤回。不能宣称已稳定掌握拆字/笔画变形。
- contrast 第 3 张的逐字错落、字后蓝块与红色短块较清楚，并加入压在标题纸边的红圆；最后一张字距挤紧、轮廓过重，可读性下降。selected 保存研究者选择的第 3 张原始模型 PNG 和对应项目，不作人工美化，不冒称模型自动选优。所有失败与最后一张仍保留。
- 两张研究选图的文字自身框审计分别 17/16 个文字节点、0 溢出；此检查不识别跨层遮挡。实心圆使用得到验证，五角实心星在本轮仍未充分验证。
- 最终 npm test：2065 项、2064 通过、1 跳过、0 失败。UI 7 类视口通过；纸张浏览器/Fabric 导出对齐通过；未部署，未做实体 Safari/Pencil 验收。

## 用户指出的排版退化（不得以局部技巧掩盖）

用户认为本轮每页像纵向摆几张纸再填字，较之前单页缺少层次。复看旧 D153/rebuild 与 D146/rebuild 原始成图：D153 的浅蓝点纸贯穿上中下、白色正文卡与树便签/人像相互交叠，小纸条形成错位；D146 的标题横带跨在星月纸、蓝布标与下部正文之间，蓝布标被标题带压住局部，形成前后连接。本轮对应双页把主要纸面做成大矩形写字区，标题单独居上，贴图与正文更分离，局部点缀不能补偿结构。

因此本轮仅认可纸面能力、单位合同与上下文保留的修复，**不认定双页整体排版优于旧单页**。色彩呼应不能替代每页内部图文组织。阶段切分和保留已有排版的研究要求可能固化了早期平板结构，文字量目标也可能让模型优先填满大卡片；这是基于画面和指令的解释，不是单因素对照证明。前后素材池/阶段指导有变化，不能把退化单独归因于纸纹、去阴影或某一个 Skill。

下一轮应先使用原来的单页案例做构图回归，比较纸片露边、大小对比、局部遮叠、标题/图像/书写的连接，再验证双页呼应。可以直接写在底纸与已有素材写面，不把每段正文默认装进独立矩形卡。丰富层叠与疏朗仍由用户选择，不规定统一层数、固定留白或强制增加纸张数量。
