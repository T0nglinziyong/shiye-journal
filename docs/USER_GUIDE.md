# 拾页操作速查

**导入**：素材库 → 添加素材（相册/拍摄/文件）→ 调整纸张四角与方向 → 预览校正 → 检查自动识别边缘，必要时手动补框 → 确认保存。

**整理**：在系列中添加素材，设置标签、种类、尺寸和使用状态；不确定的识别结果标记待检查。批量操作前先确认选中数量。

**创作**：素材加入“本次创作” → 搭配 → 选择手账方案 → 可编辑画布。笔迹、图形、文字、素材、纸张都可以独立编辑。保存后查看右上角同步状态。

**断网**：浏览器内暂存并不等于云端已收到；网络恢复后按同步状态重试。退出前检查待同步项，勿清浏览器网站数据。若长期离线，使用待同步应急备份。

**备份**：完整备份包含已同步作品与素材，ZIP 格式由新版本提供。离线应急恢复包仅用于未上传的修改。两者都可能含私人照片与日记正文，需妥善保管。

**更新**：完成当前画布编辑后点击提示的“更新拾页”；更新前必须成功保存本机修改。请不要通过清除网站数据解决更新问题。

**出现错误**：先看“同步状态”与“数据与诊断”，区分原图缺失、网络失败、模型接口和识别 Worker 超时。仅导出不含私人正文的默认诊断；若需要客服/开发协助，记录出现问题的操作步骤、设备浏览器与 Commit 版本。
