# 手帐创作参考：公开方法到拾页任务包

这里总结的是公开的创作方法，不复制品牌模板、用户上传图片或私人日记。预设图由拾页按当次风格与用途在浏览器中绘制，仅表示区域关系。

- [Hobonichi 官方用法合集](https://www.1101.com/store/techo/en/collection/)把日记、粘贴收藏、日程、工作学习、家庭等区分为不同用途；同一纸张允许文字、照片、票据、图画比例不同。拾页因此先按“用途”确定内容与阅读顺序，而不是给所有风格套同一版式。
- [Hobonichi 一日一页说明](https://www.1101.com/store/techo/en/about/)强调方格/横线既可辅助写字与贴图，也不必强制使用。拾页的格线、色块和相框只在组织信息时出现，不能机械地为每一件素材生成底框。
- [TRAVELER'S notebook 官方介绍](https://www.travelers-company.com/products/trnote/about)将地图、票据与随手记录用于旅行主题；[官方定制用品](https://www.travelers-company.com/products/customize)展示标签、票据与贴纸等可组合元素。拾页的旅途参考因此采用“路线—票据—见闻”的动线，但不虚构具体地点与日期。
- [Bullet Journal 官方方法](https://bulletjournal.com/blogs/faq/what-is-the-bullet-journal-method)区分短记录、任务状态、日记和主题集合。拾页的清单用途因此必须有可编辑条目、勾选与分组，而不只是空白清单框。
- [Canva/Affinity 官方排版课程](https://www.canva.com/design-school/lessons/affinity-layout-studio/)描述用网格、图框、图片、文字框组织照片书与跨页阅读。拾页借鉴主次、对齐、边距和跨页节奏，不照搬课件中的成品。
- [Adobe Express 拼贴灵感](https://www.adobe.com/in/express/discover/ideas/scrapbook)展示纸纹、照片、图案、胶带等混合媒材的多种组合。拾页只允许真实已有实体素材被摆放或合法裁切，新增数字笔触须保留为可编辑图层。

实现原则：同一风格×用途提供简洁、均衡、丰富、实验四种匿名构图，用作模型思考起点，不作为要照抄的最终图；每件实物仍由本次素材照片、尺寸和库存决定。完整 21 种风格与 6 种用途的可操作描述在 `src/creative-design-guide.js`，四张图与提示在 `src/creative-reference-presets.js`。
