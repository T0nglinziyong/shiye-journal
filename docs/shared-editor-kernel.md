# 人工编辑与 AI 的共享 Scene 内核

## 边界

Fabric 仍负责命中、光标、输入法、指针采样和临时显示；React 负责面板和生命周期。Command JSON 是离线 AI 输入格式，不要求浏览器写文件、运行 CLI，也不把视图缩放、选区或每个 pointermove 存成作品操作。

人工操作与 AI 调用相同的属性/单位/文本重排和 Scene 几何内核。相同输入和相同策略产生相同结果；输入适配层可以明确指定不同锚点，例如人工文字编辑保持框顶边，AI 可指定中心。最终 Scene 是唯一作品。交互预览不是第二份可持久化模型。

## 模块

- `scene-node-properties.js`：公共属性与 mm/pt/ratio 转换，创建/更新共享。
- `scene-edit-kernel.js`：类型化属性、世界/父级坐标换算、文本重排、锚点与 linked 求解。失败恢复本次节点和受影响的关联几何。
- `scene-edit-policy.js`：可信调用方提供的策略和目标/来源状态绑定的临时人工确认；不读取 Command/Scene 中的权限声明。
- `scene-structure-edit.js`：分组、解组、移入、顺序、删除及视觉复制的原子提交。失败恢复树引用和材料账本/余料/收据。
- `scene-material-edit.js`：替换素材、胶带重塑、人工裁片几何与恢复基线；复用已有几何算法和真实来源校验。
- `scene-ink-edit.js`：笔画结束后的世界空间擦除及父级局部坐标写回，保留压力和图层身份。
- `scene-edit-session.js`：隔离的检查器/剪刀编辑会话。确认提交核对原 Scene 指纹，取消不改存档；失败仍保留会话供检查。

`creation-node-update` 不再拥有另一份字段换算或文字重排逻辑。Fabric bridge 只把实际交互结果变成变更提案，然后调用共享批处理，不能直接写入实际 Scene 的几何字段。

## 策略与人工确认

| 行为 | AI | 人工 |
|---|---|---|
| 普通属性、数字对象尺寸、合法定位 | 共享校验 | 共享校验 |
| 修改被用户接管的 AI 节点 | 拒绝 | 允许明确操作；保留接管事实 |
| 修改锁定节点或锁定祖先的子节点 | 拒绝 | 拒绝；先解锁 |
| 主动解锁 | 不能自授 | 显式界面动作 |
| 实体素材视觉缩放 | 拒绝 | 本次目标/来源状态确认后允许，源尺寸和库存不变 |
| 实体素材视觉复制 | 拒绝 | 确认后产生同源视觉副本，不新增实体份数 |
| 直接编辑实体裁片几何 | 只能走受校验工艺 | 确认并通过来源/用量校验 |
| 提交检查器/剪刀隔离会话 | 不作为 AI 原始 Scene 注入入口 | 可信实时会话、未过期时提交 |

策略由模块内部登记对象识别，不允许序列化后回放。确认只存于内存，绑定目标 ID 和相关素材状态；不得持久化为用户全局“始终允许”。AI payload 即使写入 `actor: user`、人工标记或伪造确认对象也不能获得这些权限。这是宿主与不可信命令之间的进程内边界，不是用来防御能任意执行宿主 JavaScript 的攻击者。

锁和保护同样覆盖 linked 的间接改变，不能通过移动参照对象绕过一个已锁定的跟随对象。权限失败整次回滚。

## 已接入的人工路径

1. Fabric 文字输入、对象平移/旋转/缩放写回，保持原 IME textarea 与光标对象。
2. 文字/图形常用面板、检查器属性、图层可见/锁定、翻转与备选状态。
3. 单对象和多选、套索变换、组合/解组、重父级、重排、删除与视觉复制。
4. 画笔结束提交、连续笔迹组织、普通/整笔擦除（含旋转父组中的笔迹）。
5. 素材替换、胶带重塑与检查器几何提交；剪刀仍使用成熟的分割算法，在共享会话边界提交。
6. 纸色、图案、分栏等外观参数。

套索/对象拖动预览不改变持久 Scene，松手合并为一次提交；取消、权限拒绝不会形成有效作品更改。已有历史、可靠本机暂存和同步系统继续工作，不把每个采样点写成一次撤销或云请求。频繁属性更新只复制目标节点与相关联动几何；较少发生的结构/实体几何编辑有完整树事务保护。

## 不在本轮迁移范围

纸张规格/单双页切换仍使用原纸张几何算法；任务内 AI 不允许改变这些规格。历史版本恢复、作品导入、云端合并和底层裁切几何不强行改成公共 Commands，而继续保留各自的数据完整性边界。Fabric 原生字宽与光标测量、真实字体后端没有重写，不能宣称所有字体跨平台逐像素一致。

本轮不移除交互库，也不引入旧命令兼容入口；未来剩余路径必须继续接入共享内核，不能新建手工/AI 两份业务状态。

## 验证

`tests/scene-shared-edit-kernel.test.js`：实际 AI 命令与人工修改的完整文字几何一致性，重开与 linked，伪造策略/确认、来源状态绑定、取消、锁、批处理回滚、结构账本回滚、隔离会话过期、嵌套组与压力笔迹、同源复制和素材几何。

`tests/shared-editor-kernel-browser.mjs`：真实 Chromium/Fabric 输入时保留 textarea；文字保存与共享排版一致；pointermove 仅预览、释放一次提交；素材缩放取消/确认；四种视口模拟。加入 Interface browser CI。既有编辑器、工艺与离线创作 ZIP 回归必须继续通过，不能以新测试替代旧的。

模拟浏览器检查不证明真机 iPad/Safari/Pencil 的时延与手感，最终状态以当前提交的 CI 为准。
