# 手帐写什么

先看用户指定的文字和事实，再看素材的物件、印刷字、颜色和场景。没有指定主题时，从服务器提供的 365 主题候选选一个切口；候选不合适可调用 `search_writing_topics`。题目是启发，不直接抄成标题或正文。一个页面通常只需要一个主问题，旁边的图注可以从不同角度回应它。

## 可用写法

- **具体片段**：从一个动作、声音或触感开始，写发生了什么、细节如何变化、叙述者后来怎么想。结尾可以留在物件上，不必升华。
- **观察清单**：两到五条互不重复的小发现；各条有可见细节和态度。可写在已有纸面的连续可读区域，或作为边注；清单形式不意味着需要另加窄长便签。
- **写给某物的信**：收件人可以是季节、旧照片、明天的自己或一张车票。开头点明对象，中段说具体缘由，结尾留一句真正想说的话。
- **想象练习**：允许虚构天气、地点、动作、人物和小事件，写得像微型故事。第一人称是作品里的叙述者，不代表用户真实经历。
- **自问自答或对话**：用两个短声部推进一个问题，不把同义金句排成列表。
- **回望与对照**：一个旧细节和一个新细节形成差别；用户提供事实时准确保留，没有事实时写成明确的想象或普遍观察。

参考小红书的手帐话题分享、日记法和日常记录经验，但只学习方法，不复制作者句子或假装知道用户的生活。读者不应看到“画面中”“这个素材代表”等设计说明。

## 长短与排版

文字量服从本次文字参数和用户原文，与画面疏密分别判断。丰富层叠可以少字或无字，疏朗页也可以有一段连贯正文。先确认照片多/少、文字多/少的组合：照片多时让图注贴近对应图片，文字多时先保证连续写面，两者都多时减少无关点缀并按内容分区，两者都少时按用户疏密选择集中成簇或补充有意义的视觉层次；这些是取舍，不是固定四套坐标。

开局给出的 `writing.length.characters` 是暂定范围，不是字数配额。先与素材构图一起安排标题、正文和边注的可读区域，再按最终文字框宽、高、字体与行距修改。区域可以在页面空白、便签、卡片、素材内浅色位置或任何文字有稳定对比的地方；一张大素材未必会减少可写面积。具体图文定位参见 `journal-composition`。长文、短记、边注或清单按文字需求和内容选择，不按画面疏密机械分配。文字需要自然换行，不能靠压小字号硬塞。若内容太长，先删重复和套话；若页面显得空，不补无意义金句，换成真正有内容的段落。

可先写出核心段落再围绕它排版，也可边试摆边改写；标题和正文的落点要一起复核。`writing.length.characters` 仅按纸张面积估算首稿；真实篇幅取决于可写面、字号、行距和图文关系。按内容的自然转折划分段落：可以在同一张纸的不同位置，也可以跨不同底纸、便签、素材内部或页面空白。区域数量、颜色和大小由内容及画面决定，避免所有段落挤在一处，也避免机械地为每段配一张等大的卡片。用纸边、图案或细线承接阅读路线。预览中若标题与第一行交叠、后放的纸盖住前一段，或字距、行距因硬塞而显得发闷，先缩短正文并重排文字框，不要直接缩小字号。

把段落与小标题视为有大小和方向的字群，沿纸的空白、低纹样区域与背景共同排布。同一区域也可以让上方短段靠左、下一段向右下错开，形成对角线；或上部从左向右，经过中部过渡到下方左侧，再向右收尾，形成 Z 形读序。用段落宽窄、长短、小标题和落点组织路线，每段内部仍自然换行；不是让每一行强行斜排、拉大字距或拆散句子。H2/H3、小问题、日期、关键词可作为阅读锚点，数字也可独立放大参与构图。多个字群可以同在一张纸，也可延续到原页或相邻纸面，保持字色对比与读序。空间不等于新建便签，不必把所有段落排成等宽齐头的一列；横直结构适合内容时也可保留。

正文可用 `text.add`，标题和 H2/H3 可用 `creation_title` 或 title-art 的 composed 变体。正文可以按意思拆成数块，分布在原页背景、已有纸面和素材内部的可读区域，按阅读路线连接；不同承载面之间不能把句子割断。不要将整段正文做成花字。标题、正文、局部注释的字号与装饰密度逐级下降。

## 内容边界

`original` 模式允许创作性虚构；`documentary` 模式只整理用户事实与可确认观察；`visual` 或 `textMode=none` 不新增文字。用户明确指定的原文、日期、姓名和事实优先准确保留。虚构场景可以有生活感，但不能声称是用户已经做过的事。原创页可以自然写成观察、愿望或想象中的片段；除非用户要求说明创作过程，不在画面追加“以上为虚构”“写给虚构的自己”等免责声明或设计说明，也不借教程日期冒充用户记录。

## 时间轴、条目与素材内写字

有真实时间顺序时，纵轴两侧可以写长短不一的记录；没有顺序时，按主题分组而非硬造时间表。清单和编号帮助回顾，但不从教程借用日期或事件。素材少时，文字、细线和可编辑小图形也能构成完整页面。

有可读留白的印字卡、便签、浅色图案纸都能承载正文。先观察局部比例框，再用 `record-on-material` 或 `text.add` 贴着该素材定位；后者需要 `behavior:linked` 和正确层序时先看精确合同。末行越界时缩短或换位置，不靠极小字号硬塞。

需要自动形成记录组时使用 `record-checklist`。`parameters.variant=timeline` 表示按实际顺序的时间轴，`columns` 是双栏短记，`number` 是强调序号的短记；省略变体是清单。它们是内容排版工具，不替代正文写作，也不要求每页都用。

## 可组合的展开方法

时间顺序帮助找题；事实—感受—思考—行动帮助延展一个片段；视觉、听觉、触感等细节让观察具体。可用其中一部分，或自然组合，不要求每段填满栏目。已有用户原文可先形成连续写面，再围绕内容安排纸层和装饰。只有原创模式允许想象，纪实信息不足不补造事件。

正文不应永远缩进一张独立大卡片。短句可靠近有关图像，长段可在连续的原纸或纸层露出区展开；用自然转折连接这些区域。是否需要另外的底卡取决于对比与阅读，不因“有正文”便默认生成奶油色矩形。

多作者交叉来源、实际阅读范围和方法边界见 `creative-agent/research/tutorial-expansion-same-source-2026-11-23.md`。

## 正文的真实排版检查

先确定一段文字在当前底纸上真正可读的连续区域，避开已有标题、编号、图案和纸缝，再给文字框宽高。`text.add` 的高度是最小值，超长文字仍会继续往下排；不能用它保证末行不越界。可在同一事务中用 `text.fit` 按真实可用宽高和可读字号范围适配，工具有渲染器时按实际字体测量。若最小可读字号仍放不下，改写重复内容或分到另一个连续写面，不截掉用户原文，也不无限缩字。文字行数服从区域与内容，不把标题的单行限制照搬到正文。

浅底深字、深底浅字要按整段覆盖的区域判断；纸纹繁密时还要检查局部对比。正文与已有小标题之间留出实际行距，窄边注不能意外变成一字一行。预览中读出首尾两行，检查末行、人物脸、印字与段落相邻处，再进入装饰。

落字后的局部检查：逐行确认开头、末尾和每个字形，正文与竖排注记都避开实物图钉、孔洞、星纹和高反差印花。把文字升到最上层不能消除底纹干扰；先在现有写面局部移动、分段或调换行，不为每段话机械新增底卡。图像轮廓接近文本框不一定遮字，以真实预览里的笔画为准。
