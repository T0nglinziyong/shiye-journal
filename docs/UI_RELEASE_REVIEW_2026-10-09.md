# 拾页 UI 发布审查记录（2026-10-09）

## 本轮界面规范

- 创作页顶部：所有屏幕只显示「完成」与「导出」两个操作，自动保存不提供重复的保存按钮；历史、撤销、重做仍在编辑工具栏中。
- 创作工具：素材、图形选择弹窗采用相同的视觉规格。**宽度 >= 900 CSS px** 显示每行 **3 件**，其余宽度每行 **2 件**。桌面弹窗至多 432px；窄平板至多 330px，手机至多 86vw。每件缩略图最大高度 74px（窄屏 70px），标题在超长时省略，原素材比例不受裁剪。
- 素材弹窗高度不超过 `min(56dvh, 440px)`（窄手机为 `min(52dvh, 400px)`），仅内部素材列表滚动；图形列表可滚动且 `max-height: min(38dvh,330px)`。弹窗定位优先向工具按钮下方展开，空间不足时向上，并按窗口边界限高、水平限位。
- 素材/系列/作品选择栏、导入确认页、最近删除、筛选菜单沿用 PR #70～#76 所统一的样式和行为。复核实物尺寸、素材件数、作品图层可编辑性不会因 UI 修改而重写。

## 全面手动验收命令（本机可执行）

```bash
npm ci
npm run build
npm test
npm run test:ui
npm run dev -- --port 5173 --strictPort
# 另开终端，在独立的本地测试数据库/浏览器数据目录运行
SHIYE_TEST_URL=http://127.0.0.1:5173 npm run test:editor-layout-browser
SHIYE_TEST_URL=http://127.0.0.1:5173 npm run test:editor-browser
SHIYE_TEST_URL=http://127.0.0.1:5173 npm run test:selection-browser
SHIYE_TEST_URL=http://127.0.0.1:5173 npm run test:layout-browser
SHIYE_TEST_URL=http://127.0.0.1:5173 npm run test:responsive-browser
SHIYE_TEST_URL=http://127.0.0.1:5173 npm run test:interaction-browser
```

还需在 iPhone Safari、iPad Safari（横/竖）、Windows/Mac Chrome/Edge/Safari 核对：顶部按钮、图形/素材双/三列、画布缩放、虚拟键盘、拖拽、弹窗展开/收起、素材单件计数、作品自动保存与导出、断网/恢复同步。尤其检查用户已有的多个真实素材、大容量作品、使用中的账户权限、COS 图片可用性。

## Git 分支及部署约束

- 日常开发先进 `test`；正式发布必须经 GitHub PR 合入 `main`。Vercel 正式项目应以 `main` 最新 SHA 的 Git 部署为准。
- 用户明确允许 GitHub Actions 额度不足的手动检查流程，但不能把静态检查等同于真实设备验收。
- `main` 已合并且 Vercel READY 也不等于业务端到端验收通过；发布后应继续实际检查关键页面和账号同步行为。
