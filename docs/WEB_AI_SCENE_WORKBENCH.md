# 网页 AI 统一创作工作台

## 唯一数据与交付

网页可编辑任务统一导出 `scene.json`。其中 `page` 是应用原生 Scene v2，`layers` 为唯一对象树。工具调用、比例坐标便捷页面和 Craft Plan 都是工作输入，由编译器更新同一份 Scene；最终只返回 `project.shiyeproject.json`，不导入工具日志或计划。旧网页输出入口移除，需重新导出当前任务包。API 设置不决定网页任务格式；纯图片任务仍是独立交付方式。

工作文件保留任务原有场景，不用示例覆盖。素材图片绑定导出时的固定版本，source 和纸张物理规格不可改。人类在任务开始前锁定/接管的对象受到保护；本次 AI 直接修改与工具修改可以交替执行。

## 一次交付中的内部循环

1. 阅读主题、正文事实、素材加工方式，查看素材和已选参考。
2. 构思不同的内部构图，选择适合主题和素材的一种。
3. `self-test` / `inspect`：检查环境、完整 Scene、来源和当前摘要。
4. `compile` 接受便捷输入；`apply` 按 `baseSceneHash` 原子执行工具和精确操作；也可直接编辑 Scene。
5. `preview`：结构、实物来源和用量校验后生成共用 Canvas HTML。
6. 在环境允许的真实浏览器中渲染、查看实际 PNG；检查并修订。
7. `pack` 核对最终 Scene 与生成预览的哈希，输出唯一图层 JSON。
8. App 使用相同合同独立检查导入结果，再用共享渲染器呈现。

任何一次原子编辑失败都保留原工作文件。修改后清除旧交付；直接改文件后，旧预览无法通过 pack。运行时不联网、不使用账号或密钥。JSON 上限 8 MB；组深度、节点和路径点数沿用原生数据预算。

## 静态能力

| 领域 | 能力 |
| --- | --- |
| 真实素材 | 固定图片引用、裁片、复合蒙版、窗口、撕边/齿边、视觉选区取材、父片拆分与余料、平面两孔穿插 |
| 数字图形 | 预设形状、自定义路径、多色矢量、描边、透明度、混合、蒙版 |
| 文字 | 可编辑正文、字体/字号、粗斜体、对齐、行距、段距、字距、文字装饰；本地字体数值路径可用于镂空 |
| 笔迹 | 独立笔画、压感路径、多种笔型；抬笔拆成下一节点 |
| 对象树 | 多层嵌套组合、增删、精确属性修改、重排、跨组移动、组合刚性变换 |
| 页面 | 纸色、底纹、栏线、跨页中线 |

底层已支持这些静态数据；此改造扩展网页合同和工作台，使其不再受便捷排版字段限制。未引入交互口袋、翻片、脚本或外链执行。AI 不得通过手工变形/复制标记规避实物尺寸与来源规则。既有手工变形可原样保留。

## 审美与证据

任务包含主次、阅读路径、素材色彩、纸张触感、留白、叠压目的、文字内容真实性和字体层级的指导。参考是方法，不是固定版式；不强制裁切数量、装饰数量或机械网格。每次最终看图需指出具体问题与对象，再局部修订。

结构合法不等于美观；生成 HTML 不等于模型实际看过图片。清单明确保留视觉复核未验证状态，不能伪造审美通过。环境字体可能不同，原生文字仍可编辑；跨设备完全一致的字体文件不在本次保证范围。新包仍需通过实际模型创作评估主观质量。

## 验收

- 单元：工具/便捷页面/计划→原生快照→App 导入，来源和加工权限、嵌套组/蒙版/多色路径/压感、原子失败、过期预览、直接编辑后继续工具修改。
- 真实 Chromium：导出自包含包，运行 Node preview/pack，打开真实 Canvas，导入同一最终 JSON，像素精确一致；中文无方框，四种视口无水平溢出。
- Fabric 回归：编辑画布、封面和导出一致性，包括穿插与笔迹。
- `npm test`、`npm run test:ui` 为合入前门槛。浏览器合成测试不会调用付费模型或修改真实账号。
