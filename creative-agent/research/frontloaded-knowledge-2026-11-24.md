# 通用知识前置、方法合并与参数精简

## 纠正过度压缩

改动前八个 Skill 正文共 26,121 字符（不含 front matter 与运行时方法目录）：accents 3,615、color 1,596、composition 2,079、graphics 3,984、lettering 4,687、writing 3,013、paper 5,558、photo 1,589。第一版合并知识只有 3,644 字符，缩减约 86%。主题覆盖并不等于具体做法完整；用户指出新作品的排版不如此前，不能把这种主观变化直接归因于压缩，但过度摘要需要纠正。

恢复教学的 v22 为 15,425 字符；随后补充背景书写与深叠压后，当前 `runtime/creative-knowledge.mjs` 为 16,615 字符，保留八专题的具体构图示例、纸层接合、写面选择、数字与字群、纸边点缀、配色及看图修正。删去参数目录、研究引用、重复段落与同义提醒，复杂字形和裁切的精确合同按需查；不是把原文机械截短。没有固定纸片数、装饰数或留白比例。原 Skill 完整专题仍可查询。

知识作为固定任务消息的一部分从开局提供，最新观察替换与历史压缩均保留首两条消息。移除逐轮催促补读 overview 的提示，模型可直接结合全部通用知识操作。

## 减少入口，不删掉表现能力

30 个是配方方法，不是首轮同时展示的独立 API 工具。首轮仍为 13 个常用 API。方法目录由 30 个入口收为 18 个：13 个标题入口合并成 `title-art`，具体写法作为 `variant` 按需查询；旧标题 methodId 不再接受。原有 23 种标题写法全部保留（含此前各方法默认写法和变体），所以不能声称审美选项也减少了 40%。目的在于同一能力只认一个入口和一套共同字段。普通标题效果优先 `creation_title`，复杂拆字、穿字、多层底形才查配方。

常驻标题工具不再两次展开完整渲染器 Style_text：整体保留常用字体、字号、字色、粗斜体、对齐、行高、字距与描边；词组只写字体、字号、字色、粗斜体的差异，其余继承。layout 默认 plain，effect 默认 none。更细的样式编辑沿用 layer.update。原始标题 schema 9,547→6,354 字符；运行时添加版本别名后长度略有不同。

配方采用 place / size / style / content；字体参数统一后也用于内部宽度估算，防止样式字体与测量字体不一致。所选预设的默认 style 与显式 style 合并，避免只换字体就丢失预设反白等效果。非组合字形变体不再展示不会执行的 glyph / letterStyles / backgrounds / accents 字段。全方法及变体例子验证公开参数往返，并比较标题生成的完整子节点，不能只比较操作数量。

## 验证与限制

v21 是过度压缩版：同一组自有八件素材、五单页与三双页跨案例参考，low 思考、空白开始，无中途人工指导。6 轮 / 239.8 秒；未命中输入 100,832、复用 220,416、输出 37,762 token，缓存命中 68.6%，工具错误 0。纸边圆星有所加强，但构图仍规整且没有大数字，不能称为全面审美改善。

v22 使用恢复后的详细知识及合并后的方法目录，保持相同素材、参考、任务与 low 思考；结果与最终验证记录在下文。对照是小样本，并且同时修改了知识和工具，不能单独归因于知识长度。

私人素材、请求记录和结果图位于私有验收归档，不提交仓库。案例输入尚未由本 PR 启用到生产；未合并、未部署、未作实体 Safari 验收。

### v22 真实结果

9 轮 / 293.2 秒（约 4 分 53 秒），未命中输入 122,402、复用 441,600、输出 40,666 token，包含辅助审查；缓存命中率 78.3%。工具错误 0；第 1 轮约 82 秒出现初摆。9 次主创作请求的首两条消息只有一个指纹，没有重复加载 Skill overview。首轮输入 42,913 token；详细知识显著增加上下文，不能说恢复教学内容没有成本。

对比 v21，时间约增加 53 秒，未命中输入增加 21,570，输出增加 2,904；缓存比例升高也不意味着总成本减少。构图出现较明显的跨纸人物、纸边圆星和承托露边，但右页仍偏多块文字卡，大数字没有真正发挥作用，标题主要为基础排字。本次没有使用 title-art，故真实测试验证了常驻知识与常用编辑路径，标题高级变体合并由回归测试验证，不能宣称真实模型已主动使用了高级标题。

保留这张结果作为透明对照，不将“运行完成”解释为已达到最佳审美，也不因此上线。


## 背景书写与深入叠压修订

用户指出 v22 仍将新纸主要当作段落容器，且叠放浅、方向单一。调用证据显示下方承载“下一站，随心”的 blueStrip 来自原素材 m8；noteTitle / noteList / noteNote 则是新增数字纸。不是所有窄条都由模型生成，但将长条自动转成独立短句便签的用法确实仍存在。

发现两处与共通教学存在张力的反馈：独立审查曾建议把纸外正文搬入空着的卡纸；几何反馈曾把正文左边线错开列为优先核对点，并建议共同中心。虽不是硬约束，仍可能鼓励卡内书写和横竖对齐。改为平等接受背景正文、纸内正文和对角错位，只在读序、可读性与实际联系有问题时建议修改。

通用教学与原 Skill 同步补充：书写区域不是纸张对象；纸可不写字而共同承托图片和另一片纸；下层允许藏住较大部分，从最终露出的边角反推位置；对角构图是位置关系，并不要求旋转所有对象。提供深入斜向叠压、横竖穿插和背景续写的组合例子。浅搭边且一段一卡时，可以保留正文撤下多余底卡，或把纸移到主簇下露边。没有设置重叠比例、强制斜排或纸片数量。

v23 保持相同八素材、八参考及任务，仍由模型自主创作，未注入本例坐标或修图指令。


## 单页教程素材回归与主体可见性

用户指出最新双页仍浅搭边、部分文字换行不自然，进一步要求回到真实教程素材做单页测试。采用此前 D146 / D162 的独立提取和复原素材（遮挡部分为推测复原，不是作者原始扫描件），统一日常自由创作提示词；清除旧 TASK 中的案例坐标和排版指导，不提供目标成品、中间图或 Skill 插图。完整输入和输出仅存私有归档。

无参考基线：D146 16 轮 / 298.7 秒，未命中输入 178,628、复用 868,224、输出 51,409；D162 10 轮 / 208.0 秒，未命中输入 111,114、复用 455,040、输出 36,044。两组均未使用裁切，主要靠整料移动和层序；D146 新增底纸遮盖印花并反复修正文，D162 则是大纸嵌套。不能因工具完成或看到深叠压就称审美通过。用户明确指出主体被纸压住，因此不接受这两张作为上线验收。

修复实际调用中暴露的反馈问题：常驻笔迹简述补上 geometry.unit=mm，并明确笔迹不用 fill；无效 JSON 回报解析位置和数组/对象闭合提示，只重试失败调用，仍不猜测执行无效参数。D162 的两次 JSON 错误是 operations 数组末尾闭合错误，不是输出被截断。

D162 跨案例复测：同素材、同提示词，加入其他四单页和三双页，排除 D162 成品；6 轮 / 145.0 秒，未命中输入 84,286、复用 226,560、输出 22,367，无工具错误。主体小熊、心形、茶杯展示更充分，但仍偏单块大写面。这个小样本同时包含错误说明修订，不能把全部改善归因于参考图。

针对遮挡意见，将“底纸可大幅藏住”限定于承托角色的素纸或重复纹样纸；主体数字、人物、图案与有效印字应保留辨识部分，不能仅凭矩形外框当作底纸。支持有意的局部取用，不要求每个素材出场或完整露出，不自动把所有图案提到顶层，也不设统一遮挡比例。共通常驻知识当前为 16,813 字符，原 Skill 和独立审查同步。D146 继续用排除自身答案的七参考独立复测，结果待记录。


### 重整纸层教学与开局裁切

用户进一步要求不要逐项追加“要/不要”，并明确新增写字纸应压在至少两个其他对象下。将 paper-layering 的重复段落改为一条连贯的方法：素材簇和角色、显露与遮挡、写面嵌入、整料裁切、预览判断。保留三种可组合的空间关系示例，以及来源、余料、质感和进阶方法入口。此处的两个对象是本次用户对新增写字纸的明确要求，不推广为所有素材、所有风格的遮挡数量标准。常驻知识同步替换该专题，整体 14,794 字符；不是在旧清单后继续叠加约束。初始素材说明也改为先确定主体与承托角色。

初始 creation_apply 现在直接带完整 Region schema；固定工具指南包含 material.cut、material.tear 的必填字段、可执行示例、坐标与余料说明。仍是 13 个初始工具入口，基础裁切不再依赖额外查询，复杂多片/穿插仍可按需展开。

中途磁盘耗尽导致 D146-visible 第 3 轮后写入失败及完整测试失败（ENOSPC），该轮不作为创作质量结论。经用户明确授权，删除 29 个已保存成品、项目和报告的历史重放检查点，释放约 11.15 GiB；原始素材与成品保留。D146-refined 为新建目录、空白开始的独立复测，使用重整知识、初始裁切和其他七参考。该运行启动后，又替换初始素材说明中“各类素材都可以是承托层”的旧句，进一步与角色方法一致；这句后续措辞调整未包含在该真实运行中。


### 重整后真实复测结论

D146-refined 达到约六分钟预算仍未完成交付（最后完整审计为第 16 轮，354.9 秒），不通过验收。已有数字和主体图案得到较完整展示，没有新增独立写字纸，但全程未主动裁切，正文仍过度挤在星月印花纸的窄区。裁切已进入首轮合同只能证明能力可见，不能宣称模型已经正确采用。独立审查反复把印在纸上的星纹描述为可单独移走的贴纸，且有蓝色圆点遮字的可疑判断；后续应将建议关联到真实图层和可修改对象，区分印花干扰与上层对象遮挡，避免错误修正链。不能通过删去所有读字检查来缩短时间。

本轮所有成品保持模型自主生成，无手工修改。恢复磁盘后完整回归 2,090 通过、1 跳过、0 失败，UI smoke 与七视口 route parity 通过。代码功能检查通过不等于创作审美通过；未上线。


### 按尺度渐进搭配与字群路线

用户指出首次用尽素材会让小素材随后被压住。对照调用确实在初摆批次一次放入十件素材。重写 composition 的开局方法与 paper 的试摆段落：少量决定面积/重心的大素材先试搭，小素材待实际边角和字群空间形成后加入；作为主角的小素材仍可开局参与。保持混合工具与回退调整，不增加阶段门槛。

同时替换 writing 的分段组织段落：以字群大小、长短、落点和小标题形成对角线或 Z 形读序；可在同一写面内，也可延续到背景。保持段内自然换行，区分字群布局与逐行强制倾斜。与 paper、composition 的常驻教学同步，未新增逐项禁止清单。最后这次文字指导调整通过三个相关测试文件；尚未再次调用付费模型验证，不能并入上一轮真实效果结论。

D153 另有一次相对引用漏写 node: 前缀；D162 有一次把 creation_title 工具写进 creation_apply.operations，以及一次标题缺少 order，均由模型自行修正。修复裁切后的同输入复测另行归档，不覆盖上述结果。

修复后的 D153 首两轮已验证供应商接受 2020-12 合同，并成功执行三次 source/mm 矩形裁切（蓝点纸、黄点纸、圆环纸），不再出现 box 被误拒绝。第一轮放五件主材，第二轮混合 material.add / material.cut / layer.update 并独立调用 creation_paper，后续再加文字。该记录仅说明实际工具链修复，最终视觉结论以成品为准。
