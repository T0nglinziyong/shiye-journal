# 纸片层次与工艺

每层应承担内容、承托、连接、界定或固定作用。先决定哪条边需要露出、哪一块可被遮住，再做叠压。不要给每件材料四角贴胶带、统一旋转或加厚阴影。薄纸的阴影应贴边、轻而短；需要阴影时先尝试约 0.15–0.3 mm 偏移、0.5 mm 模糊和低透明度，再看实际预览调整。避免悬浮卡片式大圆角与厚阴影。

## 关系与取料

承托纸可在主素材的一侧多露一点，另一侧少露；局部共同方向让叠贴可信。照片的人脸、物品主体和已有文字优先可读。票据可从主图下探出编号或边缘；碎片连接两个内容组时应有接触或方向关联。实体只有一份，用 material.cut 产生不重叠片段并保留来源；完整使用并不比裁切低级。

边框可承载照片、短句或局部底纹。真实开窗用 material.window，不能画一块纸色遮盖冒充孔洞。已有透明素材先保持原透明通道；半透明底层可以柔化杂纹，文字仍应保持对比度。不要把整组连同正文一并降低透明度。

有完整人物或物件主体时，背景块可以在主体后方形成两三处露边，短字条和空心图形连接边缘。`subject-layering` 展示这种先背景、再主体、最后小标记的顺序。主体轮廓仍是重点，不能按示例固定贴满同样数量的星星。

## 工具与复核

胶带、半透明底层和页眉页脚的细节可按需读取 `tape-and-vellum`；配色关系不清时读取 `journal-color`。每次只补当前问题需要的方法。

### 按关系选方法

| 需要的关系 | 方法 | 先确认 |
| --- | --- | --- |
| 上下承托、局部露边 | `paper-underlay`、`paper-peek` | 原素材尺寸足以形成露边；重要内容保持可见 |
| 不规则接缝或一纸多用 | `paper-tear`、`paper-split` | 轨迹避开主体；裁片和余料分别有来源 |
| 从孔洞看到下层 | `paper-window` | 孔洞完整位于纸内；挖下的窗芯隐藏保留 |
| 窗口与同纹样小纸片呼应 | `paper-window-reuse` | `corePlace` 指定窗芯位置；使用裁下后的尺寸，不复制原纸 |
| 纸条在纸前纸后来回穿行 | `paper-weave` | 真实直纸条已对准孔位，宽度足以穿过，所有材料在同一组合层级 |

开窗后用报告中的 `output` 和 `retainedNode` 继续编辑外框与窗芯。窗芯有独立裁片外接框，定位使用该框；隐藏的窗芯先用 `layer.update hidden:false` 显示。不要重新 `material.add` 同一个来源冒充余料复用。

穿插的 `through` 为 2–16 个真实孔位，每项通过 `region` 新开孔或用 `window` 引用已有孔，不能同时提供。`sideAfter` 指明穿过该孔后位于纸前还是纸后，相邻孔必须交替。每个新孔保留窗芯，外框替换后的 ID 在报告 `frames` 中。孔位不在纸条有效长度内、孔太窄、材料层级不同或开孔相连时会整批拒绝；先调整实体位置或重新选材，不拉伸纸条凑长度。

执行示意展示的是平面真实开孔与遮挡，不代表折纸厚度、可翻折口袋或立体编织。先保证前后关系与内容可读，再决定是否组合移动。

沿自己设计的轨迹手撕纸用 `material.tear`：先确定需要露出的轮廓，再给局部坐标点、保留方向与随机种子。开放轨迹从纸边到另一处纸边；闭合轨迹用于撕出封闭形状。`depthMm` 调起伏，`periodMm` 调疏密；短标题承托通常从 0.3–0.8 mm 起伏试起。原外边缘不受影响，余料默认保留；避开主体和关键文字，不给所有材料统一撕边。

按需查询 material.cut、material.tear、material.window、material.weave、layer.update、layer.order、layer.mask 的实际合同。胶带使用现行胶带工具和真实宽度，普通条形纸不能无限延展。对不可实现的折页、口袋不做可交互承诺。

预览重点看接缝、被遮内容和纸边：明显矩形堆叠是否有主次？所有素材是不是同一高度？边框是否真的透出下层？正文是否被图案吞没？如果结构已经清楚就停止加层，复杂度不是目标。
