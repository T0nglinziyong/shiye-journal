# 纸层与叠放

## 从素材簇建立纸层

纸张、主体和文字共同构图。先看素材里最值得展示的人物、数字、插画或印字，再选择相邻的纸色、纹样和写面，把它们组织成一个或几个互相呼应的簇。原页、彩色背景或整页底纸都可作为基础；局部纸层在其上承托主体、组织边缘与接缝。大底与局部纸簇可以配合，也可以只用其中一种，按整体关系选择。用户选择疏朗或丰富决定整体疏密，材料的角色与相互关系决定局部层序。

同一材料可以兼有几种用途：纹样纸既衬托人物，也从标题后露出；浅纸的一部分承字，另一部分进入照片背后；原页和深纸也能写正文。先用决定面积与重心的少量大素材试摆这些关系，其余素材保留待选；之后沿实际露出的边角和字群空间逐步加入小件。小件的落点回应主簇，而不是先铺满再被纸盖住。文字区域不等于一张新纸。

## 按内容安排显露与遮挡

主体层保留能辨认、能表达主题的部分；承托层让颜色、纹理或撕口从主体周围显露。素纸与重复纹样可大幅藏住；人物、数字、插画和有意义的印字则依据具体内容选择可遮部分。矩形照片或图案卡同样可能是主体，不能按外框形状决定谁在底层。选用局部时，保留下来的图案仍应成立；暂时不用的材料留在素材区。

深叠压主要发生在相互承托的纸之间，主体跨压纸缘并参与局部穿插。先确定最终可见的边角，再倒推位置：上层纸可同时沿横向、纵向移入下层，露出宽窄不同的边；纸本身可以放正。判断依据是层次、主次和读序，不是统一重叠比例或统一倾角。每次调整后看实际画面，确认新增纸没有吞没原本选定的主体。

## 把写面嵌进已有构图

文字先寻找现有的低纹样空间：纸的空白区、深纸上的浅字、素材簇之间的背景。一个段落可跨相近底色；多段可分布于不同空间，或在同一空间用小标题分层。印花与正文冲突时，先重新安排字群宽度、位置和分段，或裁取合适的纸片，保留印花本身的表现作用。

新增承字纸时，把它当作已有图文簇的一层来安排：例如左上进入照片下，右下进入人物或另一片纸下，显露部分接住正文，纸本身也把两处内容连起来。先确定整张纸与邻近大素材的关系，再分配它上面的文字；一张纸可承接多段，一段也可延续到相邻背景。仅在独立文字框旁放一个圆点、或让纸角擦过另一件素材，仍未形成共同承托。独立票据等本身已有内容的素材按其叙事用途处理。

## 从整料得到合适的轮廓

素材尺寸是原料条件，最终轮廓通过选用、移动、裁切、撕分和层序共同形成。纸过大时，可以保留需要的区域、切去多余边，或撕分成同源的两片呼应；不必为了塞下整料而把主体盖住。窄条用于跨接接缝，或两端进入其他对象下，只露中段；短句则可直接写在相关对象附近。

纸层沿对角或 Z 形安排的是视觉落点，不是统一旋转角度。两片可同大或一大一小，可深入叠放，也可分开让背景承字；正放、斜放与间隔各自选择。需要实体连接时，第三片纸可从两片背后穿过；也可让同源撕口与色彩跨空隙呼应。深纸与浅纸形成的连续簇、上下分置的同源裁片、横竖交错的纸带都可以与图像和字群组合。单双页均先看主次和阅读路线，再看哪些局部需要接触。

实际操作可同轮完成取用、裁切、移动、改层序和写字，也可在后续插入某一层。`material.cut` 保留或移除指定区域，`material.tear` 沿轨迹撕分；需要多片同时摆放用 `material.split`，并保留来源与余料。裁片沿用原素材坐标框，移动前看可见轮廓。实体材料不靠缩放或重复取用增加用量。

## 纸面、边缘与透光

数字纸用 `create(kind=paper)`：`style.fill` 选纸色，`style.stroke` 选印纹色，`texture` 选 subtle / medium / rough，`edge.style` 选 straight / torn，`edge.edges` 可指定撕边位置，`pattern` 选 plain / ruled / grid / dots。颜色可用本白、米白、牛皮棕、灰纸、黑纸或彩纸，与相邻材料近色或反差都可以；纹理是细微颗粒、纤维和缓慢色差，强度以文字可读和材料协调为准，不统一做旧。文字独立放置，纸不必写字。

纸张与胶带统一用 `style.opacity` 表现透光：0 完全透明，1 完全不透明，创建和修改使用相同字段；省略时保留默认值或原值。硫酸纸可从 0.55 左右试起，让下层纹样柔和透出、衔接两种颜色；透明胶带可从 0.65 左右试起，跨接时仍能看到下面的纸边与图案。具体值随素材原有透明度和预览调整，普通纸和不透明胶带可保持 1。文字独立放置，调纸面不透明度时不把文字一起变淡。

直裁、撕口与透明度分别选择。数字纸用 edge 获得真正透明的不规则纸边；真实素材的撕口用 cut / split，原有纸纹优先保留。层次来自露边、纹理、印纹与透明叠色，创作不使用阴影。普通平涂色块可继续用图形，不必全部纸化。

已有图形纸面可用 `style.paperSurface` 调整 matte / fiber / torn，intensity 控制强度、seed 固定纹理，设为 null 可去除；默认强度 0.45、seed 17。优先使用纸张入口，不另叠白色锯齿或重复 washi 齿边。纸仍是可编辑高级图形，后续用 update 只改需要的尺寸、纸色、纹理、边缘或层序；order.before 可将它插到已有主体或正文下面。

## 从预览判断关系是否成立

缩看主体是否仍清楚、纸块是否相互承托、色块和露边是否形成节奏；近看文字是否落在真正可读的空间、承字纸是否融入已有图文簇、胶带与圆星是否接触真实纸缘。层次不足先调整已有纸的落点和显露，内容被埋则让承托纸后退或裁去多余部分。达到用户的疏密与内容目标后停止加层，保留已经成立的关系。

## 方法选择

数字纸优先用 `create(kind=paper)`；`paper-color-card` 是可选纸面方法。窄纸条先确定跨接、露边或穿插关系，再用纸张工具创建或合法裁取真实素材，通过 `layer.update.order` 安排遮挡；普通色块才用 `graphic.add`。需要准确露边读 `paper-peek`；裁切读 `paper-tear` / `paper-split`；真孔读 `paper-window`，若要连窗芯一起再利用，用同一方法的 `parameters.variant="reuse-core"` 并给 `corePlace`；穿纸读 `paper-weave`。真实胶带的固定用 `tape-fix`，双角固定或分隔分别用它的 `variant="corners"` / `"divider"`。胶带、透明承托和旧物拼贴都是可选关系，不是所有页面必备。未确定方法时读 `methods` 比较；已选中方法可直接读目标 `detail` 获取精确参数。实体裁切和层序以当前工具合同为准。
