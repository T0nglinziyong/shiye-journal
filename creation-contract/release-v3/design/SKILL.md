# 手帐创作决策 Skill：从意图到可编辑 Scene

**适用：** 初稿、相同素材重做、用户参考风格学习，以及预览呈现“只摆素材＋几段小字”时的修订。本 Skill 是审美决策流程，不是另一套编辑协议。遇到具体问题时读 `PLAYBOOK.md`；看图时读 `REVIEW.md`。

## 1. 先决定这页有什么可说
看真实素材的印刷文字、轮廓、方向、色彩与可写空白。找一个能够推进的主题、疑问、情绪或小矛盾；没有用户事实时可写想象和态度，不捏造旅行、地点、人物与经历。纯拼贴或明确不配文字的任务，不要擅自新增正文。

把材料分成焦点／底纸／书写面／印刷标题／连接／点缀。一件材料可承担多种作用，必用不等于每件必须一样大、一样显眼。不要用来源 metadata 代替看原图。

## 2. 把文字当作构图要素
先给正文找可读区域，并与主要素材同时布局；确定标题、展开内容、插话/边注是否真的需要。可写面也可以来自素材内部的空白。正文能呈现推进和停顿，不应全是可互换的金句。已有强印刷标题时，不叠加同义大标题。

`style.fontSizePt` 是实际 pt；主要随写可以先尝试约 11–15 pt 的视觉尺度，小注可略小，但最终以真实双页预览的正常显示尺度为准。字号不是配额：读不清时先改文本框、行长、内容和留白，再讨论字体大小。不要让四个段落全部只剩小字。

## 3. 建立至少一条可见的“关系”，但不凑数量
判断画面是否只有完整矩形各自展示。关系可以是：人物跨越两个底纸、短句回应印刷标题、薄色带连接相邻区域、短线指向旁注、同色的小标记跨区域呼应。先做最小有意义的改动；若关系已经成立，不必额外加装饰。

数字图形/笔迹可与真实材料并置，但不能冒充来源库存；任何实体裁切必须保留 source 与合法余料。不要用白色填充伪装真实镂空。

## 4. 按问题选功能
- 画面像陈列板 → 改主次、叠压、取局部、跨边。看 `PLAYBOOK.md#r01`、`#r02`。
- 所有文字差不多小 → 改角色、框宽、行距与位置。看 `#r03`。
- 没有第二层可细看 → 从具体词句/素材出发选择笔迹、局部高亮或矢量标记。看 `#r04`、`#r05`。
- 色彩发闷/重量失衡 → 先改色值对比和主体位置，不先加新贴纸。看 `#r06`。
- 大纸占掉正文 → 先换职责/位置，许可时再裁取。看 `#r07`。

## 5. 在真实 PNG 上作出取舍
问自己：第一焦点在哪里？遮住新增字后材料是否仍只是在展示？主要正文不放大能否阅读？每条新增笔迹是否和一句话或一件材料有关？去掉它是否更好？双页各自完整且相互呼应吗？

复核发现问题就写新 Command 进行**局部**修订；无需为了凑轮次重做全页。最终可编辑 Scene 与 PNG 必须一致。

**学习参考时学关系，不抄固定坐标、句子、日期、素材；不引用额外图片作为用户拥有的材料。**
