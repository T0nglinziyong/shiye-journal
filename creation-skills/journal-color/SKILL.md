# 配色与明暗

先观察本次素材的大面积色、明暗和纹理密度，选择需要突出的内容。已有照片、实物纸片的颜色是约束；先调整邻接关系、露出面积和文字颜色，不为套配色而给照片染色。

## 选择关系

- 同色或邻近色：用深浅、冷暖或纹理差别建立主次。颜色接近且明度也接近时，换一张承托纸或留出纸色间隙。
- 明显异色：让其中一种承担主面积，另一种只在需要引导视线的位置出现。不是每个角都需要同等点缀。
- 多彩素材：先以本次关键照片或主体定基调，少量其他颜色通过标题、短线或现有小材料回应。彩色图案之间加入干净的承载区。

颜色面积由实际材料、留白和遮挡共同决定；不把 6:3:1 等示例比例设为硬目标。浅底深字、深底浅字先保证可读。色彩不足时可以用已有纸色和文字组织，不必增加装饰物。

## 示意与操作

`blue-lilac-layout`：低饱和大色块承托深色焦点，小承载区和文字方向形成层级。学习颜色分工，不复制英文标题或坐标。

`blue-tone-rhythm`：同色系中深色结构块与浅色内容区交替。中间角色连接两个区域；真实素材只有一份时不能照图复制。

先合批完成底色、标题色与关键邻接关系，再查看整页预览。如果一眼找不到主内容，优先减小非关键色块的露出面积或调整位置。不要反复微调几个相近 HEX 值代替构图。
